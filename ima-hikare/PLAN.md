## 1. 一本の筋と柱
**「1台のテレビゲームを、ビームの時刻で育てる」。** 遊ぶ人はかたまりの部品を線でつなぎ、速さのつまみを回して、自分の回路がブラウン管のどこを光らせるかを見る。作る画面と遊ぶ画面は分けない。

1. **位置は時間。** 画面のある場所は、ビームがそこへ来る時刻のこと。点は「横の数と縦の数が同時に一致した瞬間」に光る。玉は「数える長さのずれ」で動く。当たりは「同じ瞬間に2つ光った」で決まる。答え合わせはいつもブラウン管の光で行い、真理値表や合否の表は使わない。（1972年の本物も同じ作り。手本の監修が回路表で確かめた）
2. **組んだ途中が、もう遊べる台。** 同じ1枚の基板にかたまりを足していくだけで、作り直さない。段ごとに「この台で遊ぶ」がある。そこで足りないと感じたものが、次の段の理由になる。済んだ段は名札つきの「ふた」でたたむ。
3. **おれの台。** 動く範囲のなかで、どの数を選んだかの差が台の「くせ」になる。壊れた回路はくせと呼ばない。くせには必ずひきかえをつける。

## 2. 決めごと（出したセクション → 見たセクション）

### 遊ぶ人がすること
- 線をつなぐ・つまみを回すの2つ。どの面でもビームを止められる。止めたときだけ、管のどこでもドラッグしてビームを「こする」こともできる（管の下に時間の帯もある）。手数の制限も失敗もなく、まちがえても壊れない（煙や火花は出さない）。（ゲームデザイン → UX）
- 線はドラッグが主で、タップ2回でもつなげる。指の上にルーペを出し、24px で端子に吸いつく。線は自動で直角に引く（道は描かせない）。「ひとつ戻す」をつける。（UX）

### 組む単位（NAND からは組ませない）
- **台に最初から付いているもの:** 時計・横カウンタ・縦カウンタ（ビット端子と消す時間の端子を出しておく）。
- **段階Aで組むもの:** くらべる（何度も使う。数は管のふちのものさしの▼で選ぶ）・かつ（AND。点線も当たりも使い回し）・玉のカウンタ（長さの「差」のつまみ。0 に吸いつく）・向きを覚える（フリップフロップ）・つまみタイマー（パドル。待つ行数は整数）。
- **段階Bで足すもの:** どちらか（OR）・音を取り出す・点数のカウンタと数字・打った回数。
- **1段の上限:** 新しいかたまり1つ・線3本（組み合わせる段は4本）・見えるかたまり9個まで。（ディレクター・監修 → レベルデザイン）

### マス目と本物の細かさ
- 本物の 455×262 を、カウンタの上のビット（8こま×8行）で区切ったマスにする。見えるのは約47×31で、ほぼ正方形。くらべる部品はこのマスに吸いつく。**玉とパドルの待ちだけは本物の細かさで動かす。** 玉は本物どおり4×4、パドルは4こま×15行・8区画。（ゲームデザイン 32×24 → レベルデザイン 56×32 → 検証の案 → 監修が本物で裏づけ。縮めたマスでは玉が5〜8倍速くなり、比で縮めるとパドルと8区画が入らないため）
- 玉の横の速さは本物どおり 1・2・3こま／画面（打った数0〜3／4〜11／12〜）。パドルの間を約4.2秒・2.1秒・1.4秒で渡る。縦は打った区画で決まり、上から 13,12,11,10,10,9,8,7（上3〜下3、真ん中2区画はまっすぐ）。1周を短くするのは1画面に1回だけ。
- はね返り: **パドルは向きを決める型**（本物どおり）。**壁は当たるたびに反転する型**がおすすめ（本物どおり。閉じこめも本物のくせ）。ただし検証が閉じこめの率を測ってから確定する（3章）。

### 最初の30秒（UX）
0〜3秒: ビームが1行ずつはい、横カウンタのランプが合わせて点滅する。→ 3〜8秒: 端子が1つだけ脈打ち、管にうすい見本の光が出る。→ 8〜15秒: つなぐとカチッと鳴る。線が光るたびにビームの区間も光って縞がたまり、線と管が糸で結ばれる。→ 15〜22秒: 速さのつまみが脈打ち、上げると縞が「絵」になる。→ 22〜30秒: ほかの端子が2つ光る。挿しかえると縞が変わる。
- 「ゆっくり」は1行0.5〜1秒で、残光は長めにする。AND と OR は3面目より前に出さない。

### 区割りと見た目
- **段階Aは「ならべた2枚」の配置に「作業机のジオラマ」の質感**（アートの3案 → UX）。PC は左45%が管、右55%が基板で、速さのつまみは管の真下（幅240px以上）。スマホのたて画面は、管（約280px）→ 基板 → 下の帯（つまみと置き場）。基板はパンもズームもしないで収め、端子は横7〜8列まで。
- 組んでいるときのカメラは真上に近く（10°以下）。片方が隠れるほど寄らない（線と光を同時に見るのが芯）。「透ける回路」の案からは、糸と帯だけ借りる。
- 質感: むらのある緑の基板に銅がうっすら透ける。パッドははんだのにぶい銀。IC はつや消しの黒で、型番はでたらめ。足は1本ずつ作る。フラックスのしみ・ほこり。光は机のランプと管の2つだけ。
- 信号の「1」は琥珀 `#ffb347` の1色（カウンタのランプも琥珀。赤は色覚の理由でやめた）。管は青白 `#d8ecff`。操作の UI は明るい層に置く。
- ブラウン管: インターレースなしの淡い走査線・にじみ・たる型・角の暗さ・映りこみ・電源オンの演出。色の三つ組の網目と色ずれは入れない。
- 速さのつまみは5つの止まり（止める／1行ずつ／ゆっくり／速い／本当）。新しくつなぐと自動で「ゆっくり」に戻る。

### 助け
- 見本の光をいつも出す。20秒たつと次の端子が脈打ち、40秒でうすい線が出て、そのあと「答えを見る」を出す。飛ばした段は、色をかえた「代わりの線」で埋める。
- 止まりやすい所の手当て:
  - 点＝横かつ縦がわからない → 管にうすい縦帯と横帯を出し、重なった所だけ強く光らせる。
  - 光らない → 「ずっと0」の消えたランプを出す。
  - 1周のずれが魔法に見える → 前のコマの玉をうすく残し、0の位置をピンで示す。
- うまい人へのおまけは、線を少なくすることにはしない（ゲートの最小化パズルに寄るため）。玉をネットの真上で止める・ラリーの記録・ライバルの台に勝つ、にする。

### 音
- ピコ音は自分の回路の信号から鳴らす（本物も、カウンタのビットで鳴らしていた）。段階Aは手の音と部屋のハムだけ。**BGM は基本なし**（入れるなら、机のラジオが遠くで鳴る場面の音）。15.7kHz のキーンは既定で切る。

### 図鑑の「うそ」と名前
- 1項目を「本物は／このゲームでは／なぜ変えたか」の3行で書く。うそとして書くもの: ゆっくり・長い残光・マスを上のビットにした・ネットが太い・かたまりの部品・光のつぶの速さ・玉をにじみで太らせた。資料で割れていることは「割れる」と書く（60.05/59.97Hz、上端のすき間をわざと残したか、蛍光体の残光、IC は約66個（試作は73個とも））。455・262 などの数は画面に出さず、図鑑に回す。
- 避けるもの: PONG・テレビテニス・Tennis for Two・メーカー名・機械の名前。当時の回路図の写し・筐体・ロゴは使わない。回路図の記号の見た目も避ける。宣伝とサムネは、テニスの絵でなく「ビームと光る線」で見せる。

### 計算と確かめ（検証）
- 組んだ回路を `new Function` で JS の関数に組み立てる。本物の 455×262 を1こまずつ回しても、1画面0.9〜1.5ms で間に合う（ベンチ済み）。かたまりの単位で計算する。刻み方がちがっても同じ絵になる（ハッシュで確かめる）。入力は画面の頭でだけ受け取る。時計を通らない自分への戻り線は「ぐるぐる」と知らせて、つながせない。
- 道具: `js/sim.js`（純粋）・`tools/sim-check.mjs`・`tools/stage-measure.mjs`（つまみ×配線の総当たり）・`tools/match-sweep.mjs`（台の勝負）・`tools/playtest.mjs`（`window.__probe`）。
- 目安: つまみの合格15〜20%以上かつ幅3目盛り以上。台の勝負は、勝ちすぎ（65%超）の台が0、くせの段ごとの平均勝率が40〜60%。
