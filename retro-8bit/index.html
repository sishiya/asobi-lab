8ビット互換機

一から書いた8ビットのゲーム機と、この機械のために作ったオリジナルのカセット。

ASOBI-LAB 8COMPATIBLE SYSTEM

カセットをえらぶと、本体にさしこんで電源が入ります。

とりあつかい説明書

CPU（6502）・絵・音（矩形波2・三角波・ノイズ）・カートリッジのしくみ（マッパー 0・1・2・3・7）を、あそびラボが JavaScript で書きました。メーカーのプログラムやデータは入っていません。カセットのソフトは、自作のアセンブラで作ったオリジナルです。ROM のファイルは自由にダウンロードできます（ゲームの中身は CC BY-NC 4.0）。

電池つきのカセット（恐竜かけっこ牧場 8bit）のセーブは、このブラウザの中に残ります。ふーっと息をふきかけなくても、ちゃんと動きます。
