# 8ビット互換機（ファミコン互換エミュレータ）とオリジナルのソフト — 企画書

2026-10-24〜。ユーザー「まずは練習がてらファミコン互換エミュレータと、１本オリジナルゲームを作って」。

## 0. 方針（ライセンス）
- **エミュレータは一から自分で書く**（ほかのエミュレータのコードは使わない）。CPU（6502）・PPU（絵）・APU（音）・カートリッジ（マッパー 0・1・2・3・7）。
- **BIOS はない機種なので、メーカーのコードは1バイトも入れない**。色の表（パレット）は数で決める。
- **市販ソフトは入れない・リンクしない**。
- **自分のファイルを開く**（2026-10-24 ユーザー「アップロードして起動できるように」で v002 から）: **この端末の中だけで読み、どこにも送らない・保存しない**（サーバーに上げる作りにはしない）。「権利を持っているファイルだけ」と書く。市販ゲームの名前・画面・動作の一覧・ROM サイトへのリンクは出さない。市販ゲームで遊べることを宣伝しない。
- 棚の ROM（あそびラボのオリジナル）は自由にダウンロードできる（中身は CC BY-NC 4.0）。
- エミュレータの検証に市販 ROM は使わない。使うなら、エミュレータ検証用に配られているテスト ROM（nestest・blargg のテストなど）を、ユーザーの OK をもらってから手元だけ（`_dev/`）で。
- **商標を名前に使わない**: 画面・タイトル・ファイル名に「ファミコン」「NES」「任天堂」は出さない（このメモと DEVNOTES の説明だけ）。呼び名は「8ビット互換機」。
- 入れるソフトは**あそびラボが作ったものだけ**（ソースもこのフォルダ。アセンブラも自作）。

## 1. 何を作るか
1. **エミュレータ**（`js/`）: ブラウザで動く。キーボード・ゲームパッド・スマホの指。音は WebAudio。
2. **アセンブラとビルド**（`tools/`）: 6502 のアセンブリ（`src/<ゲーム>/game.s`）と、文字で描いたドット絵（`src/<ゲーム>/art.mjs`）から `.nes` を作る。
3. **オリジナルゲーム**: 「カエルのよる」（`src/frog-night/` → `roms/frog-night.nes`）、「恐竜かけっこ牧場 8bit」（`src/dino-ranch/` → `roms/dino-ranch.nes`。v002）。

## 2. カエルのよる（手ざわり）
- 夜の池。カエルが下のハスの葉の上を **左右に動き**、**A で舌を真上にのばす**。のびる → もどる、の1往復。
- 飛んでいる虫を舌の先でとる。1回ののびで何匹もとるとボーナス（×2・×3…）。
  - ハエ 10点（速い）・ガ 30点（ゆっくり大きくゆれる）。
  - **ホタルは食べてはいけない**（ホタルは体に毒をもち、食べた生き物は具合が悪くなる。本物のしくみ）。とるとハートが1つ減り、カエルはしばらく目を回す。光っていて目立つ＝いちばん目に入る物が、さわってはいけない物。
- 夜は 90 秒。だんだん虫が増え、ホタルも増える。空が少しずつ明るくなり、朝で終わり。ハート3つがなくなっても終わり。
- 操作: ←→ 移動、A（X キー）舌、START（Enter）はじめる・一時停止。

## 3. 段階
- 段階A（v001）: エミュレータ＋カエルのよる1本、保管庫に置く。
- v002（2026-10-24）: トップを棚に・ファイルを開く・ダウンロード。**恐竜かけっこ牧場 8bit**（dino-race の移植。ユーザー「恐竜・ぺらぺら・箱庭のうち1つ以上を 8bit 版に」→ 芯が数と表に移しやすい恐竜を選んだ。ぺらぺら（3D の断面）と箱庭（水の計算）は、この機械の力では芯が残りにくい）。ブラウン管の画面（ユーザー「ブラウン管のドット絵アプリから移植してブラウン管をエミュレートできるように」）。

## 4. やらないこと（いまは）
- 市販ソフトの動作の保証、MMC3 などの複雑なマッパー、DMC の音、PAL。

## 5. 恐竜かけっこ牧場 8bit（v002）
- もとの芯をのこす: 2頭をえらんでかけ合わせ → 卵3つ → 1頭を残す（牧場は4頭）。100m のかけっこ。大きい体は重く筋肉が足りない（Hutchinson & Garcia 2002 の考え方）。脚が長く足が速いほど転びやすく、しっぽでつり合い。見た目は図鑑の骨格図（クリームの紙にインクの骨）。
- 物理のかわりに式（`src/dino-ranch/data.mjs` の `derive`、ROM の `derive` と同じ）: 出したい速さ = 18＋脚＋足の速さ＋大きさ/2、筋肉で出せる速さ = 26＋筋肉×2−大きさ×1.5 の小さい方（km/h）。転びやすさ = 脚＋足の速さ＋大きさ/2 が 10＋しっぽ×2 をこえた分。転びやすい子には「WOBBLY」。
- 杯3つ×3回。ライバルは 22〜46 km/h（1回目 22・24・26 から、3杯目の最後 42・44・46）。1位でつぎへ。ぜんぶ勝つとエンディング（Sellers & Manning 2007 にふれる）。
- スタートの「GO!」のすぐあとに A でよいスタート、GO の前に押すとフライング（小さな遊び。もとにはない）。
- 難しさ: 同じ決まりの JS のシミュレーション（いちばん速い2頭をかけ合わせ、いちばんよい子を残すだけの手）で、3杯まで 15〜30 世代。変わる確率を 1/4 → 1/2、3杯目のライバルを 2 km/h 下げてこうした。
