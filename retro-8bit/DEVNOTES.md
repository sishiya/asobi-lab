## 区割り（RULES 4章）
- **棚**: 上に機械の名前と説明、まん中にカートリッジのカード（小さな画面・名前・説明・**あそぶ**（主役）・ROM ↓）、下に「自分のファイルを開く」（この端末の中だけ、の説明を近くに）と「この機械について」。
- **遊ぶ画面**: 上の左に ← 棚へ とカートリッジの名前、右にめったに使わない道具（▣ 画面・音・リセット・全画面）。まん中に画面（ふさがない。なるべく整数倍）。下に PC はキーの案内（ソフトごと。`js/library.js` の keys）、スマホは十字キー・SELECT/START・B/A。棚から入るときは「あそぶ」が押されているので、すぐ電源が入る。URL の `#dino-ranch` などで直接ひらいたときだけ「電源を入れる」（音を出すために1回押してもらう）。

## しくみ（ファイル）
- `js/ops.js` — 6502 の命令表（CPU とアセンブラで共有）。
- `js/cpu.js` — CPU。`js/ppu.js` — 絵（1行ずつ。行の途中のスクロールの変化は行の単位で効く。0番の当たりで画面を上下に分けられる＝恐竜のかけっこの上の帯）。`js/apu.js` — 音（矩形波2・三角波・ノイズ。DMC なし）。
- `js/cart.js` — iNES。マッパー 0・1・2・3・7。`battery`（ヘッダーの電池の印）。
- `js/nes.js` — 線でつなぐ。`runFrame()`。
- `js/palette.js` — 64色。
- `js/library.js` — 棚のカートリッジ（id・ファイル・名前・説明・キーの案内・棚の小さな画面に出すまでのフレーム）。**ソフトを足したらここに1つ**。
- `js/main.js` — 棚と遊ぶ画面・入力（キー・指・ゲームパッド。すぐはなしても1フレームは押したことに。**画面の字と同じ名前のキー**: A キー＝A ボタン・B キー＝B ボタン（X・Z も）・Enter＝START・Shift＝SELECT。案内はボタンの形 → キー → すること の順で `BUTTON_KEYS`）・画面の大きさ（デバイスのピクセルで1ドットを整数に。Windows の 125%・150% でも走査線がゆがまない。crt-pixels と同じ）・音・**電池のセーブ**（`$6000` の 8KB を localStorage の `retro8.save.<id>` に。3秒ごとと、棚へもどる・タブを離れる・ページを閉じるとき。棚のソフトだけ）・**自分のファイルを開く**（`File.arrayBuffer()` で読むだけ。fetch も保存もしない。1MB まで。iNES でなければその場で知らせる）・**画面の見え方**（下）。確かめ用の窓口 `window.__retro8`（`stats.frames`・`mode`・`setScreen(m)`・`nes`）。
- `js/crt/` — **ブラウン管**: まなびラボ「ブラウン管のドット絵」（`../アプリ開発/crt-pixels/`）の `ntsc.js`（テレビの信号の計算）と `crt-gl.js`（WebGL2 の画面。土台は crt-lottes＝パブリックドメイン）を ES モジュールにしたもの。中身は変えていない（もとを直したら写しなおす）。`worker.js` で信号の計算（1コマ約 11ms）を別のスレッドに。
  - 見え方: くっきり（2D の canvas）／ブラウン管・RGB（信号の計算なし。1ドットを4点にのばして GPU へ）／ビデオ端子／アンテナ線（worker で計算して、できたら GPU へ。1コマおくれる）。localStorage の `retro8.screen`。はじめは PC がビデオ端子、スマホ（指の端末）がくっきり（描くのが重いので）。
  - 固定の値: シャドウマスク 1.5組／ドット（家のテレビ）・走査線・ガンマ 2.4・ブルーム 0.10・ふくらみ・ドットクロールは止める（1コマ目の位相。30回／秒の点滅をさける。もとのアプリと同じ考え）。WebGL のキャンバスはデバイスのピクセル（2倍まで）。
  - 速さ（2026-10-24、RTX 5070）: どの見え方でも 60 フレーム／秒。ヘッドレスの Chrome（GPU なし）では 6 くらいしか出ないので、速さは GPU ありで測る（下）。

## ROM の作り方（`tools/`）
- `asm.mjs` — 自作のアセンブラ（2回読み。`@名前` は直前のラベルの中だけ、`[ ]` が式のかっこ、`<` `>` で下・上のバイト）。分かれ道が遠すぎると止まる（`beq` ＋ `jmp` に書きかえる）。
- `lib.mjs` — 共通の道具（絵 → CHR・字・画面と属性・字のデータ・曲）。`src/font.mjs` が共通の字（数字・英大文字・記号）。字にない文字を使うとビルドが止まる。
- `src/music.s` — **曲の係（どのゲームも共通。build がつなぐ）**。メロディ（矩形波2）は1フレームずつ音量を下げる（`env_tab`。毎音いっぱいの音量にしない）、ベース（三角波）は線形カウンタで短く切る（`TRI_LIN`）、曲ごとの音色は `song_duty`。曲は `lib.mjs` の `compose()` で小節ごとに「メロディ | 和音 ベースの形」と書く（拍が合わない小節はビルドが止まる）。
- `build.mjs` — `src/<ゲーム>/data.mjs` の `build()`（絵・画面・曲・表）＋ `src/<ゲーム>/game.s` → `roms/<ゲーム>.nes`（NROM 32KB＋CHR 8KB）。`BATTERY`・`HORIZONTAL` で見出しの印。**ROM を変えたら `node retro-8bit/tools/build.mjs` を走らせて、`.nes` もいっしょにコミットする**。`--preview` で `_dev/retro-8bit/<ゲーム>-chr.png`。
- `run.mjs` — 画面なしで動かして PNG（`--press=START@100,A@180`、`--bot` はカエルのよる専用）。
- `dino-sim.mjs` — 恐竜の難しさの見積もり（下）。

## カエルのよる（`src/frog-night/`）
- 決まり: 舌は 8 ドット/フレームでのびて最大 148、6 でもどる。のびているあいだは動けない。舌の先の当たりはハエとガが ±8、ホタルは ±5。点は（ハエ 10・ガ 30 の合計）×とった数。ホタルでハートが1つ減り 1.5 秒目を回す。夜は 90 秒、15 秒ごとに虫が増える。のこり 30 秒から空が明るくなる。
- パレット: 背景 0 空と字・1 草とハス（3 が水の色）・2 水・3 月。スプライト 0 カエル・1 舌とハート・2 ハエとガ・3 ホタル。
- ゼロページの番地は `game.s` の頭（`run.mjs` のボットが読む）。

## 恐竜かけっこ牧場 8bit（`src/dino-ranch/`）
- もと: `dino-race/`（恐竜かけっこ牧場。Planck.js の物理で骨格を走らせる）。8 ビットでは物理のかわりに式 `derive`（`data.mjs` と `game.s` の両方。**片方を変えたらもう片方も**）。式と遊びは PLAN.md 5章。
- 見た目: 図鑑の骨格図。紙 $37・インク $07・セピア $17。字は影なし（紙に刷ったように）。題字のかなは 8×8 で描いて 2 倍。骨格は 24×16 の3コマ（脚だけちがう）、転ぶと上下さかさ。
- 場面: タイトル → 牧場（2×2 の囲い。十字キーでえらんで A → RACE／BREED／LET GO）→ 卵（3頭からえらぶ。B で全部逃がす）／かけっこ → 結果 → 牧場。3杯とるとエンディング。
- かけっこ: 100m = 1280 ドット（10m = 128 ドット。背景は 256 ドットでくり返すので、柱が 10m ごとにそろう）。速さは km/h×15（1フレームのドット 8.8）。上の帯（0〜3 行）は 0 番のスプライトの当たりで止め、下を横にずらす（`split_scroll`。当たらないときも止まらないよう数えて抜ける）。32 フレームに1回、つり合いが悪いと転ぶ（45 フレーム）。ゴールしたら、ゆっくり止まる（ほかの子が画面に入ってくる）。
- セーブ（電池の RAM `$6000`）: "DR81"・杯（0〜3。3 = 全部とった）・回（0〜2）・`$6010` から 4 頭 × 8 バイト（つかう・大きさ・脚・筋肉・しっぽ・足の速さ・km/h）。タイトルで **SELECT を押しながら START** で、はじめから。
- 難しさ: `node retro-8bit/tools/dino-sim.mjs [たね]` で、いちばん速い2頭をかけ合わせるだけの手で 15〜30 世代（v002）。ライバルの表は `data.mjs` の `RIVAL_KMH`（転ばない体から、決まった並びで選んで `rival_genes` に）。

## 確かめのしかた
1. `node retro-8bit/tools/test-cpu.mjs` が「ぜんぶ正しい」。
2. `node retro-8bit/tools/build.mjs` で2本とも組み立つ。
3. カエル: `node retro-8bit/tools/run.mjs --bot --press=START@100 --frames=2000,5520` で朝まで（v001: 1290点・ハート3つ）。
4. 恐竜: `node retro-8bit/tools/run.mjs retro-8bit/roms/dino-ranch.nes --frames=160,560,1300 --press=START@80,A@140,A@170,A@1400` で、牧場 → かけっこ（10m の柱の数・時間）→ 結果。かけ合わせは `A@1430,RIGHT@1450,A@1470,RIGHT@1490,A@1510,A@1660` を足す（卵 → 3頭 → 囲いに入る）。
5. ページ: `node tools/playwright/shots.mjs retro-8bit` で4つの幅（棚）。遊ぶ画面は Playwright で棚の「あそぶ」→ Enter。自分のファイルは `setInputFiles('#file', …)` で、開いたあとに通信が 0 件か。セーブは再読み込みで `prgRam` が同じか。音はボリュームゼロ（`localStorage.retro8.sound = '0'`）。
6. ブラウン管の速さ: Playwright の chromium を `--enable-gpu --ignore-gpu-blocklist --use-angle=d3d11` で起動し、`__retro8.setScreen(m)` のあと `stats.frames` の増え方を見る（アプリの Browser ペインは隠れていると止まるので測れない）。

## 曲（v003）
- ユーザー「BGM のループが短くくどくて耳障り」→ 長くして、やわらかく。カエル: 3拍子の子守歌 44 小節・約 44 秒で1周（A・A'・B・B'・A・ベースだけの息つぎ4小節）、50% の音色、音量 7 から 3 へ。恐竜の牧場: 28 小節・約 30 秒、ベースは2拍ずつ。かけっこ: 24 小節・約 16 秒、8分音符のかけ足のベース、25% の音色。音の大きさ（RMS）はカエル 0.085 → 0.049、恐竜 0.094 → 0.051（約 −5 dB）。
- 1周の秒と大きさは、ROM を動かして `mus_ptr0` が頭にもどるフレームと APU の出力で測った（耳ではまだ聞いていない）。
