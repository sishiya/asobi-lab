## 区割り（RULES 4章）
- **棚＝本体とカセットのケース**（v011。2026-10-25 ユーザーと `look/look6.html` で決めた形。v004 の「カセットの棚」の A を土台に）: 上に名前と本体、下の机に透明のケースに入ったカセットが同じ大きさで並ぶ（集めたくなる見た目）。
  - 本体: 子ども向けの商品として作れる形。さしこみ口はカセット 160px ＋ 左右 4px（v016。ぴったりで動かない）、上のふちまで欠けていて上からまっすぐ入る、窓の下は前の面と同じ平らな面（盛り上がりなし）。カセットは上から奥まで入り、外に出るのは指のかかりだけ（基板は見せない・ぶつけて折れる出っぱりを作らない）。さしこみ口にガラスはない。指のかかりの影は、カセットが入っていないときは描かない。右に RESET・POWER のスイッチと電源ランプ、左に 1P・2P の口。色は生成りとミント（カセットの色とかぶらないように）。実在の機械の形・色はまねない。
  - カセット: 8色を 4×2 で（藍・からし・すみれ・鉄・えんじ・オリーブ・あんず・ねずみ。`CART_COLORS`。v013 で「すみ」を外した）。**棚の音**（v014 で入れ、v016 で作り直し。ユーザー「SE が主人公にならないように。動作の説得力をさりげなく上げればいい」「ケースはプラスチック」「コトッは木の音で違和感」「抜き差しはこすれた シャッ と カチャッ1回で十分」）: `sfx/` の5つ（手元の Stable Audio 3 で候補を4つずつ作り、波形でカチッが1つだけ・高い音が少ないものを選んで 0.1〜0.36 秒に切り出した ogg）。入れる: ケースを開ける（`case_open`。うすいプラスチックの小さな音）→ 本体の上へ（音なし）→ 溝をすべる `slide`（シャッ）→ 底で `click`（カチャッ1回）→ からのケースを閉める（`case_close`）→ 電源（`power`）。もどる: 電源を切る → 抜く（`slide` を 1.15 倍の速さで）→ ケースを開ける → しまう（音なし）→ 閉める。鳴らすのは main.js の `clack`（ローパス 5kHz。大きさは `SFX` の表で 0.14〜0.3＝ゲームの音よりずっと小さい）。動きに音を重ねた確かめの動画 `look/shelf-av-1280.mp4`・`shelf-av-375.mp4` は手元だけ。電池のセーブがあるカセットは「…」に「セーブを消す」（v013。前は説明書の中にあった）。ラベルはタイトル画面。ケースは「すっきり」（うちがわだけ少し、ふちをもう少し曇らせる）。押す → ケースが開く → カセットが本体の上へ飛んで、口へすべりこむ（最後に 3px 沈む・カチッ）→ ケースは閉める → 電源が入って遊ぶ画面へ。別のカセットを押すと、入っているのを先に抜いてケースへ戻す。**遊ぶ画面から棚へもどる（← でもブラウザの戻るでも）と、電源が切れてカセットはケースへ帰る**（v012。入ったままだと POWER で遊べることに気づきにくい、とユーザー）。**本体のスイッチ（RESET・POWER）は飾り**で押せない（v012。ユーザー「POWER は押せなくていい。手間」。カセットを押せば電源が入る）。指をのせると、ケースごと少し持ち上がって傾く（指で押す端末では動かない）。「…」メニューを開いているあいだは傾けず、いちばん手前に出す。
  - 色・なまえ・ROM ↓・すてるはカセットの右上の「…」のメニューにまとめる（ふだんは見せない。主役はカセット）。色は localStorage の `retro8.cartColor.<id>`。いちばん右が「＋ じぶんのカセット」（押す・ドロップ）。足してもすぐには入れず、並べて ぽんと出すだけ（v012）。はじめの色は灰色の「ねずみ」（目立たない。v011 までに自動でつけた色は、いちどだけ消した＝`retro8.mineGray`）。じぶんのカセットはブラウザの中から読むので少しおくれる。前の本数（`retro8.mineCount`）だけ「よみこみ中…」のケースで先に場所をとる。とりあつかい説明書は右上の ？ から開く板（v012）。
  - フォントは1種（ページのゴシック。ドット絵ふうのフォントはやめた＝ユーザー「統一感がなく見える」）。
  - 大きさ（v012）: 本体は 600×270 の形のまま `scale` で縮める（`--kc`＝(幅−32)/600 まで。スマホでもつぶさない）。飛ぶカセットは本体の中の座標で動き、机の大きさ→本体の中の大きさへ `scale` で変える（`geo()`）。スマホ（幅 600 まで）は画面の高さにおさめ、カセットは1行に2本、列の中だけ上下に動く（`zoom:--kd`＝幅/390 まで）。「…」メニューは下からの板。

## しくみ（ファイル）
- `js/ops.js` — 6502 の命令表（CPU とアセンブラで共有）。
- `js/cpu.js` — CPU。`js/ppu.js` — 絵（1行ずつ。行の途中のスクロールの変化は行の単位で効く。0番の当たりで画面を上下に分けられる＝恐竜のかけっこの上の帯）。`js/apu.js` — 音（矩形波2・三角波・ノイズ。DMC なし）。
- `js/cart.js` — iNES。マッパー 0・1・2・3・7。`battery`（ヘッダーの電池の印）。
- `js/nes.js` — 線でつなぐ。`runFrame()`。
- `js/palette.js` — 64色。
- `js/input.js` — **入力**: キー・指・ゲームパッドを 1P・2P のコントローラーに。当時の機械と同じく 1P は 十字キー・A・B・SELECT・START、2P は 十字キー・A・B・マイク（`$4016` の 2 ビット目。`nes.mic`）。キーの割り当ては localStorage の `retro8.keys`（はじめは 1P: 矢印・A/X/Space・B/Z・Shift・Enter、2P: I/J/K/L・. ・, ・M がマイク）。ゲームパッドは 1 台目が 1P、2 台目が 2P（Y がマイク）。
- `js/settings.js` — **⚙ 設定**: タブ「画面と音」（見え方・音・大きさ・指で押したらふるえる）と「キー」（＋ を押して使いたいキーを押す、× で外す、ほかで使っていたキーは移す、はじめにもどす）。開いているあいだはゲームを止める。
- `js/mycarts.js` — **じぶんのカセット**: 開いた .nes をこのブラウザの IndexedDB（`retro8` の `carts`）にだけ残す。`listCarts`・`addCart`（30本・1本 1MB まで）・`renameCart`・`deleteCart`（セーブ `retro8.save.my-…` も消す）。棚ではほかと同じカセット（ラベルはタイトル画面と名前）、「…」のメニューに「なまえ」「ROM ↓」「すてる」（ROM ↓ はこのブラウザの中の Blob から。送らない）。電池のセーブはカセットごと。
- `js/shelf.js` — **棚**（本体・ケース・さしこむ／抜く動き（WAAPI）・「…」のメニュー・ドロップ）。`initShelf({ library, loadRom, open, sfx })` が `render`・`back` を返す。main.js は音（`clack`）と遊ぶ画面へのつなぎだけ。
- `js/library.js` — 棚のカートリッジ（id・ファイル・名前・説明・キーの案内・棚の小さな画面に出すまでのフレーム）。**ソフトを足したらここに1つ**。
- `js/main.js` — 棚と遊ぶ画面・入力（キー・指・ゲームパッド。すぐはなしても1フレームは押したことに。**画面の字と同じ名前のキー**: A キー＝A ボタン・B キー＝B ボタン（X・Z も）・Enter＝START・Shift＝SELECT。案内はボタンの形 → キー → すること の順で `BUTTON_KEYS`）・画面の大きさ（デバイスのピクセルで1ドットを整数に。Windows の 125%・150% でも走査線がゆがまない。crt-pixels と同じ）・音・**電池のセーブ**（`$6000` の 8KB を localStorage の `retro8.save.<id>` に。3秒ごとと、棚へもどる・タブを離れる・ページを閉じるとき。棚のソフトだけ）・**自分のファイルを開く**（`File.arrayBuffer()` で読むだけ。fetch も保存もしない。1MB まで。iNES でなければその場で知らせる）・**画面の見え方**（下）。確かめ用の窓口 `window.__retro8`（`stats.frames`・`mode`・`setScreen(m)`・`nes`）。
- `js/crt/` — **ブラウン管**: まなびラボ「ブラウン管のドット絵」（`../アプリ開発/crt-pixels/`）の `ntsc.js`（テレビの信号の計算）と `crt-gl.js`（WebGL2 の画面。土台は crt-lottes＝パブリックドメイン）を ES モジュールにしたもの。中身は変えていない（もとを直したら写しなおす。いまは crt-pixels c1a0e7e＝にじみを JS のガウスで作るように直したあと（その前の 219a627＝デバッグ）: ビデオ端子の明るさは色副搬送波のまわり ±1MHz だけを落とすトラップ・ブルームは光る点と頭打ちの前にまぜる・こし器の帯域は −3dB・2コマの平均は光の量で・光る点は小さいとき画面の3ピクセルに合わせる）。**互換機では `setSquare(true)`＝当時の機械と同じく色を四角い波で作る**（worker.js）。`worker.js` で信号の計算（1コマ約 11ms）と光のにじみ（`makeGlow`、約 19ms）を別のスレッドに。にじみは 4 コマに 1 回だけ作る（ぼかした光なので少しおくれても見えない）。RGB の見え方も worker を通す。写しで変えたのは2つ: `makeGlow` を export・`setSignal` の7つ目の `glow`（worker で作ったにじみを渡す／false で前のまま）。
  - 見え方: くっきり（2D の canvas）／ブラウン管・RGB（信号の計算なし。1ドットを4点にのばして GPU へ）／ビデオ端子／アンテナ線（worker で計算して、できたら GPU へ。1コマおくれる）。localStorage の `retro8.screen`。はじめは PC がビデオ端子、スマホ（指の端末）がくっきり（描くのが重いので）。
  - 固定の値: シャドウマスク 1.5組／ドット（家のテレビ）・走査線・ガンマ 2.4・ブルーム 0.10・ふくらみ・ドットクロールは止める（1コマ目の位相。30回／秒の点滅をさける。もとのアプリと同じ考え）。WebGL のキャンバスはデバイスのピクセル（2倍まで）。
  - 速さ（2026-10-24、RTX 5070）: どの見え方でも 60 フレーム／秒。ヘッドレスの Chrome（GPU なし）では 6 くらいしか出ないので、速さは GPU ありで測る（下）。

## ROM の作り方（`tools/`）
- `asm.mjs` — 自作のアセンブラ（2回読み。`@名前` は直前のラベルの中だけ、`[ ]` が式のかっこ、`<` `>` で下・上のバイト）。分かれ道が遠すぎると止まる（`beq` ＋ `jmp` に書きかえる）。
- `lib.mjs` — 共通の道具（絵 → CHR・字・画面と属性・字のデータ・曲）。`src/font.mjs` が共通の字（数字・英大文字・記号）。字にない文字を使うとビルドが止まる。
- `src/music.s` — **曲の係（どのゲームも共通。build がつなぐ）**。メロディ（矩形波2）は1フレームずつ音量を下げる（`env_tab`。毎音いっぱいの音量にしない）、ベース（三角波）は線形カウンタで短く切る（`TRI_LIN`）、曲ごとの音色は `song_duty`。曲は `lib.mjs` の `compose()` で小節ごとに「メロディ | 和音 ベースの形」と書く（拍が合わない小節はビルドが止まる）。
- `build.mjs` — `src/<ゲーム>/data.mjs` の `build()`（絵・画面・曲・表）＋ `src/<ゲーム>/game.s` → `roms/<ゲーム>.nes`（NROM 32KB＋CHR 8KB）。`BATTERY`・`HORIZONTAL` で見出しの印。**ROM を変えたら `node retro-8bit/tools/build.mjs` を走らせて、`.nes` もいっしょにコミットする**。`--preview` で `_dev/retro-8bit/<ゲーム>-chr.png`。
- `run.mjs` — 画面なしで動かして PNG（`--press=START@100,A@180`、`--bot` はカエルのよる専用）。
- `dino-sim.mjs` — 恐竜の難しさの見積もり（下）。
- `test-roms.mjs` — **エミュレータ検証用のテスト ROM**（手元だけ。`_dev/retro-8bit/test-roms/`、Git に入れない）を動かして結果を読む。nestest は PC=$C000 の自動の形で $02・$03、blargg のテストは $6000 の結果と $6004 の字、画面にだけ出すものは画面の表の字から PASSED／FAILED。

## カエルのよる（`src/frog-night/`）
- 決まり: 舌は 8 ドット/フレームでのびて最大 148、6 でもどる。のびているあいだは動けない。舌の先の当たりはハエとガが ±8、ホタルは ±5。点は（ハエ 10・ガ 30 の合計）×とった数。ホタルでハートが1つ減り 1.5 秒目を回す。夜は 90 秒、15 秒ごとに虫が増える。のこり 30 秒から空が明るくなる。
- パレット: 背景 0 空と字・1 草とハス（3 が水の色）・2 水・3 月。スプライト 0 カエル・1 舌とハート・2 ハエとガ・3 ホタル。
- ゼロページの番地は `game.s` の頭（`run.mjs` のボットが読む）。

## 恐竜かけっこ牧場 8bit（`src/dino-ranch/`）
- もと: `dino-race/`（恐竜かけっこ牧場。Planck.js の物理で骨格を走らせる）。8 ビットでは物理のかわりに式 `derive`（`data.mjs` と `game.s` の両方。**片方を変えたらもう片方も**）。式と遊びは PLAN.md 5章。
- 見た目: 図鑑の骨格図。紙 $37・インク $07・セピア $17。字は影なし（紙に刷ったように）。題字のかなは 8×8 で描いて 2 倍。骨格は 24×16 の3コマ（脚だけちがう）、転ぶと上下さかさ。
- 場面: タイトル → 牧場（2×2 の囲い。十字キーでえらんで A → RACE／BREED／LET GO）→ 卵（3頭からえらぶ。B で全部逃がす）／かけっこ → 結果 → 牧場。3杯とるとエンディング。
- かけっこ: 100m = 1280 ドット（10m = 128 ドット。背景は 256 ドットでくり返すので、柱が 10m ごとにそろう）。速さは km/h×15（1フレームのドット 8.8）。上の帯（0〜3 行）は 0 番のスプライトの当たりで止め、下を横にずらす（`split_scroll`。当たらないときも止まらないよう数えて抜ける）。32 フレームに1回、つり合いが悪いと転ぶ（45 フレーム）。ゴールしたら、ゆっくり止まる（ほかの子が画面に入ってくる）。
- セーブ（電池の RAM `$6000`）: "DR81"・杯（0〜3。3 = 全部とった）・回（0〜2）・`$6010` から 4 頭 × 8 バイト（つかう・大きさ・脚・筋肉・しっぽ・足の速さ・km/h）。タイトルで **SELECT を押しながら START** で、はじめから。トップの「とりあつかい説明書」の「恐竜かけっこ牧場のセーブを消す」でも消せる（localStorage の `retro8.save.dino-ranch` を消す。確かめのダイアログつき）。
- 難しさ: `node retro-8bit/tools/dino-sim.mjs [たね]` で、いちばん速い2頭をかけ合わせるだけの手で 15〜30 世代（v002）。ライバルの表は `data.mjs` の `RIVAL_KMH`（転ばない体から、決まった並びで選んで `rival_genes` に）。

## ダンゴムシのみち（`src/pillbug-path/`）
- 遊びと決まりは PLAN.md 6章。**決まりは `rules.mjs` の `walk` と `game.s` の `walk_step` の両方（片方を変えたらもう片方も）**。面は `stages.mjs`（16×12 の字。. 土・# 岩・L 葉っぱ・o ひなた・> v < ^ はじめ）。いちばん少ない石の数（BEST の目安）はビルドのとき `solve` で数えて ROM に入れる。
- `node retro-8bit/tools/pillbug-levels.mjs` — 面ごとに いちばん少ない石・解の数・歩く長さ（`--show` で解の道）。解き方は「石は通ったますにしか効かない」ので、通ったますにだけ置いてみる総当たり。`--gen=2 --seed=5` で候補を作る（3つ石は遅い。2つで解ける面に岩を1つ足して、2つでは解けなくなる場所を探すほうが早い。11・12面はこれで作った）。
- `node retro-8bit/tools/pillbug-play.mjs` — ROM を面ごとに解き方どおりに遊ばせ（セーブに面の番号を入れてタイトルから）、通ったますが JS と同じかを見る（v015: 12 面とも同じ）。`--none` で石なし（ひなた・ぐるぐる回る）、`--shot` で食べたあとを `_dev/retro-8bit/pillbug-<面>.png`。
- 画面: 字の段は 0〜3 行と 28 行（案内）、面は 4〜27 行。1 ます = 16×16 = 属性の 1 区画なので、ますごとに色を変えられる（葉っぱ 1・ひなた 2・ほかは 0）。面の画面は面ごとにまるごと ROM に（12 × 1024 バイト）。石を置く・食べるときは `draw_cell` が 2×2 の絵を書きなおす（土は場所で4種、式は data.mjs の `soilAt` と同じ）。
- パレット: 土 $17 に こい粒 $07（字の段の地の色）、岩は灰 $00 で大きく、置く石は明るい灰 $10 で小さく丸く（見分けるため）。ひなたは黄。ダンゴムシは黒・灰。
- 音: 曲（矩形波2・三角波）は庭をのんびり 4 拍子 26 小節、効果音（矩形波1・ノイズ）は 歩く・曲がる（左は低く、右は高く）・置く・とる・だめ・食べる・ひなた。
