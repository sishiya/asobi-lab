## 区割り（RULES 4章）
- 上: 左に機械の名前と、入っているカートリッジの名前。右にめったに使わない道具（音・リセット・全画面）。
- まん中: 画面（ふさがない）。ドットがそろうよう、なるべく整数倍に大きくする。電源を入れる前だけ、まん中に「電源を入れる」（目立たせるのはこれ1つ）。
- 下: PC はキーの案内、スマホ（指の端末）は十字キー（左）・A と B（右、ファミコン型で B が左）・SELECT と START（下のまん中）。スマホの横は画面を広くして、十字キーと AB を左右の下に重ねる。

## しくみ（ファイル）
- `js/ops.js` — 6502 の命令表（番号・名前・アドレスの形・サイクル）。CPU とアセンブラで同じ表を使う。
- `js/cpu.js` — CPU。1命令ずつ進めてサイクルを返す。NMI・IRQ・OAM の DMA で止まるサイクル。10進モードはない（本物も 2A03 にはない）。
- `js/ppu.js` — 絵の係。1行ずつ描く（ドット 256 で行を描き、本物どおり 257 で横のスクロールを t から写す、261 行目の 280 で縦を写す）。背景・8×8/8×16 のスプライト・行に8つまで（あふれの印）・0番の当たり・左8ドットを隠す・白黒。行の途中のスクロールの変化は、行の単位でだけ効く。
- `js/apu.js` — 音。矩形波2（デューティ・エンベロープ・スイープ・長さ）・三角波（線形カウンタ）・ノイズ・フレームカウンタ（4/5 段・IRQ）。DMC は鳴らさない。CPU の1サイクルごとに進め、サンプルの長さぶん平均して、直流を消すハイパスとまるめるローパス。
- `js/cart.js` — iNES のファイルを読む。マッパー 0（NROM）・1（MMC1）・2（UxROM）・3（CNROM）・7（AxROM）。
- `js/nes.js` — 線でつなぐ（CPU から見た番地の地図、コントローラーの読み出し）。`runFrame()` で1フレーム。
- `js/palette.js` — 64色の表（目で合わせて決めた RGB）。
- `js/main.js` — ブラウザの係: 画面の大きさ、音（ScriptProcessor と輪の入れ物。おくれすぎたら捨てる）、キー・指・ゲームパッドを合わせる（押してすぐはなしても1フレームは押したことにする）、タブを離れたら止める。音の ON/OFF は localStorage の `retro8.sound`。

## カエルのよる（ROM の作り方）
- `src/frog-night.s` — ゲームの本体（6502 のアセンブリ）。`src/art.mjs` — ドット絵を文字で（`.` と 1〜3）。
- `tools/asm.mjs` — 自作のアセンブラ（2回読み。`@名前` は直前のラベルの中だけ、`[ ]` が式のかっこ、`<` `>` で下・上のバイト）。
- `tools/build.mjs` — 絵 → CHR、画面（タイトル・あそぶ画面）・曲・波の表・字をデータにして、アセンブリの前後に足し、`roms/frog-night.nes`（NROM 32KB＋CHR 8KB）を書く。**ROM を変えたら `node retro-8bit/tools/build.mjs` を走らせて、`.nes` もいっしょにコミットする**（ページは `.nes` を読むだけ）。`--preview` で絵の一覧 `_dev/retro-8bit/chr.png`。
- ゼロページの番地は `frog-night.s` の頭。確かめの道具（`run.mjs` のボット）はその番地を読むので、変えたら合わせる。
- 画面の色: 背景のパレットは 0 空と字・1 草とハス（3 が水の色）・2 水・3 月。スプライトは 0 カエル・1 舌とハート・2 ハエとガ・3 ホタル。属性は 16×16 ごとなので、ハスの列（24〜25行）は草のパレットで、水の色を 3 に入れてつないだ。
- 曲: 矩形波2がメロディ、三角波がベース。`build.mjs` の `melody`・`bass` に音の名前と長さ（フレーム）で書く。効果音は矩形波1とノイズ。
- 決まり: 舌は 8 ドット/フレームでのびて最大 148、6 でもどる。のびているあいだは動けない。舌の先の当たりはハエとガが ±8、ホタルは ±5（かすっただけでは食べない）。点は（ハエ 10・ガ 30 の合計）×とった数。ホタルを食べるとハートが1つ減り、1.5 秒目を回す。夜は 90 秒、15 秒ごとに虫が増え、ホタルの割合と速さが上がる。のこり 30 秒から空が明るくなる。

## 確かめのしかた
1. `node retro-8bit/tools/test-cpu.mjs` — CPU とアセンブラ（足し算・引き算のフラグ、(zp),y、JSR/RTS、シフト、16ビット、分かれ道）。「ぜんぶ正しい」なら OK。
2. `node retro-8bit/tools/build.mjs` — ROM を作る。
3. `node retro-8bit/tools/run.mjs --bot --press=START@100 --frames=2000,5520` — 画面なしで遊ばせて、点・ハート・時間を出し、絵を `_dev/retro-8bit/run-<フレーム>.png` に。ボットはホタルの通り道をよけるので、ふつうは朝まで行く（v001: 1290点・ハート3つ）。よけないとホタルで終わる。
4. ページ: `node tools/playwright/shots.mjs retro-8bit` で4つの幅。ブラウザで電源 → Enter → ←→ と X。音はボリュームゼロで（`localStorage.retro8.sound = '0'`）。
