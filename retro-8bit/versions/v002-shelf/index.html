あそびラボ

8ビット互換機

あそびラボが一から書いた、ブラウザで動く8ビットのゲーム機です。入っているのは、この機械のために作ったオリジナルのソフトだけ。

自分のファイルを開く

iNES 形式（.nes）のファイルを、この機械で動かせます。ファイルはこの端末の中だけで読み、どこにも送りません。自分で作ったものや、配ってよいと決められたものなど、権利を持っているファイルだけを開いてください。

この機械について

CPU（6502）・絵・音（矩形波2・三角波・ノイズ）・カートリッジのしくみ（マッパー 0・1・2・3・7）を、あそびラボが JavaScript で書きました。メーカーのプログラムやデータは入っていません。棚のソフトは、自作のアセンブラで作ったものです。ROM のファイルは自由にダウンロードできます（ゲームの中身は CC BY-NC 4.0）。

電池つきのカートリッジ（恐竜かけっこ牧場 8bit）のセーブは、このブラウザの中に残ります。
