# ときの地層（仮） 企画書

2026-10-15。ユーザーの案「上下が時間、左右が空間の世界」と「家出した原始人」（`../IDEAS.md`）から作る企画。フォルダ名は `time-strata`（仮）。**まだ作っていない（企画だけ）。**

ユーザーからの注文（2026-10-15）:
- 1マスが何年かは、原初から未来までの時間軸を決め、時代ごとの出来事を置き、遊びに結びつく物を選び、それがつながるように逆算して決める。
- 横スクロールもする。旅をしても、なにか理由をつけて元の場所に戻せばよい（例: 未来の都市からロケットで逃げる → 上がる＝未来へ進むのでロケットもすぐ朽ちる → 傾いて元の場所へ落ちる → 時代が一気に戻る）。
- 各時代の経験は Claude がプロットを考え、ユーザーが口を出す。

## ひとことで
家出した原始人が、土を掘って過去へ、土を積んで未来へ行く。横にも旅をして、文明が育って滅びるまでを見る。最後は落ちて元の時代に戻り、家族と仲直りする。

## 1. しくみの芯

### 高さ＝年
- 自分の高さ y がそのまま年になる。画面に出るのは、**自分のいる年の世界**だけ（上のほうに「紀元前 9800 年」などの年の文字）。
- 上へ動くと、まわりの景色ごと未来へ変わる。その年のその場所の地面の高さを h(x, 年) とする。自分が地面より上にいれば落ち、下にいれば土の中。
- 掘る＝足もとの土を1マス取って袋に入れる（下へ＝過去へ）。積む＝袋の土を足もとに置いて乗る（上へ＝未来へ）。積んだ物はその場所・その年に残る。

### 1つの数で地形の性格が決まる: g（地面のついてくる量）
**g＝自分が1マス上がるあいだに、地面が何マス上がるか**。1マスの年数を s、その場所で地面が上がる速さを v とすると、g ＝ s × v。

| g | 帯の名前（仮） | 掘ると | 積むと | どこに置くか |
|---|---|---|---|---|
| 0〜1 | ふつうの帯 | 1マスずつ下へ | 1マスずつ上へ。地面はついてこない | 丘・岩場・ふつうの土地 |
| 1 より大 | **早送りの帯** | 地面が自分より速く下がるので、**穴の底から外に出てしまう**（ユーザーの言う不思議な感覚）。落ちつづけて、g が 1 より小さい年まで一気に過去へ | 地面が追いこしてきて押し上げられ、一気に未来へ | 川の氾濫原・火山灰・ゴミの埋め立て地・育つビル |
| 0 より小 | **もどりの帯** | 過去ほど地面が高いので、掘っても埋まる（下へ行きにくい） | 未来ほど地面が低いので、積んだ足場から降りると落ちる | 川に削られる谷・海に削られる崖・朽ちていくビル |

- 立っていられるのは、自分の高さと地面の高さが同じになる所だけ。早送りの帯ではそこから少しずれると、上か下へすべり出す。
- **本物のしくみ**: 川の氾濫原・三角州は速く積もり、丘の上や岩場は遅い。谷は削られる。都市の地面も人の手で上がる（東京の下町の盛り土、埋め立て地、ローマやトロイの「町の上に町」）。考古学でも、ゴミの層は時代を知る手がかり。

## 2. 時間軸（原初〜未来）と、遊びに使う出来事

0 マスが家（紀元前1万年＝約1万2千年前。最終氷期の終わり。縄文時代のはじめのころ）。上が＋、下が−。

### 下（過去へ。寄り道と、取りに行く物）

| 約300万〜200万年前 | アウストラロピテクス、最初の石器 | 遠いご先祖に会う。石器の作り方を見る |
| 6600万年前 | 小惑星の衝突。境目に薄いイリジウムの層 | 1マスだけの光る層。ここより下は恐竜 |
| 約2億〜6600万年前 | 恐竜の時代 | **恐竜に追われる**（ティラノサウルス・ヴェロキラプトル）。化石を見つけると図鑑に |
| 約3億年前 | 石炭紀。巨大なシダの森、大きなトンボ | **石炭の層**（森が埋もれてできた）。あとでけむりの町に持っていく |

| 約40億年前 | 海ができ、熱水のまわりで生命が生まれたらしい | ふしぎな泡。図鑑の最後のページ |

| 年 | 出来事 | 遊びにすること |
|---|---|---|
| 紀元前1万年 | 家。ほら穴と焚き火 | はじまり |
| 紀元前8000〜5000年 | 農耕・土器 | 土をこねて焼く→**土器の袋**（運べる土がふえる） |
| 紀元前3000〜1000年 | 川の文明。れんが、文字、ピラミッド（紀元前2500年ごろ） | 積む物が**れんが**に。川の氾濫で土がどっと積もる（早送りの帯）。**年の文字が絵文字から文字になる** |
| 紀元前1000〜西暦1500年 | 鉄の道具、城、紙 | **鉄のつるはし**（固い岩・石だたみが掘れる）。城壁は時代を変えてよける |

| 1900〜2026年 | 電気・プラスチック・アスファルト。2026年＝「きょう」 | アスファルトは掘れない。**土がないのでゴミを積む**（ちょっぴり風刺） |
| 2026〜2200年 | 近未来 | **育つビル**（早送りの帯）。乗ると押し上げられて一気に未来へ |
| 2200〜2500年 | 空中都市 | 下の地面がなくなり、浮かぶ足場だけ |
| 2500〜3000年 | 遠くで戦争。都市が朽ちて倒れる | 遠くの光と音だけで見せる（だれかが傷つく場面は描かない）。足場が崩れる（もどりの帯） |
| 3000年〜 | ロケットで逃げる | 上がる＝未来へ進むので、ロケットがみるみる錆びる→落ちる |

## 3. 1マスは何年か（逆算）

- 合わせて下に100マス、上に約130マス、全部で約230マス（画面の高さを17マスとすると14画面ぶん）。
- **わかったこと**: 遊びから逆算すると、どの区間も「1マス ≒ きょう（2026年）からの年数の 4〜13%（だいたい 7%）」になった。つまり**目盛りは、きょうを中心にした対数の目盛りにほぼそろう**。きょうに近いほど1マスが短く、遠いほど長い。式にすると、1マスの年数 ≒ 0.07 × |年 − 2026|（きょうの近くだけ下限 5 年）。区間ごとにばらばらに決めるより、この1本の式にするほうが作りやすく、つなぎ目もなめらか。
- 目盛りが大きく変わる所（2万年前と300万年前のあいだなど）は、地層の**不整合**（記録がとぎれた面。本物の地質の言葉）として波線で描く。
- 早送りの帯の g は、地面の上がる速さ v を場所ごとに決めて、上の s とかけ合わせて g が 1 を越えるようにする（川の氾濫原・ゴミの埋め立て地・育つビル）。

## 4. 横の旅

- 左から右へ: **家の丘（ほら穴）** → **海峡**（ふだんは海。氷期だけ陸橋） → **大きな川の平野**（文明が育つ所。のちの大都市） → 右のはしは山。
- 横の邪魔は「その時代にだけある」物にして、**時代を変えてよける**のが基本のパズル:
  - 海 → 氷期まで掘り下げて陸橋をわたり、向こうで積んで戻る。
  - 川 → 川の流れが変わる前（または後）の時代へ。
  - 城壁・高速道路 → まだない時代か、もう崩れた時代へ。
  - 山 → 持ち上がる前の時代へ（山はゆっくり高くなる）。
- 帰り道: ロケットは左へ傾いて家の丘へ落ちる（ユーザーの案）。家のほら穴は未来でも**史跡として残されていて、上に何も建たない**。だから、そこでは落ちる途中の年に地面がなく、紀元前1万年の地面まで止まらずに落ちる。落ちる途中で、見てきた時代が逆回しで流れる（ビルが縮む → ゴミが消える → 城 → ピラミッド → 麦畑 → 家）。

## 5. プロット（各時代の経験）

物語の糸は**火**。原始人は焚き火の番をしくじって家族とけんかした。旅のあいだ、人の火が形を変えるのを見る（土器を焼く火 → 鉄を打つ火 → 蒸気の火 → 電気 → 戦争の光 → ロケットの火）。

0. **家出（紀元前1万年・家）** — 焚き火の番の日、見とれていたら火が消えた。叱られて、ほら穴を飛び出す。歩く・土を掘る・運ぶ・積むを覚える。
1. **海の向こう（2万年前へ）** — 向こう岸に煙が見えるが、海がある。川べり（早送りの帯）で掘ると、なぜか穴の底から外へ出て、氷期の寒い浜に立っている。海が干上がった陸橋をマンモスの群れといっしょにわたる。
2. **麦の村（紀元前7000年ごろ）** — 向こう岸で積んで上がると、人が麦を育てている。土をこねて土器を焼く手伝い → 土器の袋（運べる量がふえる）。火で土が固くなるのを見る。
3. **れんがの都（紀元前2500年ごろ）** — 川がひろがり、都ができている。れんがで階段を積んでピラミッドのてっぺんへ（大きく上がる最初の山場）。年の文字が絵文字から読める文字に変わる。川の氾濫で、いっきに未来へ押し上げられる。
4. **鉄と城（1000年ごろ）** — 鍛冶屋で鉄のつるはしをもらうが、炉を燃やす鉄の材料が足りない → **25億年前の鉄の層まで掘りに行く**（深い寄り道。途中に恐竜の層）。城壁は、まだない時代まで下がってくぐる。
5. **けむりの町（1850年ごろ）** — 蒸気機関が止まりかけている。炭鉱のエレベーターで3億年前の石炭の森へ。帰りにエレベーターが恐竜の層で止まり、追われて逃げる（ここがいちばんの恐竜の場面）。人の暮らしが、遠い昔の森を燃やして動いていると知る。
6. **ゴミの山（1950〜2026年）** — 地面はアスファルト。土がないので、捨てられたゴミを拾って積む。ゴミも年代ごとに変わる（びん → プラスチック → 電話）。2026年に「きょう」の札。
7. **育つビル（2100年ごろ）** — ビルがどんどん育ち、乗っていると一気に押し上げられる（早送りの帯の山場）。
8. **空中都市（2300年ごろ）** — 地面がなくなる。浮かぶ足場を渡る。にぎやかで便利だが、だれも土にさわらない。ほら穴の焚き火を思い出す。
9. **遠くの光（2600年ごろ）** — 遠くで戦争の光が見える。足場が朽ちていく（もどりの帯）。ふり返ると、都市が少しずつ倒れていく。
10. **ロケット（3000年ごろ）** — 古いロケットに乗って逃げる。上がるほど未来に進むので、みるみる錆びてばらばらになる。傾いて、家の丘のほうへ落ちる。
11. **落ちる** — 見てきた時代が逆回しで流れる。家のほら穴は未来で史跡になっていて、壁には**手形の絵**がある。
12. **帰る（紀元前1万年）** — ほら穴の前に落ちる。旅で覚えた火のおこし方で焚き火をつけなおし、家族と仲直り。みんなで壁に手形をつける。それがさっき未来で見た手形だった。ちゃんちゃん。

- 下への寄り道（図鑑・化石・石器のご先祖・カンブリアの海など）は、本筋とは別に好きなだけ。いちばん下はマグマで、焼けて戻される。
- 失敗しても、いちばん近い焚き火のしるしからやり直す（焚き火＝セーブの場所。これも火の糸）。

## 6. 見た目と操作
- 横から見た2次元の操作。奥行きは背景を何枚も重ねて出す（遠くの山・町・空）。見た目のチープさに気をつける（質感・光・奥行きを最初から）。
- 年の文字は画面の上。時代の名前も出す（「最終氷期」「産業革命」など）。
- 地層の断面を見せる時間図（左右＝場所、上下＝年）の小さな地図を画面の隅に。

## 7. 気をつけること
- 戦争・焼け死ぬ・恐竜に襲われるは、やわらかく描く（遠くの光、画面が赤くなって焚き火へ戻される、など）。人が傷つく場面は描かない。
- 原始人や昔の人を笑い者にしない。風刺はゴミの場面くらいの軽さで。
- 年代は本物の値を使い、画面の「本物の話」で出典を確かめてから出す（parasite-pilot と同じ）。

## 8. 段階（案）
- **段階A**: しくみの試作。1つの場所（横は狭く）で、高さ＝年、g の3つの帯、掘る・積む、年の文字。区間は家のまわり（氷期〜川の文明）だけ。「掘っているのに外に出る」が気持ちよいか確かめる。
- **段階B**: 横の旅（海峡の陸橋）、上の本筋（〜2026年）、焚き火のセーブ。
- **段階C**: 未来（育つビル〜ロケット）、落ちる逆回し、エンディング。下への寄り道と図鑑。

## 9. 決まったこと・決めること
- 2026-10-15 ユーザー「よい」: 家は紀元前1万年、けんかのきっかけは焚き火の番、で進める。
- 2026-10-15 ユーザー「いったん寄り道も入れてみよう」: 鉄（25億年前）と石炭（3億年前）を取りに深く潜る2回の寄り道を、本筋に入れる。
- 題名はまだ。Claude の案（2026-10-15）:
  1. **掘れば昔、積めば未来** — 遊び方がそのまま題名。←おすすめ
  2. **四十六億年の家出** — 家出の大げささがおかしい。物語の題名らしい。
  3. **ときの地層** — いまの仮題。しずかで図鑑ふう。
  4. **ほって つんで ときの旅** — ひらがなで、子どもにも読める。
  5. **原始人、時をのぼる** — だれが何をするかがすぐ分かる。
  6. **焚き火にかえる** — 物語の糸（火）と、元の時代へ帰る結末。遊んだあとで意味が分かる。
  7. **したは昔、うえは未来** — 世界のルールを一行で。
  8. **ちゃんちゃん紀元前** — 終わりの一言から。軽くて覚えやすい。
  - 英語の題名の案: *Dig to the Past, Stack to the Future* ／ *Strata Runaway* ／ *A 4.6-Billion-Year Runaway*
