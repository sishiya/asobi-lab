# 32ビット互換機 — 見た目の目標（ムネエソの腹あかり）

RULES.md 10章の手順。採点はアートディレクター役が、原寸（320×240 を 2 倍で保存）の絵と、この表だけで行う。

## 方向
- 中深層（200〜700m）のたそがれの海。暗い青のグラデーションとディザの粒は残す。ローポリのカクカクは味として残し、**一色の多角形のふちを見せない**（グーローと加算の重ねでぼかす）。
- 本物の手本（手本の監修）: ムネエソは鏡のような銀の横腹・手斧の形・腹の発光器の列・上を向いた目。捕食者はデメニギス科（すき通った頭・上を向いた筒の目）。魚の目は自分では光らない。

## 数の目標（2026-10-25 アートディレクターの採点 46点から）
| もの | 目標 |
|---|---|
| ムネエソの形 | 尾をのぞく高さ ≒ 長さ × 0.9、腹は斧の刃のようにとがったキール、尾のつけねは高さの 1/5、目は頭の 1/4 で上向き |
| ムネエソのぬり | 扇でなく横の帯 3〜4 段のグーロー: 背 #1c2a3a → 横腹の銀 #c8d4e0 → 腹 #7088a0 |
| 発光器 | 腹のふちに 10〜12 こ。消えていてもくぼみ #23384a、光ると #7fe8ff とにじみ |
| 見上げた光の円 | 同心のだ円 4 枚（100/80/55/30%）を加算で重ね、ふちをぼかす。夜は約 0.8 倍で寒い青 #24365a |
| 見上げた影 | 下から見た魚の形（腹の点の列つき）。合っていても点がうっすら残る |
| 捕食者 | 体は #0e0c10 → 背のつや #2a2630 のグーロー、頭はすき通ったドーム（加算 #3a5a60 の 25%）、上向きの目は緑の反射 #6fe08a＋淡いにじみ |
| 見上げた画面の目 | ボタンに見えない（塗りのにじみ。合っていると細く閉じ、疑いで大きく・だいだいへ）。案内の字とはなす |
| 光の筋 | 幅 20〜90px で 6 本、ふちは 0・まん中だけうすく加算、±4px でゆれる、600m より深いと 0 |
| 水の色（昼） | 150m #1f5f8f・480m #0b2a52・700m #050c1e。夜はさらに暗く |
| マリンスノー | 2 層の視差（奥はゆっくり・暗く）、合わせて 40 粒 |

## 採点の記録
- 1回目（v003）: 46点。魚がフグに見える・円がかたい・捕食者が黒い板・光の筋が平行な帯。
- 3回目: 78点。見上げた画面はほぼ完成、おわりの腹をともした魚がいちばんきれいな絵。そのあと直したこと: 命の印を数からはなす・タイトルの魚の目にひとみ（並べ表の同じ箱では、あとから入れた面が先に描かれる → ひとみを輪より先に入れる）・消えた発光器は #4a6078 のくぼみだけ・背を暗く・おわりの印を青緑に・見開いた目のひとみを魚のほうへ・光の模様を少し強く。残り: 題の字。
