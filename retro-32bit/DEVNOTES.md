## しくみ
- `js/cpu.js` — MIPS R3000A。全部の命令（COP2＝GTE は段階B）。**遅延スロット**（`next` を持ち、とぶ命令は `next` を書きかえる）と**ロードの遅れ**（`ldR/ldV` を1命令あとに書く。その命令が同じレジスタに書いたら取り消し。lwl/lwr は読みかけの値に重ねる）。例外（あふれ・番地のずれ・syscall・break・知らない命令）と割りこみ（SR の IEc・IM と CAUSE の 10 番）。かけ算の上の 32 ビットは `umulHi`（16 ビットずつ）。
- `js/psx.js` — 本体。メモリの地図（RAM 2MB・スクラッチパッド・I/O）、割りこみ（I_STAT・I_MASK）、DMA（2＝GPU のブロックとつながったリスト、6＝並べ表をつくる。すぐ終わる）、タイマー（ざっくり）、`runFrame()`（263 行×1行 2152 サイクル、1命令 2 サイクル。240 行目で垂直帰線の割りこみ）、`display()`（15 ビットと 24 ビット）。
  - **BIOS を通らない**（PLAN.md 0章）: `loadExe()` が実行ファイルの本体を RAM に置き、pc・gp・sp を入れて動かす。例外の入り口 80000080 には「EPC へ戻るだけ」の4語を置く。ソフトが A0/B0/C0 を呼んだら `bios()` が JS で受けて ra へ戻す（いまは文字出しだけ `tty` にためる）。段階D で自前の BIOS に。
- `js/gpu.js` ＋ `js/raster.js` — GPU。VRAM 1024×512×16 ビット。GP0（三角形・四角・線・塗りつぶし・VRAM への転送／から／の中のコピー・描き方の設定 E1〜E6）、GP1（リセット・表示の場所と形・DMA の向き）、GPUSTAT。塗りは辺の式で、上と左の辺だけ入れる（四角の2つの三角形のつなぎ目を2回塗らない）。グーロー・テクスチャ（4/8/15 ビット・CLUT・テクスチャの窓・色をかける）・半透明4種・マスク・ディザ（4×4）。テクスチャは画面の上でまっすぐ補間（本物の「ゆがみ」）。
- `js/gte.js` — GTE（COP2）。データ・制御のレジスタ（読むときの符号の癖・IRGB/ORGB・LZCS/LZCR・SXYP で FIFO を押す）、命令 RTPS/RTPT・NCLIP・AVSZ3/4・MVMVA・OP・SQR・GPF/GPL・NCS/NCT・NCCS/NCCT・NCDS/NCDT・CC・CDP・DPCS/DPCT・DCPL・INTPL。とちゅうの和は 44 ビットであふれを見て FLAG に印。投げるときの割り算は本物と同じ表（UNR）＋ニュートン法2回（ぴったりの割り算から 3 までずれる。本物も同じ）。
- `js/pad.js` — コントローラーの口（SIO0）と十字キーのパッド（01→42→00→ボタン2バイト、押すと 0。1バイトごとの ACK で割りこみ 7）。ボタンの名前はあそびラボで決めた **A＝右・B＝下・X＝左・Y＝上**、L・R、START・SELECT（他社の記号は使わない）。口 2 には何もつながっていない。
- `js/input.js` — キー（←↑↓→・X＝A・Z＝B・A＝X・S＝Y・Q＝L・W＝R・Enter・Shift）・ゲームパッド（標準の並び）・指のパッド（`bindTouch`。指をすべらせると押すボタンも替わる）を口 1 にまとめる。キーの割り当ての変更は段階E。
- `js/main.js` — ページ。ソフトの札・自分のファイルを開く（この端末の中だけで読む）・一時停止・はじめから。60 こま／秒で回し、表示の形（320×240 など）の絵を 640×480 の canvas にドットのまま大きく。
- `tools/asm.mjs` — MIPS のアセンブラ（2回読み）。レジスタは `$t0`・`t0`・`$8`、数は `0x`。`%hi()`・`%lo()`、疑似命令（li・la・move・b・beqz…）。**遅延スロットは並べかえない**（自分で nop）。`makeExe()` で実行ファイルの形（頭 2048 バイト）に。
- `tools/build.mjs` — `src/<ソフト>/main.s`（＋`data.mjs` の `gen()` が作る表）→ `discs/<ソフト>.exe`。

## ソフト
- `src/spin-tri/` — 「回る三角形」（段階A の確かめ）。グーローの背景（ディザ）→ 軌道の円（線をつなぐ）→ 加算の半透明でまわる 8 つの四角（DMA のつながったリスト）→ まん中のグーローの三角形。VRAM の上と下を交互に描くダブルバッファ。sin の表は `data.mjs`。

- `src/glow-belly/` — **「ムネエソの腹あかり」（仮。段階B のオリジナル。PLAN.md 5章）**。`main.s`＝はじめ・1こまの流れ・決まり（時刻・浮く沈む・腹の光・エネルギー・捕食者・プランクトン）、`draw.s`＝水・光の筋・マリンスノー・プランクトン・捕食者・見上げた画面・字・HUD、`fish.s`＝行列（GTE の MVMVA で 3×3 のかけ算）・ムネエソを GTE で投げて並べ表へ・発光器・変数の場所、`data.mjs`＝表と形（sin・空の明るさの段・腹の光の段ごとのエネルギー・水の色・プランクトンの深さ・ムネエソ 三角形 36・捕食者の形・5×7 の字）。build は `main.s` ＋ ほかの .s（名前の順）＋ `data.mjs`（`tools/lib.mjs` の `buildSoft`）。
  - **明るさは段（対数）**: 24 段で 10 倍。上からの光 I = 空の段（昼 300・夜 158）− 深さ × 4/3（澄んだ外洋で 72m ごとに 1/10。手本の監修）。深さの 1 = 4m、魚は 100〜700m。腹の光 L も段（0〜255）。エネルギーの減りは明るさそのものに比例（`cost` の表）＝浅い昼は合わせるとすぐ切れる。
  - 見上げた画面は「捕食者の目は暗さに慣れている」として、上の光の円をいつも同じ明るさ（`V_BASE`＝昼の青〜夜の寒い青）で描き、魚の影を V_BASE × (16 + (L − I)/2)/16 の色にする（差だけを見せる。夜でも読める）。カメラは真下でなく 67°（`LOOKUP` = 48）のななめ下から＝魚の形と腹の点の列が見える。
  - 見た目の目標は `ART.md`（アートディレクター役の採点の数値）。魚は 7 本の輪切り × 4 段の帯をグーローでぬる（頂点の色 × 面の光の強さ。光の強さは GTE の MVMVA で内積、色のかけ算は CPU の `shade`）。光の円・捕食者の頭と目・見上げた目は `blob`（ふちが 0 の加算のグーローの扇）でぼかす。
  - 捕食者は見る間だけ疑いがふえる: はずれ = |L − I| が TOL（12 段 ≒ 3 倍）をこえた分の 1/32 ＋ 1。160 で見つかる。はじめの1回は練習（上限の手前で止まる）。
- `src/cube/` — 「光るキューブ」（段階B の確かめ）。GTE の RTPT → NCLIP（裏を捨てる）→ RTPS（4つ目の点）→ AVSZ4 → 並べ表（DMA 6 で空にして、奥ほど大きい番号）、光は MVMVA（RT×面の向き）→ MVMVA（LLM×IR、lm）→ CC。RGBC の上のバイトに GPU の命令（0x28）を入れておくと、色の FIFO からそのまま荷物に書ける。十字キーで回す。GTE の画面のずらし（OFX/OFY）は 0 にして、まん中へは GPU の E5 でずらす（両方だと二重になる）。

## 区割り（RULES.md 4章）
- 上＝名前（右にことば JP/EN）、まん中＝画面（4:3 の黒い枠）、下＝ソフトの札（左。いま動いているものだけ赤い枠）と操作（右: 開く・一時停止・はじめから）とキーの案内（PC）。
- スマホのたて: 画面の下に指のパッド（左手＝L・十字キー・SELECT、右手＝R・ひし形の Y/X/A/B・START）、その下に札と操作。スマホの横: 画面をまん中に、左右の手にパッド、上の帯に開く・一時停止・はじめから（札は隠す）。

## わかったこと
- アセンブラの範囲の確かめ（16 ビットに入らない値）で、自分のソフトのまちがい（`andi` に 0x10000）がすぐ見つかった。ソフトを書くときは `srl`/`sll` で。
- 光るキューブで2回つまずいたのは、どちらもソフトの側: ① GTE と GPU の両方で画面のまん中へずらして二重 ② `lbu` のすぐあとでその値を使った（ロードの遅れで前の値が見える＝エミュレータは本物どおり）。アセンブリを書くときは、ロードのつぎの1命令を必ず見る。
- Claude のプレビューの窓は、隠れていると rAF が 1 秒 8 回ほどに落ちる（速さを測るときは `runFrame()` を直接回す。ブラウザで 1こま 4.3ms）。
