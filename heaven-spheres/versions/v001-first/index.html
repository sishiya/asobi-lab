天をまわす箱庭（試作）

天動説の世界です。大地は世界の真ん中で動かず、まわりを月・太陽・星の天球がめぐっています。きみは神の手で天球を回し、大地の形を変えられます。

遊びかた

  • 天球の帯（目盛りのついた輪）をつかんで回す。はなすと勢いが残り、ゆっくりふつうの速さにもどる。キーボードは ←→ で月、Shift＋←→ で太陽。
  • 「盛る」「削る」を選んで大地をなぞる。削った土は土ぶくろへ入り、盛るとへる。浜をくぼませると、潮が引いても水が残る「潮だまり」になる。
  • ホイール・ピンチ・＋－で寄る。「見る」のときは大地をドラッグして動かせる。スペースで止める。

この世界のきまり（天動説）

  • 元素は自分の場所へ帰る。地がいちばん下、その上に水、空気、火。だから水は大地をおおって海になる。
  • 月と太陽は水を引きよせる。真下と反対がわがふくらむ（潮）。月と太陽が重なるか反対にあると大潮。
  • 天球を急に回すと、海が取り残されて揺れもどる。回しすぎると津波になって、生き物が流される。

本当は

潮の満ち引きは月と太陽の引く力（重力）で起きます。ただし動いているのは天球ではなく、地球のほうです（太陽のまわりを回り、自分も回る）。水が地球をおおうのも、元素の性質ではなく重力のためです。潮の満ち引きでできる浜や潮だまりが、生き物が陸へ上がるのを助けたという説があります。この試作では津波を「天球を回しすぎたせい」にしていますが、本当の津波はおもに海の底の地震などで起きます。
