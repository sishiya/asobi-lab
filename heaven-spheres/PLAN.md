# 天をまわす箱庭（仮） 企画書

2026-10-12。ユーザーの案「ちいさな惑星の箱庭」（`../IDEAS.md`）の**天動説版**。ユーザーの指示「天動説版で PLAN.md を作って」。フォルダ名 `heaven-spheres`。題名は仮。

## 題材とねらい
- ロコロコのような「キャラを直接動かさず、世界を動かす」遊び。ただし借りるのは操作の型だけ（`../IDEAS.md` の線引き: 分かれる・くっつく丸いキャラ、実を食べて大きくなる、歌う顔、平たい色面の絵柄は使わない）。
- **天動説を本気のルールにした箱庭**。大地は真ん中で動かず、まわりの天球（月・太陽・星）を神の手で回す。昔の人が信じた物理（アリストテレスの元素、プトレマイオスの天球と周転円、「月が潮を支配する」）をゲームの理屈にするので、**楽しければ多少の嘘も OK**（ユーザー）。
- 嘘は嘘として遊び、図鑑とエンディングで「本当は」の答え合わせ（`black-hole` の「映画版／本当の見え方」と同じ考え方）。
- 絵もプログラムも独特の世界観に。**古い天文図の銅版画ふう**。

## ひとことで
小さな大地のまわりの天球を、渾天儀のハンドルで回す。月の天球が潮を満ち引きさせ、太陽の天球が昼と夜を運ぶ。回しすぎれば津波。指で地をもり上げて島を分け、橋をかけて種を出会わせる。生き物は世代をかさねて、きみが作った世界に合わせて変わっていく。

## 世界のルール（天動説の物理）
| しくみ | ゲームの中のルール（天動説） | 本当は（図鑑で） |
|---|---|---|
| 海ができる | 元素は自分の場所へ帰る。地がいちばん下（真ん中）、その上に水、空気、いちばん外に火（月の天球の内がわ） | 重力が物を中心へ引く |
| 大地 | 世界の真ん中で動かない | 太陽のまわりを回り、自分も回る |
| 昼と夜 | 太陽の天球が大地のまわりを回る | 地球が自転する |
| 潮の満ち引き | 月が水を引きよせる（月の真下と反対がわがふくらむ）。月の天球を回すと、ふくらみが大地の上を動く | 月と太陽の重力の差。ふくらみの下を地球が回る |
| 津波 | 天球を急に回す・止めると、水が取り残されて揺れもどる | （津波の本当の原因は地震などの海底の動き。ここはゲームの嘘として図鑑で言う） |
| 大潮・小潮 | 月と太陽の天球が重なる（または反対）と潮が大きい | 本当にそう（月・太陽・地球が一直線） |
| 周転円 | 月の天球に小さな円を足すと、月が近づく日・遠ざかる日ができ、潮の大きさが変わる | 月の軌道はだ円。近いときの潮は少し大きい |

- 「月が潮を支配する」は古代から知られていた（嘘ではない）。原因の説明だけがちがう。
- 天動説の嘘を足すときの約束: **昔の誰かが本当にそう考えた**ものを優先し、純粋な作りごとは図鑑で「ゲームの作りごと」と書く。

## 遊びのしくみ
- **画面**: 大地の輪切り（2D）。真ん中に大地と海、まわりに同心円の天球（月・太陽・恒星）。外側に渾天儀のハンドル。
- **操作（シンプルに）**:
  - ハンドル（またはそれぞれの天球）をつかんで回す。左右の矢印キー・マウスのドラッグ・指。回す速さは手の速さ。
  - 地の上をなぞると、もり上げる／くぼめる（地の量は一定で、どこかを盛ればどこかが減る）。神の力には回数か「力」のゲージの限り。
  - 時間の早送り。
- **水**: 輪の上の浅い水として計算する（N≈360 区画の浅水方程式）。潮も津波も、この計算から自然に出る。
- **生き物**: 数種類から始める。個体ごとに遺伝子（体の大きさ・水と陸のどちらが好きか・昼と夜のどちらに動くか・波への強さ・食べもの）。食べて、子を残し、世代がかわる。
  - 潮だまりで水と陸を行き来するうちに、陸に上がるものが出てくる（潮だまり説）。
  - 海や山で隔てると、別々に変わっていき、やがて別の種になる。
  - 地の橋でつなぐと、出会って混ざる（近い種）か、競いあう（遠い種）。
  - 津波・干上がりが選ぶ力になる（`../resistance/` の「生き残ったものの性質が増える」）。
  - 子を残すしくみは `../dino-race/` のかけ合わせ、世代の進み方は `../../アプリ開発/ga-creatures/` が下じき。
- **ゲームの目標（あそびラボなので、ゲームの4条件を満たす）**: 「創世の日」ごとのお題。
  1. 海の生き物を、陸で暮らせる生き物にする
  2. 陸の生き物を、2つの種に分ける
  3. 潮が引くと現れる道で、ちがう種を出会わせる
  4. 周転円で月を近づけ、いちばん大きな潮を起こす
  5. 4つの種がいっしょに暮らす世界にする（v002 で決めた。くわしくは `js/quests.js`）
  - ★1〜3 は、そのお題を始めてからクリアまでの日数で（v002）。全滅したら最初から（v002。「その日のやり直し」は段階Cでセーブと一緒に）。

## 絵と音
- 羊皮紙色の地に、黒〜茶のインクの線とハッチング。天球には星座の記号、太陽と月に顔の版画ふう（こわくしない）。生き物も図鑑の版画ふうの線画（`dino-race` の骨格図ふうと同じ「昔の図版」の系統）。
- 色は少なく。海は藍のハッチング、津波は線の乱れで見せる。
- 文字の飾りは昔の天文書ふう（ラテン語ふうの飾り文字は使ってもよいが、読む文字は日本語）。外部フォントは使うなら Google Fonts の、だれが見ても大丈夫なものだけ。
- 音: WebAudio で作る（音ファイルなし）。天球が回る低いうなり（天球の音楽）、潮の音、津波の鳴り。

## 下敷きになる話（図鑑・エンディングに出す。**作るときにすべて出どころを確かめる**）
- アリストテレス『天体論』: 4元素と「自然な場所」、天のエーテル、同心の天球。
- プトレマイオス『アルマゲスト』: 周転円と導円で惑星の動きを説明。
- 潮と月: 古代（ピュテアス、ポセイドニオスなど）から月と潮の関係は知られていた。
- ガリレオは潮を「地球が動いている証拠」と考え、月が原因というケプラーの考えを退けた（実際はケプラーの方向が近かった）。皮肉な話として図鑑に。
- ニュートン『プリンキピア』: 潮を月と太陽の重力で説明。
- 潮だまり説: 潮の満ち引きが生き物の上陸を助けたという説（Balbus 2014 など。要確認）。
- 隔離による種分化、アメリカ大陸間大交差（陸橋で種が混ざり競った）。

## 段階
- **段階A（v001・試作）**: 遊びの芯だけ。2D の輪切り、浅水の海、月と太陽の天球を回す、潮と津波、地をなぞって盛る／削る、生き物1〜2種（遺伝子は2〜3個）。お題は1つ（「陸へ上げる」）。絵は線画の最低限。保管庫に掲載。
  - 確かめたいこと: 天球を回すのが気持ちいいか、潮と津波が見ていて楽しいか、生き物への影響が目で分かるか。
- **段階B（v002・遊びの広がり）**: 2026-10-12 に作った。
  - 種: 4つめの遺伝子「アゴのかたさ」と、土地ごとの草のかたさ（東はやわらかい・島はなか・西はかたい）。子は近くの似た相手と遺伝子を合わせ、親の種を受けつぐ。種の中がはっきり2つに分かれたら新しい種、近づいて同じあたりに住む種はひとつに混ざる。名前は姿から（ヤワ／ナカ／カタ＋アゴ＋ウオ／ハマ／アシ）。
  - お題5つ（陸へ上げる・陸の種を2つに・潮が引くと現れる道で出会わせる・周転円でいちばん大きな潮・4つの種）と、お題ごとの★。
  - 周転円（月が近いほど強く引く。距離の3乗に反比例）、恒星天を回すとすべての天球が回る、天球をタップで止める。
  - 気温（2026-10-12 ユーザー「ずっと太陽が照ってたら水が蒸発したり、熱くなったりする」「逆に太陽がずっとないと凍える」）: 太陽を止めると昼の側は焼けて蒸発・雲・雨、夜の側は凍る（凍った海は流れない）。草は暑すぎ・寒すぎで枯れ、生き物は 40 度より上・0 度より下で弱る。
  - 神の手をボタンなしに（ユーザー「ドラッグ操作でも盛ったり削ったり」）: 大地のふちを外へなぞると盛る、内へなぞると削る。
  - BGM をおだやかに（ユーザー「不穏すぎる。控えめに穏やか、眠くなる系でも」）: ハ長調の五音音階の正弦波の和音とオルゴールの音。見出しに音楽のオン・オフ。見えないあいだは音を止める（ユーザー「アプリけしてもおとなりっぱなし」）。
  - 変化を見やすく（ユーザー「変化がわかりづらい」）: 種ごとの色、種の一覧（押すとそこへ寄る）、種の数の移り変わりのグラフ、新しい種の札を地図の上に。
- **段階C（製品の体裁・ver. 1.0）**: タイトル、つづきから、図鑑（「天動説では」と「本当は」を並べる）、エンディング（天球が消えて地動説の宇宙へ引いていく答え合わせ）、音、一時停止、てびき、スマホ。
- **段階D（候補）**: 惑星の天球（水星・金星・火星・木星・土星）を足す。ユーザーの元の案（本物の物理版）をもう一つのモードとして入れ、同じ大地で比べる。
- **植物（ユーザー 2026-10-12「段階的に、植物もいれたい」）**: v002 では草（食べもの）が気温で枯れるところまで。次は、草に種類と遺伝子（暑さ・寒さ・乾きへの強さ、背の高さ）を持たせて、種（たね）で広がり、土地ごとに変わっていく。木（大きくなるのに時間がかかる、日かげを作る）、陸に草が広がってから動物が上がる順番（本当の歴史もそう）も候補。
- **3D の視点（ユーザー 2026-10-12「3D的な視点で、裏側も見てみたい」）**: いまの世界は大地の輪切り（赤道の1本の輪）なので、3D にするなら海の計算を球の表面（2次元）に作り直す必要がある。軽い案は、いまの輪を球の赤道に巻いて斜めから見る（裏側は輪の反対がわ）。本気の案は球面の浅水方程式と、球の上の生き物。
  - 2026-10-12 ユーザー「3Dは軽い案で試してみて」→ v003 で「地球儀」の見え方を足した（`js/globe.js`）。輪を赤道に巻き、帯の外は「未知の地」。ドラッグで回して裏側も見られる。見るだけで、天球や大地をさわるのは輪切りで。
- **世界を支える生き物（ユーザーの問い「亀がいるんだっけ？」）**: 大地を亀や象が支える宇宙観は、インドの神話などに見られる（プトレマイオスの天動説では大地は球で、何にも支えられず真ん中にある）。入れるなら、実在の神話をからかわない形で、別の宇宙観の図鑑として。
## やらないこと
- 段階A・B で 3D にしない（まず 2D の輪切りで遊びを固める。3D は上の「3D の視点」で相談）。
- 本当の軌道の計算（ケプラーの法則・N体）はしない。天動説のルールで動かす。
- 占星術の「星が運命を決める」は、昔の考えとして紹介するだけで、当たる・効くとは言わない。
- 生き物の死をむごく見せない（津波で流されたものは、線がほどけて消える程度）。

## 気をつけること
- 基本ルール（CLAUDE.md）: 性的な内容・R18 の要素をまぜない。生き物がふえるのは「子を残す」程度の言い方。神・宗教の扱いは「神の手」という遊びの役割にとどめ、実在の宗教や神話をからかわない。
- 嘘の扱い: ゲームの中では堂々と天動説、図鑑では必ず「本当は」を並べる。「天動説が正しい」と受け取られない作りにする。
- 技術: Canvas 2D。`css/` `js/` に分け、1ファイル 800 行・60KB まで（まなびラボ RULES 2章）。水の計算と生き物の数は、スマホでも 60fps を目安に（生き物は数百まで）。
