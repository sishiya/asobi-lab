## しくみ
- `js/main.js`: 画面の流れ（タイトル → 準備 → 1枚ずつ「出る 1.8秒 → 表情 5秒（のこり3秒で 3・2・1）→ シャッター → 止め 1.1秒」→ けっか）、看板の合成、保存、設定（localStorage `face-in-frame`、読めなくても動く）。
- `js/face.js`: MediaPipe Face Landmarker（VIDEO）。`readFace` が顔の外わく・首のかたむき（目じりの線）・顔の向き（鼻先がほおの間のどこか）・表情の数（`expression`。blendshapes を口・眉・目の8つにまとめ、左右はならす）を返す。座標は鏡にした映像の画素。
- `js/score.js`: お手本（`js/goals.js`。`node face-in-frame/tools/calibrate.mjs` が、その絵自身の顔を穴にぴったりはめて読んだ数を書く。読めない絵は paintings.js の手の数）（口の形の jaw・smile・frown・round と、首の roll・yaw。目と眉は見ない）（`paintings.js` の goal・roll・yaw）との近さ。表情は 0.35、首は 25度・向き 0.6 ずれると 0。首は重み 0.6。シャッターの前 0.45 秒の顔をならして採点。◎ 0.75 以上・○ 0.45 以上。
- `js/blend.js`: WebGL で映像を鏡にし、Reinhard の lαβ で色移し（映像の顔のまん中の平均・散らばり → 穴の中の絵の顔の色。散らばりの比は 明るさ 0.6〜1.4・色 0.35〜2.0 にとどめる。明るさを強めすぎると穴に入った暗い背景で顔の明暗がきつくなるため）＋少しぼかし＋粒。映像の顔の色は 0.3 秒ごとに 40×40 に縮めて測り、ならす。
- なじませ（`js/harmonize.js`、v010）: 色移し（blend.js）のあと、穴のまわりを「ぼかした成分」と「こまかい成分」に分け、ぼかした成分（6×6 にならした明るさ・色・光の当たり方）を、穴の下の元の絵の顔のぼかした成分に入れかえる（映像 + (絵のぼかし − 映像のぼかし) × 強さ）。部屋の明るさ・照明の色・肌の色・横からの光がまとめて絵の光になり、口の開きや鼻すじは残る。6×6 より細かくすると、開けた口が絵の閉じた口で明るく埋まる。前の陰影の地図（soft-light）はやめた。確かめは `node face-in-frame/tools/light-test.mjs`（試験の顔に `&light=明るさ:色温度:肌:ざらつき` をつけて6つの条件×絵を並べる。`_dev/face-in-frame/light/sheet.png`）。
- 顔を絵になじませる・筆のタッチをなじませるやり方のまとめは `STYLE.md`。
- 筆のタッチ（`js/style.js`）: Magenta の任意スタイル変換を TensorFlow.js（WebGL）で。絵ごとの「スタイルの特徴」（100 の数）は事前に `node face-in-frame/tools/style-bottlenecks.mjs` で `js/styles.js` に書いておく（スタイルを読むネットワーク 9.5MB は `_dev/face-in-frame/style-predictor/` だけに置き、公開しない）。読む広さは顔のはばの3倍（写楽は暗い地で顔が黒ずむので 1.1 倍＝`styleCrop`）。遊んでいるあいだは穴をふくむ正方形を 224×224 にして変換し、終わるたびに次をはじめる（1〜2コマおくれる）。写真は 448×448 で変換しなおして重ね、穴のあいた絵をのせなおす。大きさを2つに決めてあるのは、大きさが変わるたびに GPU の下ごしらえが1〜2秒かかるため（読みこみのときに両方の大きさで一度ずつ流しておく）。WebGL が使えないと1コマ7秒かかるので使わない。下ごしらえのあと 224 が 120ms をこえる端末は、写真だけにかける。RTX 5070 で 224 が約 50ms。表情の点は、もとの映像で測るので変わらない。確かめは `GPU=1 node face-in-frame/tools/playtest.mjs …`（ふつうの headless は WebGL がソフトウェアなので切れる）。
- （いまは使っていない）絵ごとの専用モデル（`js/style-fast.js`・`vendor/style-models/<絵>.bin`・`.json`）: `paintings.js` で `fast: true` にした絵は、任意スタイル変換のかわりにこれを使う（v010 でやめた。重みは消した）。平らな所で縦縞が出たので、学習の写真の半分をぼかし、入力にゆらぎ（0.02、ブラウザでは大きさごとに決まった模様）をのせ、TV を 4e-6 にした。形は Johnson ほか 2016（9×9 の畳みこみ・ストライド2を2つ・残差5つ・最近傍の拡大と畳みこみを2つ・9×9、インスタンス正規化、出力は sigmoid）、約 170 万の重みを float16 で 3.3MB。学習は `face-in-frame/tools/train_style.py`（PyTorch。損失は VGG16 の relu2_2 の中身と relu1_2〜4_3 のグラム行列。写真は COCO val2017 の 5000 枚を 256 に切って2回り、RTX 5070 で1枚の絵あたり約2分15秒）。この PC では、audio-studio-mcp の .venv の Python（PyTorch 2.7.1+cu128）に、torchvision と Pillow だけを別のフォルダ（PYTHONPATH）に入れて使った（その .venv は書きかえない）。写楽は顔の肌だけ読むと紙の色しか学ばないので、学習は `fastCrop` 1.8・`--style-weight 3e5`。ほかはふつう（1e5）。くらべるときは `?touch=arb` で専用モデルを使わない。
- 看板の合成（`placement`）: 映像を絵の画素へ `p = 穴の中心 + k × (v − c)` で置く。寄せないとき k は、カメラの短い辺の 4 割が絵の顔のはばになる大きさ、c は映像のまん中。寄せるときは、自分の顔の「くり抜く所」の箱が絵の穴の箱をおおう k（たて・よこの大きいほうの比）と、その箱の中心の c へ、強さの割合（0・0.3・0.55・0.8）だけ近づける。**首のかたむきは寄せない**（遊ぶ人が合わせる所なので）。
- 穴: 絵ごとに顔の線（`paintings.js` の face。鼻先と、眉の下・上まぶた・下まぶた・あご・ほおの位置。首のかたむきで回した向き）を持ち、`face.js` の `areaBox` で「くり抜く所」の箱を出して、ふちのぼかしのまん中が箱のふちに来るだ円にする。映像の顔も同じ `faceLines`→`areaBox` で箱にするので、絵と自分の同じ所が重なる。顔が見つかる絵（モナ・リザ・真珠・トカゲ）は Face Landmarker の値、見つからない絵（叫び・写楽・ゴッホ）は目で測った。横を向いた顔は向こうのほおが隠れるので、横のはばは目じり・口の角もふくめて測る。`tools/analyze.html` で3つの箱を絵に重ねて見られる。
- 区割り: 上＝何枚目・絵の名前（左に「×」やめる）、まん中＝額の中の絵（ことば「さけべ！」は絵の上のまん中、3・2・1 は右下）、下＝時間の棒。

## 確かめ方
- `node face-in-frame/tools/playtest.mjs <test の絵> <幅> <高さ> [出す絵]`: カメラのかわりに絵の顔（`?test=<id>`、ゆらして動かす）で1回遊び、タイトル・出る・表情・けっかを `_dev/face-in-frame/<日時>/` に撮る。点・部位・エラー・外への通信を出す。幅は 1280×720・375×740・812×375 で見る。
- `?pick=pearl,monalisa` で出す絵を決められる。
- 速さ（RTX 5070、headless で GPU）: 筆のタッチ・なじませをどちらも入れても、遊んでいるあいだ 60fps（変換は描く流れとは別に回り、終わるたびに重ねる）。
- 動くサムネイル: `node face-in-frame/tools/motion-thumb.mjs` → `thumbs/face-in-frame.mp4`（640×360・4秒）と最初のコマの `.jpg`。カメラのかわりにトカゲの少年の顔を `&path=align`（`main.js` の ALIGN。絵が出てからの秒ごとのずれ・大きさ・かたむき）で動かし、寄せる補正なしでモナ・リザに合わせる。縦長の窓で録って穴のまわりを 16:9 に切りぬき、録画の中のシャッターの白い光をさがして、その 0.5 秒あとで終わるように切る（録画の時計はページより1〜2秒おくれるため）。コマは `_dev/face-in-frame/motion/sheet.png`。
- `tools/analyze.html`: 絵に Face Landmarker をかけて、顔の外わくと表情の数を出す（穴とお手本の下書き）。
- 本物のカメラ（PC とスマホ）はユーザーに試してもらう。見るところ: 穴に合わせやすいか・寄せる強さの心地よさ・5秒は短くないか・点が表情の工夫で動くか・なじませの強さ。
