# 名画の顔ハメ: 顔を絵になじませる・スタイル変換をなじませるやり方（メモ）

2026-10-26。ユーザー「スタイル変換をなじませるやりかたはちゃんとメモとしてのこしておいてね」。ほかのゲームでも使えるように、試してわかったことをまとめる。
しくみの細かいところは `DEVNOTES.md`、コードは `js/blend.js`・`js/harmonize.js`・`js/style.js`。

## 順番（1コマごと）
1. **色移し**（`js/blend.js`、WebGL）: カメラの映像を鏡にし、顔のまん中の色の平均と散らばり（Reinhard の lαβ）を、穴の中の絵の顔の色にそろえる。散らばりの比は 明るさ 0.6〜1.4・色 0.35〜2.0 にとどめる（明るさを強めすぎると、穴に入った暗い背景で顔の明暗がきつくなる）。
2. **周波数で分けるなじませ**（`js/harmonize.js`、WebGL）: 穴のまわりを「ぼかした成分」（明るさ・色・光の当たり方）と「こまかい成分」（口・鼻すじ・しわ）に分け、**ぼかした成分だけを、穴の下にある元の絵の顔のぼかした成分に入れかえる**。`映像 + (絵のぼかし − 映像のぼかし) × 強さ`。ぼかしは 6×6 に縮めて、4点をならして広げる。
   - これで、部屋の明るさ・照明の色・肌の色・横からの光が、まとめて絵の光（モナ・リザのやわらかい影、真珠の左からの光）に置きかわる。表情はこまかいほうに残る。
   - **6×6 より細かくしない**: 開けた口が、絵の閉じた口の明るさで埋まって、表情が読めなくなる。
   - 前の「陰影の地図」（明るさの地図を soft-light で重ね、自分の光は逆の地図でうすめる）は、境目が出やすく、横からの光が残ったのでやめた。
3. **スタイル変換（筆のタッチ）**（`js/style.js`、TensorFlow.js）: 2 のあとの絵を、穴をふくむ正方形に切って変換し、上に重ねる。
4. 穴をあけた絵をいちばん上にのせる（穴のふちは外の 16% をぼかす）。

## スタイル変換をなじませるこつ
- **変換のあと、明るさと色の散らばりを、変換の前の顔にもどす**（筆づかいの模様だけをもらう）。測るのは正方形の**まん中だけ**（まわりの暗い所で平均がずれないように）。これをしないと、暗い絵（フェルメール・カラヴァッジョ）で顔が黒ずむ（ユーザー「すごい濃くなっちゃった」）。
- **スタイルを読む所は、絵ごとに選ぶ**（`paintings.js` の `styleCrop`＝顔のはばの何倍か）。ふつうは顔のまわり3倍。暗い地や髪がまわりにある絵（写楽・真珠・トカゲ）は、顔の肌だけ（1.1 倍）にしないと、地の色を読んで顔が黒ずむ。
- **なめらかな肌の絵は強さの上限を下げる**（`touchMax` 0.4。真珠・トカゲ・モナ・リザ）。筆づかいの少ない絵は、任意スタイル変換がのせる模様のほうが絵より強く見える。
- 強さは「重ねる割合」で決める（`TOUCH` なし・弱 0.45・中 0.75・強 1）。表情の点は変換の**前**の映像で測るので、変換しても点は変わらない。

## 速さ（リアルタイムで続けるために）
- 入力の大きさを2つに決める（遊んでいるあいだ 224×224、写真 448×448）。大きさが変わるたびに GPU の下ごしらえが1〜2秒かかるので、読みこみのときに両方の大きさで一度ずつ流しておく。
- 変換は描く流れと別に回し、終わるたびに次をはじめる（1〜2コマおくれて追いかける）。描く流れは止めない → RTX 5070 で、なじませ・筆のタッチを入れても 60fps。
- WebGL が使えない（CPU だと1コマ7秒）・写真1枚に 0.8 秒をこえる端末では使わない。224 が 120ms をこえる端末は写真だけにかける。
- 筆のタッチを「なし」にしたままなら、TensorFlow.js もモデルも読みこまない。

## 絵ごとの専用モデル（速いスタイル変換）を試したこと
- `tools/train_style.py`（Johnson ほか 2016 の形を PyTorch で学習 → float16 の重みを `js/style-fast.js` が TensorFlow.js で組みなおす）。タッチは任意スタイル変換よりよく出た（ゴッホ・写楽）。1枚の絵の学習は RTX 5070 で約2分。
- **平らな所で縦縞と格子が出た**（ユーザー「変な縦縞がでました」。カメラの映像は肌や壁が平ら）。学習の写真の半分をぼかし、入力に小さなゆらぎ（0.02。ブラウザでは大きさごとに決まった模様にしてちらつかせない）をのせ、TV を 4e-6 にすると消えた。
- 学習しなおしの手間とトークンを考えて、いまは任意スタイル変換にもどした（重みは消した。道具は残してある）。使うときは `paintings.js` で `fast: true`、学習のしかたは DEVNOTES。

## 確かめ方
- `node face-in-frame/tools/light-test.mjs [絵] [設定の JSON]`: 試験の顔に `&light=明るさ:色温度:肌:ざらつき` をつけて、6つの条件（ふつう・暗い電球色の部屋・明るい窓・電球色・濃い肌・濃い肌で暗い部屋）×絵を並べる → `_dev/face-in-frame/light/sheet.png`。GPU で（筆のタッチを入れるため）。
- 筆のタッチの見くらべは、設定の 筆のタッチ「なし」と「強」で同じ回を撮って並べる（`GPU=1 node face-in-frame/tools/playtest.mjs …`）。
