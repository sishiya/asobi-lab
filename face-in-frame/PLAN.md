# 名画の顔ハメ（仮） 企画書

最終更新: 2026-10-25

## 何を作るか
パブリックドメインの名画の顔の部分をくり抜いて、**顔ハメ看板**にする。カメラに映った自分の顔を穴に合わせ、決められた秒数のうちに**絵の表情をまねして**シャッターを切る。何枚か撮り終えたら、どれだけ似ていたかの点が出る。撮った写真は、結果を見たあとで自由にダウンロードできる。

2026-10-25 ユーザーの案から（「一部切り抜いて自分の顔の一部をはめ込んだおもしろ動画」がきっかけ）。

### 柱
1. **鼻から下をのぞかせる**（2026-10-25 ユーザーが決めた）: 穴は絵の鼻から下だけ。絵の目・眉・髪・耳は残し、自分の鼻と口がのぞく。
2. **看板式**: 穴は絵の中で動かない。遊ぶ人が自分で体を動かして顔を合わせる。顔ハメ看板の楽しさをそのまま残す。
3. **補正はほどほど**: 顔の位置と大きさを、穴のほうへ少しだけ寄せる。強すぎると自分で細かく合わせられなくなるので、寄せるのは一部だけ。**強さは設定で選べる**（なし／弱／中／強。最初は弱）。
4. **表情まねが点になる**: 似ているかは、穴からのぞく口の形（開き・口角・すぼめ・への字）と首のかたむき・向きで見る（目と眉は絵のまま隠れているので見ない。v005）。1枚ごとに「口 ◎・首 ○」のように見せ、次の工夫につなげる。採点はきびしくしすぎない（少しずれても点が入る幅をとる）。
5. **映像は外に出さない**: カメラの映像は端末の中だけで扱い、送らない・残さない。保存するのは、結果の画面で遊ぶ人が自分で「保存」を押したときだけ。

## 流れ
| 場面 | すること |
|---|---|
| タイトル | 「はじめる」。カメラを使うこと、**映像は送られず保存もされない**ことを、短く一言で伝える |
| カメラの許可 | ブラウザの許可。断られたとき・カメラがないときは、その旨を出してタイトルへ戻る |
| 撮影（5枚） | 絵が映る → 穴に顔を合わせ、表情を作る → 「3・2・1」で自動のシャッター。1枚あたり約5秒（秒数は試して決める） |
| 結果 | 1枚ごとの写真と点・部位ごとの◎○△・合計点。写真は1枚ずつ、または5枚まとめた1枚で保存できる |

- 絵は候補の中から1回ごとにランダムに選ぶ。
- 字は少なく。最初の30秒で「顔を穴に合わせる→表情をまねする→撮られる」が伝わるかを、試作で確かめる。

## しくみ
- **顔を見つける**: MediaPipe の Face Landmarker（ブラウザの中だけで動く）。表情の数値（blendshapes、約50）と顔の向き・位置を取る。モデルのファイルはリポジトリに置き、外から読みこまない。
- **看板の合成**: 絵の上の層に穴をあけ、その下にカメラの映像を置く。映像は左右反転して鏡のように見せる。補正の強さに合わせて、映像の位置と大きさを穴のほうへ寄せる（強さ0＝寄せない）。
- **なじませる（ユーザー「元絵に色味なども合わせてなじませる画像処理ができるといい」）**: 穴のまわりの絵の色（平均と散らばり）を測っておき、映像の顔の色をそれに合わせる（Lab に近い色空間で、平均と標準偏差をそろえる色移し）。そのうえで、ニスの黄ばみ・ひび・粒・少しのぼかしをかけ、穴のふちをぼかす。やりすぎて表情がわからなくならない程度に。強さは設定で選べる。
- **お手本の数値**: 絵ごとに、似ているかを見る表情の数値と首の向きを、手で決めて持っておく（絵の顔に Face Landmarker をかけた結果は参考にとどめる）。部位ごとに重みを変えられるようにする（例:「叫び」は口と手、モナ・リザは口角）。
- **点**: 部位ごとの近さを◎○△と0〜100点にして合計する。
- **保存**: 撮影のときに合成した絵を画像として残し、結果の画面で「保存」を押したときだけファイルに書き出す。ページを閉じたら消える。

## 絵の候補（全年齢・表情がはっきりしているもの）
- ムンク「叫び」
- 写楽の大首絵（目をむく・への字の口）
- ダ・ヴィンチ「モナ・リザ」（控えめなほほえみ。むずかしい絵として）
- フェルメール「真珠の耳飾りの少女」（ふり向き・口が少し開く）
- カラヴァッジョ「トカゲに噛まれる少年」（びっくり顔）
- ボワイー「35の表情の頭部」（1枚の中に変顔。1つを選ぶ）
- ゴッホの自画像（むすっとした顔）

- **出典とライセンスは1枚ずつ `CREDITS.md` に記録する**。できるだけ CC0 の所蔵館（メトロポリタン美術館・アムステルダム国立美術館・ワシントン・ナショナル・ギャラリー・シカゴ美術館・マウリッツハイス美術館など）から。日本の作品は ColBase など。所蔵館がライセンスをつけている写真は使わない。
- 裸の人物・血や傷の描写・こわすぎる絵は入れない（基本ルール）。絵はこちらで選んだものだけにし、遊ぶ人が絵を足すしくみは作らない。

## 段階
### 段階A（試作。v001）
- 絵3〜4枚、1回3枚。看板式の合成と補正の強さ（設定）、自動シャッター、結果と保存。
- 採点はまず口・眉・目・首のかたむきの4つ（v005 で口と首だけにした）。
- 確かめること: 穴に合わせやすいか（スマホの縦・PC の横）、補正の強さはどれが心地よいか、5秒は短すぎないか、点が表情の工夫に合って動くか。

### 筆のタッチ（2026-10-25、v007）
- 色と陰影のなじませに加えて、穴のまわりをその絵のスタイル（筆づかい・線・紙の質感）に変換する。まず任意スタイル変換（1つのモデルでどの絵にも）で試す。出来のいい絵から、絵ごとに学習した専用のモデル（速く、タッチがよく出る）に置きかえるかを決める。

### 段階B（案）
- 絵を7枚以上に。1回5枚。
- なじませを強く（絵のタッチに寄せる）。
- 結果に一言の講評（「ムンクより叫んでいる」など）。
- 日本語・英語。

## やらないこと
- 映像や写真をサーバーに送る・ランキングにする・アクセス解析に送る。
- 顔をすり替える（ディープフェイクのように絵の顔へ貼りかえる）。あくまで看板の穴から自分の顔がのぞく。
- 性的な内容・R18（基本ルール）。
