# 恐竜かけっこ牧場 企画書

2026-10-09 ユーザーと決めたこと。あそびラボの最初のゲーム。フォルダ名 `dino-race`。

## ひとことで
恐竜をかけ合わせて育て、**物理で本当に走らせて**かけっこで競わせる。体の形は本物の恐竜の範囲におさめ、走り方は進化で身につける。

## 決めたこと
| 項目 | 決めたこと |
|---|---|
| 動き | **合わせ技**: 体の形（脚の長さ・骨の比率・首・しっぽ・大きさ）は本物の恐竜から外れすぎない範囲に、動きは物理（関節・筋肉）で |
| 進化 | **両方**: 自分で親を2匹選んでかけ合わせる（アストロノーカ型）のが基本。「おまかせで N 世代」ボタンで自動の GA も |

| 遊ぶ長さ | どちらでも（1レースは数十秒、育成は続けられるようにセーブ） |
| 誰のため | まず自分が楽しい |
| 名前 | **恐竜かけっこ牧場**（2026-10-09 決定） |
| 絵 | **図鑑の骨格図ふう**（クリーム色の紙に、骨をインクの線で。2026-10-09 決定） |

## 下敷きになる研究（画面にも出す）
- Sellers, W.I. & Manning, P.L. (2007) Estimating dinosaur maximum running speeds using evolutionary robotics. *Proc. R. Soc. B* 274: 2711–2716. — 骨格の模型を物理の中で GA で走らせ、最高速度を推定。**このゲームのしくみそのもの**。
- Hutchinson, J.R. & Garcia, M. (2002) Tyrannosaurus was not a fast runner. *Nature* 415: 1018–1021. — 体が大きいほど速く走るのに必要な脚の筋肉が足りなくなる。→ 大きさと筋力の関係（下の「相似則」）。
- Alexander, R.McN. (1976) Estimates of speeds of dinosaurs. *Nature* 261: 129–130. — 足あとの歩幅と腰の高さから速さを出す式。→ レース後に「足あとから推定すると時速◯km」と比べる。
- 体の比率は骨格の計測データから（例: Persons & Currie 2016 の獣脚類の後ろ脚の比率）。**値と出どころは段階Aの調べものとして確かめてから使う**（想像で埋めない）。

## しくみの案
### 体（遺伝子）
- 骨格は決まった形: 胴・首と頭・しっぽ・後ろ脚（太もも・すね・足の甲・指）・前脚。段階Aは**二足歩行の獣脚類型だけ**。
- 遺伝子は「比率」と「大きさ」: 腰の高さ、太もも：すね：足の甲の比、首・しっぽの長さ、胴の長さ、体の大きさ（全長）。範囲は本物の恐竜の計測値の少し外まで。
- **相似則**（ここが「合わせ技」の本物らしさ）: 体の大きさを2倍にすると、重さは8倍、筋肉の力（断面積）は4倍。だから大きい恐竜は力が足りなくなる（Hutchinson & Garcia）。筋肉の量も遺伝子だが、体に対する割合に上限をつける。
- 走り方の遺伝子: 1歩のリズム、関節ごとの力の入れ方（いつ・どれだけ）。進化の箱庭と同じ「周期の中の位置と長さ」から始め、必要ならバランスをとる簡単な反射（体が前に倒れたら脚を前へ）を足す。
- しっぽと首は**重心のつり合い**に効く（しっぽが短いと前に倒れやすい）。これが遊びのおもしろさになるはず。

### 物理
- 2次元の横から見た骨格。かたい骨の部品を関節でつなぎ、関節には動く角度の範囲、筋肉はトルク（力の上限は相似則で）。
- 進化の箱庭（`../アプリ開発/ga-creatures/`）は点とばねの体なので、物理は作り直す。GA・記録・描画の作りは参考にする。
- 1レース 100m（または15秒で何m）。転んだら失格ではなく、そこで止まる（起き上がりはあとで）。

### 育てる（牧場）
- 牧場に恐竜が数匹。2匹を選んで「かけ合わせ」→ 卵が3〜4個 → 生まれた子を走らせてみて、残す・逃がすを決める。
- 「おまかせで N 世代」: 牧場の外で自動の GA を回し、いちばん速い子を連れて帰る（時間がかかるのでその間は見ていられる）。
- 牧場の頭数には上限（残す子を選ぶのが遊び）。
- セーブはブラウザに（消えることがあると画面に書く）。書き出し・読み込みもあるとよい。

### かけっこ
- 自分の恐竜 vs ライバル。ライバルは**研究で推定された速さの本物の恐竜**（例: ティラノサウルスは時速◯km と推定、の「ゴースト」）。値は出どころつきで。
- レースのあとに「足あとから推定すると」（Alexander の式）と、実際にシミュレーションで出た速さを並べる。

## 段階
- **段階A（最初の1本）**: 二足歩行の1種類の骨格、平地 100m。物理で走る、かけ合わせ（親を選ぶ）と突然変異、おまかせ GA、牧場（数匹）、レース結果。本物の恐竜の比率は2〜3種（ティラノサウルス・ヴェロキラプトル・コンプソグナトゥスなど、調べて決める）をはじめの牧場に。
- **段階B**: ゴーストのライバル、セーブの書き出し、相似則の見える化（大きくすると重くなる様子）、図鑑（生まれた形の記録）。

  - **遊びの芯**: 
    1. **当日の調子**: かけっこと大会（はじめの2つ以外）は、走り方を毎回ほんの少しずらして走る（GA の「少しずらした2回目」と同じ 0.4%）。ライバルはいつもの走り。カードに「6回中◯回ゴール」（しっかり度）とタイムの幅を出し、結果に「この子の幅」と今回の位置を出す。→ 「速いけど危うい子／少し遅いけど安定した子」のどちらを残すかが判断になる（練習は弱めない。練習で伸びなくなったら「伸びしろ: ほぼ出しきった」）。
    2. **お題を3段に**（初級4・中級4・上級3＝11）。段のお題をぜんぶ取ると次の段が開く。中級に「中型級（50〜500kg）」を足す。人の世界記録は中級へ。落ちたときはお題ごとの次の一手のヒント。
    3. **かけ合わせを読める**: かけ合わせる前のシートで、走り方をどちらの親から受けつぐか選べる（しっかり度つき）・子の体重の幅（帯）・体の大きさがちがいすぎると注意。子には「親ごえ ▲◯秒」と「◯◯ゆずりの走り」。詳しくの体のバーに両親の位置の印。
    4. **新種ストルティオミムス**（オルニトミムス類、約150kg、すね・足の甲が長い俊足型）が中級が開いたときに牧場に仲間入り。50〜500kg の空きを埋める。
    5. おまかせの「体の形も変える」は中級をぜんぶ取ったら使える（重量級・巨人をかけ合わせで解く余地を残す）。
    6. **記録帳に「体重と速さ」の図**（相似則。自分の恐竜・人・ゾウ・ダチョウ・Sellers & Manning 2007 の推定）と「研究の推定とくらべる」表 → エンディングのあともめざすもの。
  - **手ざわり**: 流れる遠景（視差）と紙の質感・地層、足あとの列、ゴールの判子・転倒の土ぼこりと揺れ、卵がかえる（記録が出るまで卵がゆれる→割れて1匹ずつ）、走りを見たあとは元の場所へ。

  - **競うもの**: 100m の「いつもの走り」（カードの記録。物理は決まった計算なので、遺伝子から同じタイムを出し直せる）を、記録帳と同じ体重クラス5つ（`CLASSES`）ごとに上位20。相似則で大きい恐竜にも出番がある。当日の調子は確かめられないので使わない。
  - **しっかり度**（ゲームデザイン・ディレクター）: 出せるのは「10回中7回以上ゴール」の子だけ。表のタイムの横に「◯/10」。綱渡りの走りばかりにならないように。
  - **出し方**（ゲームデザイン・UX）: 自動では送らない。自分で選んで出す。1牧場につき1クラス1匹（出し直すと入れかわる）。出す場所は記録帳の「みんな」のページ（クラスごとに出せる子を選ぶ）と、恐竜の「…」くわしく。
  - **名前**（ディレクター・UX）: 自由な文字は送らない。恐竜は系統（種の id 1〜2個。表示は見る人の言語で「ラプコン」など）、牧場は決まった言葉の組み合わせ。言葉のリストは悪い意味にならない組み合わせだけ。
  - **牧場の名前を自分で選ぶ**（2026-10-18 ユーザー「ユーザー目線では、自分で名前つけたいかな」→ 自由な名前をみんなに見せる案・自分の画面だけの自由な名前の案とくらべて「A案でいこう」）: くじではなく、言葉を2つ一覧から選んで「{A}の{B}牧場」（A 40語・B 30語＝1,200通り、おまかせもある）。はじめて出すときと「みんな」のページの「名前を変える」で選べ、変えるとサーバーの自分の行もすぐそろう。言葉はディレクターが1,200通りを日本語の音・英語の並びで確かめ、3つ差しかえた（Bluesky→Sky＝実在の SNS、はま Beach→Shore＝Pebble Beach がゴルフ場の商標、のはら→せせらぎ＝「の」が重なる）。
  - **画面**（UX）: 記録帳を4ページに（ラベルを「まとめ／体重と速さ／本物／みんな」にちぢめる。375px で折り返さないように）。1行は「順位・タイム（◯/10）・系統（下に小さく牧場）」。行を押すと「走りを見る」で自分の画面で再生。自分の行は枠と太字、20位に入らないときは表の下に「あなた ◯位」。はじめて出すときだけ、送る1行の見本と「送るのはこの1行と走りのもと（遺伝子）だけ」を見せて「出す／やめる」。
  - **つながらないとき**（ディレクター・UX）: 通信するのは「みんな」のページを開いたときと出すときだけ（読み込み・タイトルでは通信しない）。失敗したら「いまはつながりません」と「もう一度」、前に見た表を日付つきで。ほかの遊びは止めない。
  - **うその防ぎ**: サーバーで遺伝子が範囲の中か・体重を遺伝子から計算し直してクラスを決める・タイム 5〜40 秒・回数の上限。見る人が再生すると、その画面で物理を計算し直す。送られたタイムとちがったら「この環境では同じ走りになりませんでした」（責めない言い方。Safari と Chrome で Math.sin などがわずかにちがい、本人でも合わないことがあるため）。
  - **作り**（ディレクター）: 順位まわりは `js/online.js` と別の localStorage のかぎに分け、セーブには入れない。送り先は1か所のスイッチ（null にすると「みんな」のページが消える）。localhost はローカルのサーバー、`versions/` からは送らない。送るデータに物理の版（`sim1`）を入れ、sim.js や planck を変えてタイムが変わるときは表を分ける。IP や記録の日時以外は保存しない（IP は回数の上限のためにメモリで数えるだけ）。メニューに「送るもの・送らないもの」。
  - やらないこと（試しの範囲）: リアルタイム対戦、ランキングの恐竜を連れて帰る、自由な名前・コメント、取り下げ、季節の区切り。あとの案: 記録帳の図にみんなの点を薄く打つ、再生で自分の子と並べて走る、表に研究の推定の線。
