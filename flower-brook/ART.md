## 2D か 3D か → 3D（斜め見下ろしの箱庭）
| | 2D 真上（A1 の画面） | 3D 斜め見下ろし |
|---|---|---|
| 花 | 岸の点。横に並ぶだけ | 立って見える。手前・奥に重なり、花畑の厚みが出る |
| 華やかさ | 色の点の模様どまり | 光の筋・舞う花びら・遠くのかすみ・ぼけで奥行き |
| 見やすさ | 全体が平らに見える | 先が小さくなるので、遠くは「来るものの予告」になる |
| 重さ | 軽い | 花を数千、1回の描画でまとめて描けば、スマホでも足りる（Three.js の InstancedMesh） |
- 決まり（`js/sim.js`）は1本の道 s と左右 x のまま。3D は見せ方だけ（s → 奥行き、x → 左右）。

## カメラ
- **しずくの列のうしろ上から、川下を見る。見下ろす角度は 36°**（真上 90°、水平 0°。`look/3d.html` で 30・36・40・55 を見くらべて決めた。30 はアーチが立って見えて美しいが手前の花が大きすぎ、55 は平らで 2D と変わらない）。
  - たての画面（スマホ）では、横に川はば×2.8 ぶん（両岸の花）が入るところまでカメラを引く。川はばはせまめ（花の面を広く）。
  - 先にあるアーチ・日なたの岸・大きな流れが画面の上のほうに見える。決めることの予告になる。
  - 列は画面のまん中。指は画面の下半分に置くので、列を隠さない（PLAN.md の手ざわり）。
  - 30° より浅いと、先の花で川がかくれる。55° より深いと、花が立たず 2D と変わらない。
- 列の左右にゆっくりついていく（急に振らない）。ゆっくり下るときは少し寄り、速いときは少し引く（速さが目でわかる）。
- 画面の上下を少しぼかす（ティルトシフトの箱庭）。まん中の列のあたりだけくっきり。
- カメラを回す操作は入れない（RULES 4章の「回す向きの逆転」は要らない）。

## 色と光
- 水彩: 紙の地（クリーム）に、にじむ色を重ねる。影は黒でなく、青むらさきの淡い色。
- 遠くは紙の色にかすむ（霧の色＝紙の色）。
- 日なたの岸は、上から光の筋。地面は黄みを帯びる。めずらしい花はそこでほのかに光る。
- しずく: すき通った水色 → はちみつ色 → 琥珀まで（茶色にしない。PLAN.md）。つやの白い光。
- 雷: 一瞬だけ画面が白く、そのあとしばらく青むらさきにくもる。花はゆれる。

## 気持ちよさ（見ているだけで）
- いつも何かがゆっくり動く: 花がそよぐ・花びらが舞う・水面のきらめき・光の粒。
- 花が咲くときは、つぼみ → ひらく を 0.5 秒かけて、ぽんと少しはずむ。小さな音（PLAN.md の音）。
- 速く下ると、両岸の花が流れて見える（奥行きがあるので速さが気持ちいい）。
- 目立たせるのは1つ（RULES 4章）: いまは列。花は華やかでも、彩度の高いのはめずらしい花だけ。

## やらないこと
- 写実的な草や花（ユーザーは抽象のほうが好み。まなびラボのメモ）。水彩の絵の花を立てる。
- 出口から長いものが出てくる絵（PLAN.md）。
