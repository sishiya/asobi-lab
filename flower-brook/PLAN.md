# 花の小川（仮） 企画書

最終更新: 2026-11-06

## 何を作るか
花の咲きみだれる庭を、くねくねと流れる長い小川。遊ぶ人は、その小川を下る**やわらかいしずくの列**（つながった玉）を動かす。土手の花は、しずくから水を飲んで咲く。**長くとどまるほど花は咲くが、しずくは乾いて、花のアーチをくぐるたびに丸い粒にちぎれていく**。急げば花は咲かず、しずくは水っぽいまま出口でしぶきになって散る。

2026-11-06 ユーザー「下痢とコロコロとバナナの形状変化を取り入れつつ、うんちとは直接的には伝えないゲーム」→「むしろルックは華やか、お花畑みたいに」→ 案A（自分で動かすアクション）×お花畑に決めた。もとは、まなびラボの会話で説明した、大腸で形が決まるしくみ（下の表）。同じ日に批判役に読んでもらい、10件を反映した（下の「批判役の指摘」）。

### 柱
1. **どこで飲ませるかの取りあい**: 日なたの岸にはめずらしい花が咲くが、そこはしずくがよく乾く。川のまん中は乾きにくいが、花は少ない。めずらしい花を咲かせたいほど、しずくは形を保ちにくい。左右の位置と、とどまる時間で決める。
2. **形は計算で決まる**: 出口の形は、玉ごとの水の量・つながりの強さ・アーチの締めつけから計算する。点数をつけて形を選ぶのではない。下り方の結果として形が出る。
3. **答えは言わない**: 画面・ことば・音に「うんち」「便」「おなか」「腸」「トイレ」は出さない。しずくを茶色にしない。7段を順番に並べた表も見せない。子どもにはまず気づかれず、知っている大人がふと気づく、くらいにする。
4. **華やか**: お花畑。花・花びら・光・水しぶきで、見ているだけで気持ちがいい画面にする。

### たとえの表（作る人だけが使う。画面には出さない）
| 体の中 | ゲームの中 |
|---|---|
| 大腸の中身（はじめは水分 約90%） | しずくの列（玉がつながったもの） |
| 大腸が水を吸う。とどまるほど吸われる | 土手の花が、近くの玉から水を飲んで咲く。岸に寄るほどよく飲む |
| ハウストラ（くびれ）と分節運動 | 小川にかかる花のアーチ。リズムをもってすぼまる・ゆるむ |
| 食物繊維（水を抱えてゲルになる・かさを増やす） | 流れてくるわら・花びら。取りこむと ①水を抱えて乾きにくい ②つながりが強い ③かさが増えて少し速く流れる |
| ストレス（分節運動を強める／CRF で動きを速める。人と時による） | にわか雷。アーチが強く締まるか、流れが急になるか、どちらかに転ぶ |
| 大ぜん動（1日に数回の大きな押し出し） | ときどき来る大きな流れ。乗ると一気に下れる |
| ブリストル便形状スケール 1〜7（Lewis & Heaton 1997） | 出口の形の7段（作る人の呼び名。画面では花の名前） |

**このたとえの限り（DEVNOTES にも書く）**: 形を「とどまった時間と水」だけで決めるモデル。本物の下痢は、腸が水を出す（分泌性）・水を引きこむ（浸透圧性）ことが大きく、「急いだ」だけではない。1段の粒がくびれでできるという説明も、よく言われるが測って確かめられたものではない（推定）。

## 手ざわり（遊ぶ人の手がすること）
画面は**小川を少し斜め上から見下ろす**。たてに長い川を、しずくが下（出口）へ下る。スマホのたて持ちを先に考える（RULES 4章）。しずくの列は画面の上〜中ほどに映す（下に置いた指で隠れないように）。

| 手 | すること |
|---|---|
| 指を置く（マウスを押す） | **置いた位置で決める**: 指の左右＝寄る岸、指の高さ＝速さ（上ほど速い） |
| 指をはなす | その場で**とどまる**（最後の左右の位置のまま。花はどんどん水を飲む） |
| キー | ←→ で岸、↑↓ で速さ、スペースでとどまる |
| 大きな流れが来たとき | 上へ大きく動かすと乗れる（一気に下る） |

- アーチは**すぼまる・ゆるむのリズム**をもつ。ゆるんだときに通るか、待つか、が時間の判断になる。
- 時間は流れる。1回の下りは**2〜3分**。止まっても時間は止まらない。止めたいときは一時停止のボタン。
- **教えるのは1つずつ**: ①指を置くと進む → ②岸に寄ると花が飲む → ③最初のアーチで乾いた玉がちぎれる。字は短く、その場の近くに1行だけ。
- **いまの様子をいつも見せる**: 玉の水の量はつや・透け方で。「このまま出口に着いたら何になるか」は、しずくの先頭の小さなつぼみの形で出しつづける。

## しくみ（段階Aの決まり）
- しずくの列は**玉 N 個**（はじめ 12 くらい）が、ばねでつながったもの。玉ごとに **水 w**（0〜1。はじめ 0.9 ぐらい）と **わら f** を持つ。
- **花が水を飲む**: 玉が花の近くにいるあいだ、w が減り、花は飲んだ分だけ育つ。飲む速さは**岸との近さ・日なたかどうか**で変わる（まん中・日かげはおそい）。
- **つながりの強さ**: となりの玉とのつながりは、w が中くらいのとき強く、乾くと弱い。わらがあると強い。w が高すぎると玉の形がなくなって混ざる（列がだらりと溶ける）。
- **アーチ**: すぼまっているときに通ると、列を締める。締める力がつながりより強いところで列が**ちぎれる**。ちぎれた玉は、乾いていれば丸まって粒になる。湿っていれば、うしろの玉とまたくっつく。
- **粒の房**: 乾いた粒でも、うしろから押されてアーチで締められると、詰まって**かたまる**（ごつごつの房。2段）。
- **わら**: 上の表の3つの効き目。
- **雷**: ときどき鳴る。しばらく「アーチが強く締まる」か「流れが急になる」のどちらかになる（鳴ったときの空の色で分かる）。
- **大きな流れ**: ときどき上から来る。乗るとアーチの前を一気に通りすぎる。
- **出口**: 着いたときの列から形を決める。**平均の w・いくつに分かれたか・粒の房があるか・玉の丸さ**から7段に分ける。
- 数の手本（あとで生き物監修役に確かめる。決めつけない）: 大腸に入るときの水分 約90%、形の段と大腸を通る時間の関係（Lewis & Heaton 1997）。ゲームの時間は縮めるので**比べ方だけ**合わせ、実際の時間・％は画面に出さない。

## 出口の7段（画面では花の名前）
作る人の呼び名は段の番号。画面では、出口でしずくが**花に吸いこまれ、その花が咲く**。咲く花の種類が段を表す。出口から長いものが出てくる絵は見せない。

| 段 | 咲く花（案） | しずくの様子（作る人用） | 集める重み |
|---|---|---|---|
| 1 | スズランの小さな鈴 | 乾いた粒がばらばら | ついでに取れる |
| 2 | アジサイの房 | 粒がかたまった房 | 狙う |
| 3 | 枝咲きのフジ | 1本だが表面にひび | 狙う |
| 4 | 大輪のシャクヤク | 1本・なめらか | いちばんの目標 |
| 5 | 八重の花びら | やわらかい切れ | 狙う |
| 6 | タンポポの綿毛 | ふちのくずれたかたまり | 狙う |
| 7 | 霧の虹 | 形がなく、しぶき | ついでに取れる |

- 1段・7段は、ずっととどまる・ずっと急ぐだけで出るので、「ついでに取れる」扱い。集める遊びの重みは2・3・5・6段を狙って出すことに置く。
- 図鑑は順番の表にしない。**咲いた花が庭のどこかに植わっていく絵**として見せる（くり返し遊ぶと庭が育つ）。
- 花の名前・種類は案。段階Aで、画面で見てたとえがあからさまにならないか確かめる。

## 見た目
- **華やかなお花畑**。見くらべのページ `look/`（手元だけ、`.gitignore`）で3案を**止まった絵で**並べ、ユーザーに選んでもらう（RULES 6章・10章）:
  1. **水彩の花畑**（にじむ色、光の粒、やわらかい影）
  2. **押し花の図鑑**（紙の地、線画＋手で塗った色、ラベル）
  3. **切り絵・ステンドグラス**（はっきりした色の面、光が透ける）
- しずくは**すき通った水色〜はちみつ色**。乾くほど色が濃く、つやがなくなる。**色の上限は金色・琥珀色**（茶色に寄せない）。
- 花は飲んだ水で、つぼみ → 半分 → 満開。満開の花から花びらが舞い、川に落ちる（わらと同じく拾える）。
- 描き方は Canvas 2D（花は前もって描いた絵を使い回す）。重ければ WebGL に。
- 音は Web Audio（水の音・花が開く音・アーチの「きゅっ」・雷）。BGM はおとライブラリ（`../sound-library/`）から選ぶ。

## 段階
### 段階A1（しくみの試し。v001）
- 見た目は単純な丸と線のまま。玉の列・水・つながり・アーチ（リズム）・花が飲む（岸と日なた）・雷・大きな流れ・出口の7段の判定。
- **自動の遊び手**（`tools/`）で、「速さを一定・岸を一定」の押し方を何通りも走らせる。**決まった押し方で4段が安定して出てしまうなら、しくみを作り直す**。めずらしい花と4段が取りあいになっているかも数で見る。
- 並行して、`look/` でルック3案を止まった絵で並べる。
- 音・図鑑の絵はまだ。公開しない（コミットだけ）。

### 段階A2（試作。v002〜）
- 決めたルックで仕上げる。教える順（1つずつ）・先頭のつぼみ・音。
- タイトル・一時停止・出口の花が庭に植わる（セーブは植わった花だけ、localStorage）。
- 日本語のみ。保管庫へ。

### 段階B（案）
- はじめに「泉」で、しずくのもとを選ぶ（水・わら・蜜の混ぜ方）。泉から水がわき足される庭（分泌性の下痢のたとえ）。
- 季節のちがう庭（春の野・夏のひまわり・秋のコスモス）。季節で花の飲む速さがちがう。

## 批判役の指摘（2026-11-06。反映したもの）
1. 2つの目標が同じ答えを指していて、決まった押し方で勝てる → めずらしい花を日なたの岸に・飲む速さを場所ごとに・アーチにリズム・A1 の自動の遊び手で確かめる。
2. 2段が出ない（乾いた粒は元にもどらない） → 粒が詰まってかたまる決まり。
3. 生理: 下痢＝急いだ、だけではない／ストレスは速めることも多い／わらの効き目は3つ／くびれで粒ができるのは推定 → たとえの表と「限り」に反映。
4. 7段の名前がブリストルの説明そのまま・順番の図鑑で正体がわかる → 花の名前・庭に植わる絵・色の上限。
5. スマホで、はなす＝とどまると、ドラッグで左右がぶつかる → 置いた位置で決める（左右＝岸、高さ＝速さ）。
6. はじめに3つ教えるのは多い・結果が遅い → 1つずつ・先頭のつぼみで予想を出しつづける。
7. 1段・7段は何もしないで取れる → ついでに取れる扱い。
8. 段階Aが多すぎる → A1（しくみ）と A2（仕上げ）に分けた。
9. もう一度遊ぶ理由が弱い → 出口の花が庭に植わって育つ。
10. 4段のごほうびがいちばん正体がばれる → しずくが花に吸いこまれて咲く形に。

## やらないこと
- 「うんち」「便」「おなか」「腸」「トイレ」など、答えにあたることばや絵（たとえの表は企画書と DEVNOTES だけ）。
- しずくを茶色にする。においや音で答えをにおわせる。出口から長いものが出てくる絵。
- 性的な内容・R18（基本ルール）。
- 点数で形を選ぶこと（形は計算の結果で出す）。
