## しくみ（PLAN.md の「しくみ」を作ってわかったこと）
- 川は1本の道 s（0〜3600）と左右 x（-1 左岸〜+1 右岸）。玉 12 個、0 が先頭。
- **出口の前の池**（最後の 260）を足した。アーチで切れた切れは、そのままだと二度とふれあわず、早いうちの切れ目が最後まで残った。本物も、形は最後にたまって押しあうところ（直腸）で決まるので、池で集めて押しあわせる。やわらかい切れ（水 0.71 より上）はくっつき、中くらいに乾いた粒はかたまって房（2段）、とても乾いた粒（0.64 より下）はばらばらのまま（1段）。
- 湿った切れ（0.83 より上）は、離れていても寄りあう（どろり）。
- 7段の分け目は水の平均と切れ・房・粒の数（`gradeOf`）。水の分け目は `RULE.wMelt / wMush / wSoft / wSmooth`。
- 日なたの帯（めずらしい花）は池の手前までに等間隔に 8 本、岸はでたらめ（はじめは、でたらめに置いたら1本しかない川があった）。

## 自動の遊び手の結果（2026-11-07、川 30 本）
| 押し方 | 段の数（1〜7） | 4段 | めずらしい花 |
|---|---|---|---|
| 指を上・右岸寄り（u1 x0.9） | 0 0 5 25 0 0 0 | 83% | 0.0 |
| 指を上・まん中（u1 x0） | 0 0 0 0 0 6 24 | 0% | 0.0 |
| まん中で少しゆっくり（u0.4 x0） | 0 0 0 0 23 7 0 | 0% | 0.0 |
| 右岸寄りでゆっくり（u0.4 x0.9） | 9 21 0 0 0 0 0 | 0% | 0.2 |
| はなしたまま | 30 0 0 0 0 0 0 | 0% | 0.6 |
| smart（水を見て日なたで飲ませる） | 2 0 16 12 0 0 0 | 40% | 2.0 |
- **わかったこと**: 7段すべてが、押し方しだいで出る。決まった押し方では「4段」と「めずらしい花」を両方は取れない（4段がいちばん出る押し方は、めずらしい花が 0）。smart はめずらしい花を取るが、日なたでとどまった玉だけが乾いて、池でくっつけずに 3段になりやすい（玉ごとの乾きのむら）。
- **気になること**: 「指を上・右岸寄り」だけで 4段が 83% 出る。4段だけを狙うなら考えなくていい。めずらしい花を点にする（4段＋花の数）なら、とりあいは成り立っている。A2 で決める。

## 批判役の指摘（2026-11-07、A2 の画面。反映したもの）
1. 自分で咲かせた花が見分けられない → 遠くの花畑を岸から離し、岸から 4 までの花は区画が飲むと咲く。咲くと花びらがふき出す（めずらしい花は星も）。
2. しずくの水の量が読めない → 湿っているほど透けて縁が虹色、乾くほど中がはちみつのように光る（`dry`）。乾いた玉ほどよくきらめく。
3. 琥珀の玉がたてに積み重なった絵がいちばん答えをもらす → 色の終わりを はちみつの金に。池では玉が左右にゆらゆら広がる。
4. アーチの締まりが見えない → 水面に光の帯（幅＝通れる幅、色＝水色→赤むらさき）。カーテンの花は少なく大きく。
5. 光の筋がガラスの板に見える → カメラへ向く板で、横はふわっと消える。
6. 水面の白いかたまり → 濃淡だけにして、白は小さくまたたく点。
7. 手前のカードの四角いふち → 絵の表を内側から読む・カメラのすぐ前はうすく。
8. スマホの重さ → `backdrop-filter` のぼかしをやめ紙色のグラデーションに、遠くの花畑は 200 ごとに分けて映らない分は描かない、スマホは DPR 1.5 まで、毎こまの一時オブジェクトを使い回す。
9. 知らせが目立たない・視界をふさぐ → 泡の帯を太く波打つ帯に。知らせは教えることばと同じ1行（一度に1つ）。
10. おわりが地味 → 花が咲くと花びらと星がふき出す。結果のカードは 4.6 秒後に下へ寄せて、池の花が上に見えるように。

## 確認のしかた
1. `node flower-brook/tools/autoplay.mjs --seeds=30` がエラーなく終わり、smart の 4段が 30% 以上・めずらしい花 1.5 以上、決まった押し方は めずらしい花 0.5 以下で 4段 ほぼ 0% か、4段が出ても めずらしい花が 0 に近い。
2. 画面: `http://localhost:8797/flower-brook/`（manabi-lab の `.claude/launch.json` の `games`。ブラウザの窓が隠れていると、こまが止まる）。タイトル →「はじめる」→ 指を置くと進み、はなすと止まって岸の花が咲き、花びらがふき出す。右岸寄りでゆっくり下ると、しずくが金色になり、アーチの下の光の帯が赤むらさきのときに通ると粒にちぎれる。池でゆらゆら広がり、数秒でつぼみに吸いこまれて花が咲き、4.6 秒で下にカード。タイトルの庭に1つ増える。
3. 幅 1280×720・375×740・812×375 で、タイトル・遊び・おわりのカードがはみ出さず、列が指（画面の下半分）で隠れない。コンソールにエラーがない。
4. しらべ: コンソールで `__fb.start(3)`、`(await import('./js/sim.js')).step(__fb.S, {hold:true,u:1,x:0.9})` をくり返すと早送りできる。
