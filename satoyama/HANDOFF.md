# 引き継ぎ資料（2026-11-07）

別のセッションで再開するためのまとめ。くわしい決めごとは `PLAN.md`、仕組みと記録は `DEVNOTES.md`。

## 1. このゲームは何か
- 「里山」（仮）。日本の里山の実在の生き物が、本物どおりに暮らす 3D の箱庭。
- ユーザーの言葉（そのまま守る）:
  - 「3D空間で自然界の動物がリアルに生活するところをまず作ろう。モデルとか全部一から刷新していい」
  - 「しぐさや食生活、排泄、睡眠など、リアルに再現して。時間の概念も入れて」
  - 「骨と筋や歩き方などは学習前提」
  - 「まずは現代のリアルな生態系と生物を再現して、それからゲーム向けにカスタマイズしていこう」
  - 「声で成長させたりすることは変わりないので、そこはお忘れなく」（こえのこ `../voice-pet/` の芯。段階Dでのせる）
  - 「既存のリソースを無理に使おうとするがあまり遠回りになったりゴールが遠ざかるようなことがないように」
  - 「本物の跳び方を手本に」（学習のしかた）
- ユーザーが選んだこと: 新しいフォルダ・日本の里山・学習は手元で回して結果をページに入れる・時間は昼夜と季節と年齢（1日12分・1年12日）・暮らしは本物で見た目は見くらべて決める・体は 3D の物理・A〜C のあいだ遊ぶ人は眺めるだけ。

1. 暮らし（A-2）: 止まっているときのしぐさを増やす（伏せて耳を倒す・毛づくろいで泥を落とす・草を食べる）。姿勢は物理の関節のねらいで作る（学習しない形）。時刻で切りかえる。

## 4. ファイル
- `PLAN.md` 企画（柱・生き物・段階・ユーザーが決めたこと）。`DEVNOTES.md` 仕組みと学習の記録。
- `js/ground.js` 地面（高さの式と Rapier の heightfield）。
- `js/hare.js` ノウサギの体（`buildHare`）、筋のリズムと反射（`drive`、数は `PARAMS`）、体のむき（`pose`）。
- `js/trial.js` 試し（`trial`）と点数（`score(r, 秒, すべりの重み, 手本の重み)`）、足が地面についているか（`contactPoint`）。
- `js/reference.js` 本物の跳び方の手本（`HOP`、`shape` で一致を 0..1 に）。
- `js/gait-hare*.json` 学習したリズム。`gait-hare.json`＝いまのもの（2段目を途中で止めたので不安定かも）、`-p1`＝新しい体の1段目、`-imit`＝短い体で手本に合わせたもの、`-walk`＝左右交互の歩き（ずれの範囲をしぼる前）。
- `tools/learn.mjs` 学習（`node learn.mjs 回数 つづきから(0/1) 段(straight/turn) すべりの重み 手本の重み`）。記録は `tools/logs/`。
- `test/hop.html` 3D の確かめ（`http://localhost:8780/satoyama/test/hop.html`。`?gait=imit` で `gait-hare-imit.json` を読む）。確かめ用に `window.__hop.advance(秒)`・`__hop.stats`。

動かし方:
```
cd satoyama/tools && npm install
node learn.mjs 100 0 straight 1.5 0
```
1回の試し（6秒）は約0.25秒。150回 × 32 で約20分。バックグラウンドで回して、終わってから `tools/logs/` を見る。

## 5. 調べたこと（生き物監修・別ゲーム調査の要点）
- 最初の8種: ニホンノウサギ・ホンドタヌキ・アカネズミ・キジ・コナラ・ススキ・フトミミズ類・センチコガネ。
- ノウサギ: 夜行性・単独・巣穴を持たず昼は藪で伏せる・昼の糞は食べ（食糞）夜の糞は散らばる（平川 1996）・後ろ足が前足より前に着く跳び方。
- 跳び方（手本）: ウサギ科はハーフバウンド。前足は左右交互・後ろ足は左右同時（アナウサギ Carneiro ら 2021）、前足のつく時間は後ろ足より短い（Hildebrand 1977）、後ろ足のつく時間 0.40±0.15 秒（アナウサギ Hall ら 2022）、後ろ足の左右のずれ 6.7〜20ms・背中は宙の前半で伸び後半〜着くまでに丸まる（ナキウサギ Schilling & Hackert 2006）。**ノウサギ属の足ごとの数は確かめられていない**（歩数 約4回/秒は仮置き）。
- 似た作品: Equilinox・Species・The Sapling・Ecosystem・WolfQuest・Shelter・Rain World。里山の実在の種を物理の体で動かす作品は見つからなかった。手本なしの学習はばたつく歩き方になりやすい（Peng ら 2020 は犬の動きをまねて学習）。
