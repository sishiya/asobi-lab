# 里山 保管庫に出すまで（2026-11-08 検討）

ユーザー「このすきにゲームとしてリリースにむけてほかになにが必要か検討して」。制作チームの3役（ディレクター・ゲームデザイン・遊び手UX）が別々に見て、まとめた。保管庫に置くのはユーザーの指示のあと（CLAUDE.md）。

## 芯
- 「自分の声から生まれた、よその体の子が、その子なりに動き方を覚えていくのを見守り、ときどきその体に入って走る」（GAME.md 9章）。学習＝成長、不器用さは味。
- 生む → 育てる → 走る は芯の「生む → 覚える → 入る」と重なる（ディレクター）。練習の段を増やして「起き上がる・歩く・曲がる・跳ぶ」と育ちを見せる（ユーザー）。

## 決めてもらうこと
1. **タブの数**: いまは ユーザーの案で「生む・育てる・走る」。ディレクターは「生むは最初の1回の行動なので、同じ重さのタブに並べると何度も押す所に見える。育てる｜走る の2つ＋生むは最初の画面と小さな入口に」をすすめる。→ どちらで行くか。
2. **走るを開けるとき**: ユーザーの「不完全でも試せる」でいまは子がいればすぐ。遊び手UX は「うまれたてで入ると転び続け、失敗が先に来る」と心配。→ 案: いつでも押せるまま、よちよちの間は走るのタブをうすく見せ、押すと「まだよちよち。入ってみる？」と一度だけ聞く。
3. **行き来したくなる理由**（ゲームデザイン）: すすめは「走った地面が、そのまま次の練習の場所になる」（1か所で練習すると、はじめての場所で転ぶ＝本物の学習どおり）＋「藪めぐり」（藪7つほど。着いた藪に毛の色の足あとが残り、ぜんぶめぐるとその子の足あとの地図）。秒の表示と順位は外す（くらべっこを誘う＝9.7）。
4. **声で育てる意味**: 見た目が寄るのは「名札」のまま。声をかけるほど慣れて、呼ぶと耳を立てて寄ってくる・入る前にこちらを見て待つ、などのしぐさで見せる（ゲームデザイン）。罰（声をかけないと操作が悪い）は入れない。
5. **柱の書き直し**: PLAN.md 1章の「本物の箱庭」と GAME.md の「声の子」が2本立て。芯の文を1つにする（カードの一言のため）。

## 出す前に必須
- **どの子も最後には歩ける**: 練習を終わるまで回すと、16頭のうち12頭が4か所の確かめを 35〜65 世代で通った（行きづまって歩き方を変えた子は 0）。ただし終わりの歩きを別の8か所で試すと 1〜8/8 とばらつく → 曲がる練習で、まっすぐの強さが落ちていないかを見る。（`tools/practice-survey.mjs`、`logs/full-*.txt`）
- **転んだあと**: いまの 0.8 秒の作り直しはぱっと消えて不具合に見える。自分で起き上がる練習（`js/getup.js`、試し中）か、身ぶるいで毛を整える演出で包む。起き上がれなければ 1.5〜3 秒で演出で起こす（もがく姿を長く見せない＝9.7）。
- **入口のページ**: `test/` でない `index.html`。最初の30秒（話す → たまご → かえる → よろけて歩く）と声のみほん。
- **マイク**: はじめて押すと許可の画面のあいだに指をはなした知らせが過ぎ、録音が止まらなくなる → はじめては許可をとるだけ、指がはなれていたら「もう一度、押しながら話して」。マイクを開く前に「声は送らない・残さない」。
- **スマホ幅（375）**: タブの字が2行に割れる（`white-space:nowrap`、高さ 44px）。名前のカードがタブに重なる。かえった直後「この子を育てる」と下のまとまりが 4px で押しまちがえる。子が近すぎて左右が切れる（せまい幅はカメラを引く）。走るは上に3段つまる。
- **「声のみほん」の見出し**: 6つのボタンに名前がない（文では「声のみほん」と呼んでいる）。ボタンを 36px 以上・2列×3。
- **ことば**: 「まだ練習がたりないみたい」→「もうすこし練習してからにしよう」（子を評する文にしない）。めもりはその子の歩みだけ。
- **重さ**: 練習の Worker・物理・フェルトの皮をいっしょに回して、スマホのたて・横と PC で動くか・熱くならないか。
- **声を残さない**の確かめ: localStorage に入るのは名前・遺伝子・歩き方の数だけ。解析に声の値を送らない。
- **体の見た目の確かめ**（9.7）: 出せる形の幅を、横・前・上・動いている途中で並べて目で見る。関節の逆曲がり・脚のふるえ（ふみ出しの反射で出た速いふるえのたぐい）が出ないか。
- 版の決まり（RULES 3章・8章）: v番号・ランチャー・保管庫のカード・サムネイル・解析の1行・`?v=`（「保管庫へ」のあと）。

## あるとよい
- 鳴き声（こえのこと同じく、その子の体から合成して自分の声に似る）。育つ間の静かな環境音。
- 声を聞いているときの手ごたえ（ボタンのふちが声の大きさでふくらむ）。
- ボタンに動詞と印（生む＝たまごの印「話してたまごをつくる」、育てる＝子の印「話しかける」）で見出しを消す。生むで子がいるときは、話す前に一度「新しい子をつくると、いまの子は野にかえる」。
- 声で変わった所の一言（「耳がのびた」）。名前が書きかえられる印（鉛筆）。からの巣に1文「声をふきこむと、その声から子が生まれます」。
- 走る: 光る藪の目立たせ方と画面の外の向きの印・スマホの案内から「矢印キー・WASD」を外す・カメラと揺れと雨を「見え方」1つに・近くの大きな藪も透かす。
- 泥と雨を声の子の走るにも（いまはある）。

## あと

## 守ること

- 繁殖は「巣・たまご・かえる」まで。保管庫が先、入口へは出さない。
