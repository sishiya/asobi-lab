## 6.5 確かめ方のこつ（次のセッションで同じ失敗をしないために）
- ページの確かめ用: `window.__voice`（`sample(名)`・`advance(秒, 描くか)`・`go(mode)`・`kid`・`pals`・`egg`・`OUT`・`garden`・`profSync(こま数)`）。`window.__pause = true` で毎こまの更新を止めて1こまずつ。
- `advance(秒, false)` は最後の1こましか render しない。render の中で進むもの（色の移り変わり・水浴び・種が落ちる）は `advance(秒)` で。
- アドレスの `#` だけ変えても読みなおされない。`location.reload()` する。止めたままだと DOM の transition が進まず、字がうすく写ることがある。
- ブラウザの確かめは音を消す: 音はページに実際にさわるまで鳴らないので、script の click だけなら鳴らない。音量を 0 にして試したら `localStorage.removeItem('koenoko.vol')` でもどす。
- 消す確かめをするときは localStorage（`koenoko.kids`・`koenoko.garden`）を控えて、もどす。ページを閉じるときに `keep` が書きもどすので、書きかえたらすぐ reload。
- シェルで長い heredoc が「unexpected EOF」で失敗することがある。長い編集は Write で .py を scratchpad に書いて実行。1行の式のうしろに `//` コメントを足すと、続きの `}` まで消して壊れる（2回やった。`node --check` で見る）。
- **「直した」と言う前に再現する**: 皮の崩れは、再現せずに原因を決めて1回はずした。向き 0 で作ってから付けかえる、が本当の原因（2.8 章）。
