# 里山（仮）— 本物の里山で、生き物が本物どおりに暮らす

2026-11-07〜。こえのこ（`../voice-pet/`）の会話から。

## 1. 柱（ディレクター）
1. **本物どおりに暮らす**: しぐさ・食べる・排泄・眠りが、時刻と季節で切りかわる。手本のある数だけ使い、見立ては分けて書く。
2. **体は物理、歩き方は学んで身につく**: 骨・筋・重さで動き、その種らしい歩き方は学習で出る（決まった動きの絵を使わない）。
3. **時間がめぐって里山が変わる**: 昼夜・季節・年齢。
- （4. 声で育つ — 段階Dで本当の柱にする。席だけ取っておく。体の表し方は `../voice-pet/evo/phys.js` とそろえ、声で生まれた子も同じ物理と同じ暮らしの決まりにのせられるようにしておく）

## 2. 最初の生き物（生き物監修。出典はくわしくは DISCUSSION.md に）
- 動物: ニホンノウサギ・ホンドタヌキ・アカネズミ・キジ。植物: コナラ・ススキ。土: フトミミズ類・センチコガネ。食べる・どんぐりを埋める・糞が土にかえる・芽が出る、のめぐりが閉じる組み合わせ。
- **ニホンノウサギ**（A の1種）: 夜行性で単独、巣は持たず昼は木の根元や藪で伏せて休む。ねぐらから 300〜400 m。葉・芽・枝・樹皮、秋〜春は根茎や実生。昼休む間の糞は食べ（食糞）、夜の活動中の硬い糞は捨てる＝夜に歩いた所に丸い糞が散らばり、ねぐらに糞はない（平川 1996）。跳び方は後ろ足が前足より前に着く（足あとがY字）。毛と目の開いた子が地面のくぼみで生まれる。
- **ホンドタヌキ**（B）: 夜〜薄明薄暮、雑食（土地で変わる）、ため糞（決まった場所に積もる・種が芽を出す）、秋に太る（和歌山 5月3.4kg→11月4.1kg）、冬眠しない、出産5〜6月に平均4〜5頭。
- **アカネズミ**（B）: どんぐりを運んで埋める。忘れたどんぐりが芽生える（数は未確認）。**コナラ**: どんぐりはその年の秋、年ごとに豊作・不作。
- **キジ**（C）: 昼行性、ふだん歩いて走り、飛ぶのは短い距離。春の早朝に母衣打ち。
- よくある間違い（しない）: ノウサギを巣穴や群れで描く・ニンジン・前足が前に出る跳び方。タヌキの冬眠・アライグマとまざる。キジがよく飛ぶ。一日中うろつく（本物は休む時間が長い）。夜をまっ暗にする（月で見え方が変わる）。
- 睡眠時間の野生の数は見つかっていない → 当面は「休む場所と姿勢」だけ決め、時間は推定と書く。

## 3. 体と学習
- 体は骨・関節・筋・重さ（位置にもとづく計算、筋は2点のあいだの長さ）。こえのこの evo/phys.js の考え方を、種ごとの骨格（ノウサギ: 長い後ろ足・短い前足）に。
- 学習は手元で、報酬は「その種らしい歩き方」に近づける（ノウサギ: ゆっくり跳ぶ・後ろ足が前足より前に着く・速さで歩き方が変わる）。手本の動画やモーションキャプチャは、使ってよい条件を確かめるまで使わない（論文の数で手本を作る）。
- **批判役の指摘**: 横から見た平面の物理だけでは、でこぼこの地面・曲がる・斜面を横切るで足がすべる。学習した物理をそのまま描くと、ぶるぶるして本物らしく見えない。→ ユーザーは **3Dの物理** に決めた（8章）。ぶるぶるは、描くときにならす（見た目だけ）で手当てする。
- 遠くの個体・画面の外は簡単な動きに落とす。「ページでも少しずつ学び続ける」は、重さと崩れのおそれがあるので保留（批判役）。

## 4. 時間
- 案: 1日＝12分、1季節＝3日、1年＝12日（2.4時間）。昼の長さは国立天文台の表（東京で夏至14.5時間・冬至9.8時間）。月の明るさで夜の見え方を変える。**速さはユーザーに聞く**。
- 夜行性のノウサギは、昼は藪で動かない → 昼は「ゆうべの痕跡（足あと・糞・食べあと）」が見える時間。早送りはできごとで止まる案（批判役）。

## 5. 段階（課題は1つずつ）
- **A-1**: 平らな地面と昼夜だけ。ノウサギ1頭が学習で跳べ、Y字の足あとが残る。先に小さな試し: 起伏のある地面で8の字に10秒動かし、足のすべりの距離・1頭あたりの時間・Y字の足あとが出るかを測る（批判役）。
- **A-2**: 草木と季節。休む・食べる・動く・排泄の割合を時刻と季節で切りかえる。藪で伏せて耳を倒す。
- A の「できた」（ディレクター）: 12分の1日を見て、夕方に藪から出る → Y字の足あとで跳ぶ → 芽を食べる → 夜の道に丸い糞 → 朝に藪で耳を倒して伏せる、が目で追える。Y字の割合と時刻ごとの行動の割合を手本の数とくらべる。
- **B**: タヌキ・アカネズミ・コナラの豊作不作。**C**: 土の生き物で糞が土にかえる、キジ。痕跡読み・観察帳は C の終わりまでに。
- **D**: ゲーム向けの手直し。声で生まれ・声で育つ子をこの里山に（こえのこの「育ててくれた声に駆けよる系統」を、本物の地形の上でやり直す）。人の手入れの暦（田の水・雑木林の萌芽更新）を入れるかもこのとき。

## 6. 見た目
- 写実の 3D はブラウザでチープに見えやすい（別ゲーム調査）。好み（汚しと崩れ・ジオラマのぼけ・ボクセルとティルトシフト）とぶつかりうる。**「リアル」が暮らしのことか見た目の写実も含むかをユーザーに聞き**、そのあと見くらべ（`look/`、手元だけ）で決める。A の前に決める。

## 7. 似た作品と差（別ゲーム調査）
- 生態系の箱庭（Equilinox・Species・The Sapling）、学習で動く生き物（Ecosystem・Karl Sims）、動物の暮らし（WolfQuest・Shelter）、生き物が自分のために動く（Rain World）。里山の実在の種を物理の体で動かす作品は見つからなかった。
- 差: 実在の種の歩き方を本物と見くらべられる・里山の時間（暦）。
- まねしない: 体をいじるエディタ・多様性ポイントの通貨・1頭を操作して子を育てる型・水墨のタヌキが主役。

## 9. ユーザーのアイデア（2026-11-07、まだ決めていない。D 以降の候補）
- 「育てたペットをただ眺めるだけでなく、ペットとなって草原を走り回ったり、オンライン要素で他の人が育てたペットと同じフィールドで遭遇できたら面白そう」
- つながり: 体は学習した歩き方で動くので、遊ぶ人は**行きたい向きと速さだけ**を渡す（関節は操らない）。8の字の学習の `turn`（曲がる強さ）と歩く強さ `g` がそのまま操作の入口になる。
- オンライン: 送るのは**遺伝子の数と、いる場所・向き**だけ（声は送らない＝こえのこの約束のまま）。サーバーは「みんなの記録」と同じ `../server/`（Cloudflare Workers）を下敷きにできる。決まりは `../RULES.md` 11章。
- （2026-11-07 ユーザー）「ドロかぶったりしたら汚れをつけたり、雨振ったら洗い流されたり、そういうところもこだわりたい」

  - 地面のほうにも残す（ぬれた土に深い足あと・泥はね）。見た目は見くらべ（`look/`）で、好み「汚しと崩れ」に合わせる。A-2（天気と行動）から。
