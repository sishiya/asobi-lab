# こえのこ（仮）— 声から生まれる生き物

2026-11-06〜。ユーザーの案（IDEAS.md「声から生まれる生き物」）: 声入力から生き物を生成する・声質から遺伝子が組まれ特徴が現れる・ペットになる・場合によっては対戦。
ユーザー「まずは声からペットを作る部分は全ての起点になるとおもうのでまずそこのプロトタイプから」。

## 0. 芯
- **声をふきこむと、たまごが生まれ、その声の特徴を遺伝子にもつ子がかえる。**
- その子の鳴き声は、**その子の体から作る**（声の筒の長さ＝体の大きさ）。だから自分の声に似て聞こえる。
- かえったあとも声をかけると、耳をすまし、自分の声で**まねして**答える。

モンスターファーム（物から生まれる→育てて戦う）の後追いにしない。差は「声と体が本物のしくみでつながっている」ことと、対戦をするなら鳴き比べ（あとの段階）。

## 1. 声 → 遺伝子 → 形（決まり）
手本があるものだけを使う。ないものは「見立て」と書く。

| 遺伝子 | 声のどこから | 手本 |
|---|---|---|
| 体の大きさ | 声の筒の長さ（フォルマントの間かく ΔF。L = c / 2ΔF） | 動物の声は体の大きさを隠せない（Fitch 1997 アカゲザル、Reby & McComb 2003 アカシカ、Taylor 2010 イヌ） |
| 目の大きさ | 体の大きさの逆 | 小さい動物ほど目が体に対して大きい（Haller の法則） |
| 色の明るさ | 声の高さ（F0） | 高い音↔明るい色の結びつき（感覚どうしの対応。Spence 2011） |
| 色あい | 声の明るさ（スペクトルの重心） | 明るい音色↔暖かく明るい色（同上） |
| まるい／とがる | 声のなめらかさと立ち上がり・息の子音 | ブーバ・キキ効果（Ramachandran & Hubbard 2001） |
| 体の形（横長・縦長） | 母音（F1・F2） | 見立て（口を大きくあける声＝横に広い） |
| 毛のふわふわ | 息まじり（HNR が低い） | 見立て（ざらつき・息の音↔やわらかい手ざわり） |
| もよう | 声のゆらぎ（ふるえ・かすれ） | 見立て |
| かざり（耳・えり） | 抑揚の大きさ | 見立て（声で見せる動物はかざりも大きい、のゆるい見立て） |
| 足と動きの速さ | 話す速さ（音節の数／秒） | 見立て |

- 遺伝子は**2本（2倍体）**で持ち、形はその平均で出る（あとでかけ合わせに使う）。1つの声からは2本ともほぼ同じ値に、少しの突然変異をのせる。同じ声でも少しずつちがう子になる。
- 鳴き声: 源（声帯のパルス＋息の雑音）→ 声の筒（その子の L から ΔF を出してフォルマントを並べる）。高さはふきこんだ声の高さ、節まわしはふきこんだ声の上がり下がりの形。

- **体の型も声で決める**（2026-11-07 ユーザー）: その声で鳴く本物の動物の型（高く速い声＝すわる小獣、息まじりの低い声＝シカ型、節のない低めの声＝カエル型、抑揚の大きな声＝ツル型）。
- **ふ化したてはどの子も幼い体つき**（ベビースキーマ）。声の筒の遺伝子は育つにつれて鼻・首・体の大きさに出る（ヒトの声の筒、アカシカののど仏も育つと長く・低く）。見た目は鉛筆（ART.md）。色の遺伝子は鉛筆では毛色の濃さに。

## 2. 手ざわり
- 押しているあいだ声が入るボタン（長押し・スペースキー）。1〜6秒。押すとたまごが声に合わせて光り、ゆれる。
- はなすとたまごが割れて、子が出てきて最初の一声。
- 子をなでる（ドラッグ）・つつく（クリック）と反応して鳴く。声をかけると耳をすまし、まねして答える。
- 右（スマホは下）に「この子の遺伝子」: 遺伝子ごとに、どの声のどこから来たか。

## 3. 声の扱い（決まり）
- **声は端末の中だけで数に変え、送らない・保存しない**。残すのは遺伝子の数だけ（localStorage `voicepet.v1`）。
- 録音の前に、ボタンのそばに1行で伝える。

## 4. 段階
- **段階A（いま）**: 声 → たまご → 子。遺伝子の表。なでる・つつく・声をかけるとまねして鳴く。マイクなしの確かめ `?test=<声の見本>`。
- 段階B: 何匹か巣に置く・名前・2匹のかけ合わせ（2人の声の子）・育つ（大きさは遺伝子で決まり、育ちで変わるのは別の物）。
- 段階C: 鳴き比べ（対戦の形を決める。殴り合いにしない）。

## 5. やらないこと
- 声を送る・保存する・ことばを聞き取る（何を言ったかは使わない。声の質だけ）。
- 人の声の特徴から人を判定するような表示（男女・年齢の判定を画面に出さない。体の大きさは「声の筒の長さ」とだけ）。
