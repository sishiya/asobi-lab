# 里山（仮）ゲーム部分の案（2026-11-07、制作チーム。まだ決めていない）

ユーザーの指示: 「声で生み育て、オンラインフィールドで放牧でき、任意でペット視点で走り回ることができ、他のユーザーのペットと邂逅する」。
ディレクター・ゲームデザイン・別ゲーム調査の3役が別々に案を出し、まとめた。決まったら PLAN.md に移す。

## 1. 芯（案）
**自分の声から生まれた子を本物の里山に放す。子は里山の決まりで自分で暮らす。ときどきその体に入って走り、よその人の子と痕跡で出会う。**
- 4つの要素は1本の線: 声で生む（自分の子）→ 放す（子が自分で暮らす）→ 入る（その体で走る）→ 出会う（よその子に会う）。

## 2. 柱（案）
1. **声から生まれ、声で育つ**: こえのこの芯。声は端末の中で数にするだけ、残すのは遺伝子の数。声は命令でなく「体の材料」（声の筒の長さ→体の大きさ→物理の体→歩き方）。
2. **放せば自分で暮らす**: 声の子も野生の種と同じ決まり（食べる・眠る・排泄・時刻と季節）。放牧は「世話」でなく「暮らしぶりを見る・痕跡を読む」遊び。
3. **入っても渡すのは向きと速さだけ**: 操作は drive の `turn` と `g`。体の気持ち（眠気・空腹）が舵の3割ほどをにぎる。暮らしの主は遊ぶ人でなく子の体と暦。
4. **出会いは里山の中で起きる**: 足あと・糞・食べあと・におい。文字も名前も使わない。送るのは遺伝子の数と場所・向きだけ。

## 3. 少ない決まり（ゲームデザイン）
決まりは3つ。4つの要素はこの組み合わせで動く。
- **慣れ**（くり返し会うものに慣れる。強い刺激では過敏に）: なつき・友だち・雨を気にしない子・入っても暴れない子が、決まりを足さずに出る。
- **ふれた所が入れかわる**（泥・足あと・におい・種）: 泥の足の子は泥色の足あとを遠くまで残す。雨は体の泥も古い足あとも流す（雨上がりは痕跡が新しく出会いやすい）。毛づくろいで落ちる・乾くと色が変わる。食べた実の種が糞から芽を出し、草木の場所が少しずつ変わる。
- **親になるのは、声に応え、しかも里山で冬を越した子**: 声で選ぶ＝家畜化、冬を越す＝自然選択。なつかせすぎると幼い体つき（Trut 1999 の見立て）で冬に弱い。この引っぱり合いが育てる芯。死ぬ場面は見せない（こえのこと同じく「眠る」）。

## 4. 遊びの流れ（案）
- **最初の30秒**: 夕方の藪の前に「押したまま話しかける」の1行だけ。2〜3秒話すと地面のくぼみから子が出て、あなたの声に似た一声で鳴き、よろけて数歩。もう一度話すと寄ってくる（ノウサギの子は毛も目も開いて生まれ、すぐ動ける）。
- **1回（里山の1日＝12分）**: ゆうべの痕跡を読む → 話しかける → 夕方に放すか、入って走る → よその子の痕跡・姿 → 朝に呼び戻すと藪で伏せて終わり。
- **何日も**: 季節がめぐり（1年＝12日）、冬を越すと系統が変わる。よその子との子も。

## 5. 出会い（案）
- まず**すれちがい型（非同期）**: 開いたときに何頭かぶんの遺伝子とねぐら・通り道を受けとり、その子たちは手元の計算で里山に暮らす。痕跡が先に見つかり、夜に姿が出る。本物の野生の出会い方と同じ。RULES 11章（通信は開いたときとボタンのときだけ）・無料プランの上限とぶつからない。
- 同時に同じ場所にいる形は次の段階（11章を変えることになる）。物理は各端末で計算し、送るのは数秒に1回の場所と向きだけ、1つの谷に数人まで。
- 出会いのふるまいも「慣れ」で: はじめは距離をとってにおいをかぐ、くり返し会うと並んで食べる・近くで伏せる。
- 子が生まれるのは、春に同じ場所で何度も伏せた2匹で、両方の遊ぶ人が「迎える」を選んだときだけ（繁殖まわりの本物のふるまいは入れない）。

## 6. 似た作品との差（別ゲーム調査）
部品の先例はある（声で育てる Seaman・外の物から生まれる モンスターファーム・他人の生き物が来る Spore／Peridot・動物の目で走る WolfQuest／Shelter・無言の出会い Journey／Sky・非同期の痕跡 Death Stranding）。つないだ作品は見つからない。
1. 自分の声の質が、物理の体と歩き方になる（声＝命令でなく材料）。
2. 出会いが生き物の痕跡（文字・名前なし。タヌキのため糞は本物でもにおいで知らせ合う場所）。
3. 入っても暮らしは本物のまま（操作する主にならない）。
- 学ぶ: 自由に作れる物に手当てがないと荒れる（Spore）。交流の手ざわりが薄すぎると続かない（たまごっち Uni の出たばかりのころ）。遺伝子の数だけを送り形は手元の決まりで作るので、変な投稿は起きにくい。

## 7. ぶつかる所（ディレクター）
- **7章「1頭を操作して子を育てる型をまねしない」**: 柱3の線引き（入るのはひととき、暮らしは体と暦）で差をつける。7章の文をこの意味に書き直す。
- **本物の暮らしと声の子**: こえのこの子は体節や足の数が変わる「里山にいない生き物」。(a) 実在種（まずノウサギ）の1頭で、声は個体差（大きさ・毛色・耳・鳴き方）／(b) よそから来た生き物で、体は自由だが里山の決まりに従う。ディレクターは (a) をすすめる（学習もいまのまま使える）。ゲームデザインの折衷案: 体を変える遺伝子を2つ（大きさ・後ろ足と前足の比）にしぼり、3×3＝9体をあらかじめ学習して間をつなぐ。
- **声を送らない約束**: 遺伝子の数だけなら守れる。ただし受けた側は遺伝子から鳴き声を合成するので、声の高さ・太さに似た鳴き声がよその人に聞こえる → はじめて送るときの見本に書く。名前は自由な文字にしない。
- **far-caravan の「ペットにしない」**: 別作品なのでそのまま。里山でペットになるのは声の子だけ、野生の種は野生のまま（なつかない・世話しない）。

## 8. 段階の組み直し（案）
1. A-1（いま）: 8の字が跳べる体をページで確かめる。
2. **A-1+「入って走る」**: `turn` と `g` に向きと速さをつなぐ。カメラは子のうしろ、スマホは「行きたい所をさわる」1本指。泥の汚れもここから。**遊べる最小の形**。測る: はじめての人が30秒以内に3m 先の藪に着く割合（目安8割）・転ぶ割合・入力から曲がり始めまでの遅れ。フィールドはまず 30〜40m 四方のジオラマ。
3. 「影の子」: 前回の自分の走りをもう1頭として流す（サーバーなしで非同期の出会いの気持ちよさを確かめる）。
4. A-2 暮らし（休む・食べる・排泄・毛づくろい・天気）＝放牧の土台。
5. 声で生む（いまの D を前へ）。
6. 出会い（すれちがい型。`../server/`）。
7. 野生の種を足す（タヌキ・アカネズミ・コナラ・キジ・土の生き物）は並行。

## 9. ユーザーが決めたこと（2026-11-07）
1. **声の子は (b) 形が進化するよその生き物**。「チャレンジングですが、ここは外したくない。不器用な走り方でも、それが味になる。がんばれと応援したくなる」
   - → 体の形ごとに歩き方を覚える必要がある。うまく走れることより、**その子なりに覚えていく姿**を見せる。案: 生まれた子が端末の中で歩き方を学習し、ばたつき → よろよろ → その子なりの走り、と育つのをそのまま見せる（学習＝成長）。体の形の幅は、いまのノウサギの体（骨と関節と筋）を部品にして組みかえる。
   - 野生の種（ノウサギ・タヌキ…）は本物のまま。声の子は「よそから来た生き物」で、体は自由だが里山の決まり（食べる・眠る・排泄・天敵・冬）に従う。
2. **出会い**: 「サーバに遺伝子情報を保存しておき、適宜ダウンロードして召喚します。いろいろな容姿、歩き方の個体を見てたのしむ」
   - → サーバー（`../server/`）に遺伝子の数（＋覚えた歩き方の数。どちらも小さな数の並び）を置き、端末が何頭かを受けとって手元の里山に呼ぶ。同時に同じ場所にいる形はとらない。声は送らない。
3. **段階の並べかえ OK**: 入って走る → 暮らし → 声の子 → 出会い。「A〜C は眺めるだけ」はやめる。
- まだ: 留守のあいだに進める時間の上限（ゲームデザイン案は最大1日分＝12分）。鳴き声の節まわし（高さ8点）を送ってよいか。

## 9.5 ゴールの学習からわかること（ゲームの中の学習を決める材料）
ユーザー（2026-11-07）: 「完成形をいま学習させているのは、まずゴールが望むものであるかそもそも実現できるかの検証のため。どれくらいどのように学習させたら走れるようになるのか知るためのもの。ゲームでは、どの段階から学習を始めればいいか、どの方向に学習を進めればいいかは要検討ですが、ゴールの学習結果が役に立つはず」。
ゲームでは、生まれた子が端末の中で学習し、ばたつき → よろよろ → その子なりの走り、と育つのを見せる（学習＝成長）。

ノウサギの体（剛体15・関節19）でここまでにわかったこと（くわしくは DEVNOTES）:
- **出発点がいちばん効く**。数を真ん中から始めると100世代でも動けない。広くばらまいても 300 回中「転ばず 0.5m」は 0。**本物の跳び方の形**（後ろ足は伸ばす向きをそろえて左右同時・背骨は蹴るときに伸ばす・前足は半周ずらす）から始めると、1世代目から跳ぶ。→ ゲームでは「その体の形から決まる手本の出発点」を、遺伝子から作って渡せばよい（どの方向に学習を進めるかの答えの1つ）。
- **体のしくみが足りないと、学習では埋まらない**。足が前後にしか曲がらないあいだは、何回学習しても横に転んだ。横へ開く関節と「傾いた側へ足を出す反射」を足したら、すぐ転ばなくなった。→ どの体にも、立ち直りの反射（前後・左右）をはじめから入れておく。反射の強さも学習する。
- **点のつけ方の順番（段）**: 1段目は転んでもよい・すべってもよいから動く → 2段目で転ぶ罰とすべりを重く → 3段目で曲がる。→ 成長の段階としてそのまま見せられる（ばたばた跳ぶ → 転ばなくなる → 曲がれる）。
- **1か所だけで学習すると、はじめての場所で転ぶ**（8か所中3か所）。→ ゲームの中の学習は、その子が歩いた地面そのもので進めれば自然に広がる。
- **かかる量**: 1回の試し（6秒）は Node で約0.1〜0.25秒。1段目は 100世代×32頭（約3200回・数分）で Y字が出た。2段目で転ばなくなったのは横の反射を足してから数世代。8の字は 100世代。ブラウザで1頭ずつ見せながら学習するには、もっと少ない回数で育つ形が要る（例: 手本の出発点＋反射があれば、数十回で「よろよろ走る」まで行けるか、を次に測る）。
- 見た目の不器用さはそのまま味になる（ユーザー）。点を「速さ」ではなく「転ばずに前へ」で頭打ちにしておけば、無理にきれいな走りに寄らない。

- **声の子の体でも、2段の練習で数十〜百数十回の試しで歩ける**（2026-11-08、`js/kid.js`）: 遺伝子から作った6本足は 49回目、よつあしは 119〜145回目に「転ばず1m」。1回の試し（6秒）は手元で 0.1〜0.2 秒なので、端末の中でも数分で「よろよろ歩く」まで育つ見込み。手本の出発点は、どの体にも同じ「のっそり歩く（横の順）」でよかった。止まって動かない形に逃げないよう、はじめは転んでもよいから前へ、の段がいる。

## 9.6 アイデア: 鳥も学習で（2026-11-07 ユーザー「鳥とかも学習で再現できるんですかね？」）
- 歩く・跳ねる鳥（キジ・スズメ）は、ノウサギと同じしくみ（骨・関節の筋・反射・手本の出発点）でいける。2本足は倒れやすいが、首を前後にふる歩き方など手本がはっきりしている。
- 飛ぶには、翼の骨ごとに空気の力（面の向きと速さから揚力・抗力を出す簡単な式）を足す（Rapier に空気はない）。先例: Won ら 2017 "How to Train Your Dragon"（物理の翼を学習ではばたかせる）、Wu & Popović 2003。学習の量は歩くよりずっと多い。
- 段: 歩く・跳ねる → 斜面から滑空 → 短く羽ばたいて飛び上がる（キジ）→ 長く飛ぶ。
- 声の子に翼が生える系統が出たら、飛べずにばたつく → 少しずつ滑空、が「不器用さが味・応援したくなる」成長になる。

## 9.7 体の不自由さに見えないための配慮（2026-11-07 ユーザー「配慮はその方向で」で決めた。きっかけは ユーザー「身体障害をもつ方への配慮が必要なくらいリアルになってしまった」）
羊毛フェルトの皮をのせたら、物理の体と学習した動きが本物らしく見えるようになった。そのぶん「不器用な走り」「転ぶ」「ばたつく」が、けがや体の不自由な生き物に見えるおそれがある。笑いものや「かわいそう」の見せ物にしない。
1. **不器用さは「育ちの途中」と「よその体」の味として見せ、欠けとして見せない**。どの子も練習で自分なりの走り方に行きつく（いつまでも転び続けない）。走り方を「ふつう」と比べて点にしない（速さの順位を出さない・「上手／下手」と言わない）。
2. **特定のけがや病気に似た動きを出さない**: 片足を引きずる・片側だけ動かない・ふるえ・足がだらりと垂れる・関節が逆に曲がる・地面にめりこむ。学習の点に左右のそろいを入れる（`turn2` でまっすぐ流れるくせは消えた）。声の子の体は左右対称で生まれる（遺伝子の決まり）。物理のくずれ（関節の逆曲がり・ぶるぶる）は描く前にならす。
3. **転んだときの見せ方**: 失敗の音・文字・ゆっくり映す・痛そうな姿勢で止める、をしない。すぐ起き上がる（体をふるって毛を整える＝本物のしぐさ）。「ころんだ」の文字は試しのページだけ。
4. **見た目は作り物の側に置く**: 羊毛フェルトのおもちゃらしさを保つ（傷・血・骨が出る・やせ細る、を描かない）。「力のすけ見」（骨と筋が見える案）は医療の画像に見えないかを先に確かめる。
5. **ことば**: 「障害」「欠陥」「不具合」「かわいそう」を生き物に使わない。「その子なりの走り方」「練習中」。
6. 本物の里山にも、けがをした動物はいる。でもこのゲームでは描かない（暮らしの本物さは、食べる・休む・痕跡で出す）。
7. **体の形**（ユーザー「体の形です。いわゆる奇形というやつですね」）: 実在の種は本物の寸法と輪郭に合わせ、動いても皮が崩れない（こぶ・くびれ・のびすぎ・つぶれ）ようにする。声の子は「ノウサギが崩れた形」ではなく、**別の種として整った形**にする: 左右対称・部位の太さと長さがつり合う・つなぎ目が自然・どの部位にも役目がある（使わない手足をぶら下げない）。形の幅は遺伝子の決まりの中で、整った形にしか行かないように作る。
8. 確かめ: 新しい体は、横・前・上からの止めた姿と、跳んでいる途中の姿を並べて、本物の輪郭とくらべる（`look/felt.html` の「横」）。

## 10. ほかのセクションに残っている問い
- 遊び手・UX: 30秒で「声→生まれた→寄ってきた」が伝わるか。舵の3割を体がにぎっても「言うことを聞かない」と感じないか。入る・出るの切りかえ。
- 検証: 試し1の数・舵の比・9体の学習時間・留守の1日分の計算時間・無料プランで1つの谷に何人。
- 生き物監修: ノウサギの個体差の本物の幅、出会いのふるまい（繁殖にかかわらないもの）、冬越しと体の大きさ、全力の速さの出典、ため糞・足あとで個体を見分けられるか。
- レベルデザイン: 40m 四方の藪・泥・水場・高い所の置き方、出会いの密度。
- アート・音: 泥の色と乾いた色、泥色の足あとが遠くから読めるか、のどを通った鳴き声。
