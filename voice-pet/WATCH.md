# 眺める・年をとる・最期（案。2026-11-08）

ユーザー「かれらの眺めるモードも考えておいて。どのタイミングで入れるかは別途。フェルトのうんちをしたり、もふもふのごはんをたべたり」「加齢で、フェルトが黄ばんでいく・ところどころ起毛がはげてくる」「寿命で心拍が止まるのは悲しそうだが、体験してみたい」。
いつ入れるかは決めていない（RELEASE.md の「あと」）。決まりは GAME.md 9.7（体の配慮）と、PLAN.md の本物の暮らし（食べる・排泄・眠る）。

## 1. 眺める
- **何をする画面か**: 子が草原で勝手に暮らすのを、ジオラマの外から見る。遊ぶ人は見ているだけでよい。声をかけると耳を立てて寄ってくる（育てると同じ「声をかけて育てる」）。
- **場面**: 育てるの草原を少し広げ、巣・水場・ごはんの草むら・日だまりを置く。カメラはゆっくり回る見下ろし（ティルトシフトを強め）。タップで寄る。
- **1日**: PLAN の「1日12分」。朝に起きて食べる → 昼は日だまりで毛づくろい・昼寝 → 夕方にまた食べる → 夜は巣で丸くなって眠る（呼吸がゆっくり、耳がたまにぴくっ）。
- **ごはん**: もふもふのフェルトの草の玉（クローバーやイネ科の穂の形。色はやわらかい緑と白い花）。子は鼻を寄せてはむはむし、玉が毛玉のほぐれる形で少しずつ小さくなる。食べ終わると、数時間（ゲームの時間）で同じ所にまた生える。
- **うんち**: 本物のノウサギと同じ、丸いころころ（直径 1cm ほど）。フェルトの小さな玉で、こげ茶とよもぎ色のまだら。食べたあと少しして、しっぽを少し上げて、ぽろぽろと数個。
  - 見せ方は図鑑の目線で、ことばは「ころころ」（画面に「うんち」と大きく出さない）。音はかわいい小さな音にしない（からかいにしない）。
  - ころころは土にかえって、そこの草が少し濃く、ごはんが早く生える（めぐり。果ての滝の箱庭の「土の肥え」と同じ考え）。眺めているうちに、子がよくいる所の草が育つ。
- **泥と雨**: 走るで泥がついた子は、日だまりで身ぶるいして泥を落とす（泥は毛先の表面のかたまり＝js/felt.js）。雨の日は巣にこもる。
- **体の配慮**（9.7）: 眠る・食べるの姿勢も左右対称・関節は本物の向き。ぐったりして見える姿勢（横倒しで動かない）は、眠るときも使わない（丸くなる・伏せる）。

## 2. 年をとる
- **見た目**: フェルトが黄ばんで少しくすむ・ところどころ毛羽がはげて下のフェルトが見える（年 0..1、`FB.setAge(a)`。試しは js/felt.js）。毛羽のはげは左右どちらかに寄らない、全体にまだらに（片側だけの脱毛は病気に見える）。
- **動き**: 歩く速さが少し落ちる、眠る時間が長くなる、日だまりにいる時間が長くなる。ふるえ・ふらつき・足を引きずるは出さない（9.7 の4）。
- **長さ**: 本物のノウサギは野生で 1〜5 年ほど。ゲームでは「育てた日数」でなく、遊んだ時間で年をとる（放っておいた間に死なない）。目安は合わせて十数時間ほど遊んで年寄りに（決めるのはあと）。
- **前ぶれ**: 年寄りになったら、育てるの左上に「このごろ、よく眠る」のように一度だけ出す（数字の残り時間は出さない）。

## 3. 最期
- **起きること**: 年寄りの子が、晴れた日の昼に日だまりで伏せて眠る。呼吸がだんだん遅く浅くなり、1分ほどで止まる。耳はもう動かない。
  - 痛そう・苦しそうな動き（もがく・ふるえる・あえぐ）は出さない。突然倒れない。事故・病気・天敵では死なない（走るで転んでも死なない）。
  - 呼吸は胸のふくらみで見せる（いまの `breathe`。心臓の拍は見えないので、拍の音や線は出さない）。
- **そのあと**: カメラはそのまま、まわりの草がそよぎ、日が少しかたむく。遊ぶ人が「おやすみ」を押すまで、子はそこにいる。
  - 押すと、子の体はやわらかくほどけて、そこに子の毛の色の花が咲く（フェルトの毛がほどける形。消えるでも、骨や体の中は見せない）。
  - 巣には、その子の声の遺伝子を少し受けついだたまごが1つ残る（生むと同じかえり方。親の名前は花のそばの小さな札に）。
- **選べること**: 設定で「年をとらない」を選べる（子どもが遊ぶとき・つらい人のため）。はじめて年寄りになる前に、一度だけ「年をとって、いつかお別れがあります」と知らせる。
- **ことば**: 「死んだ」は使わず「ねむった」「おやすみ」。説明の文（図鑑）は本物どおりに「生き物はいつか死ぬ」と書いてよい。

## 4. 作る順（案）
1. 眺めるの1日（起きる・食べる・ころころ・眠る）を、いまの体と歩き方のまま（食べる・眠るの姿勢は、立つ姿勢から首と足をゆっくり曲げるだけ）。
2. ごはんの玉の生え方・ころころの土へのかえり方（めぐり）。
3. 年の見た目（いまの `setAge`）と動きの変化。
4. 最期と、たまごの受けつぎ。ユーザーに実物を見てもらってから、ことばと間を決める。

## 5. 決めること（ユーザー）
- 眺めるを、タブ（生む・育てる・走る・眺める）にするか、育てるの中の「見守る」にするか。
- 年をとる速さ。年をとらない設定のはじめの値。
- 最期のあと、たまごが残る（代がつながる）か、ひと区切りにするか。
