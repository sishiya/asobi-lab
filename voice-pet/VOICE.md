# 声 → 子 の対応表と計算式

2026-11-10 にユーザーの依頼で作った。**作り手用**。遊ぶ人に見せるかは未定。
元の式は `js/features.js`（声の数）・`js/voice-founder.js`（型と体）・`js/kid-look.js`（見た目）。見本の表は `node tools/voice-table.mjs` で出し直せる。

## 1. 声 → 0..1 の数（`features.js` の `analyze`）

`norm(v, a, b)` は a を 0、b を 1 にして 0..1 に切りつめる。声そのものは、この数にしたら捨てる。

| 数 | 式 | 意味 |
|---|---|---|
| pitch | norm(log2 F0, log2 85, log2 420) | 声の高さ（F0 は中央値 Hz） |
| tempo | norm(音節数/秒, 2, 8.5) | はやさ |
| breath | norm(非周期の度合い, 0.04, 0.4) | 息まじり |
| rough | norm(シマー, 0.03, 0.12)×0.3 + norm(ジッター, 0.001, 0.008)×0.7 | かすれ |
| sharp | norm(高域の割合, 0.02, 0.18)×0.6 + norm(立ち上がり数/秒, 1, 8)×0.4 | はじける子音 |
| melody | norm(半音のばらつき, 0.4, 4.5) | 抑揚 |
| size | norm(声の筒の長さ cm, 10, 19) | 声の筒 |
| bright | norm(log2 重心 Hz, log2 260, log2 1500) | 声の明るさ |

卵には 3〜4 回の声を、**声の長さで重みをつけて平均**した数が使われる（`mixGenes`）。

## 2. 数 → 体の型（`typeScores`・`typeZ`・`typeOf`）

2026-11-10 にユーザーの指示で「各型が均等に出る」ように変え、2026-11-11 にタヌキを足して6型にした。計算は3段階。

1. 型の点 S を式で出す（下の表）。
2. ふつうの話し声の中でどれだけ目立つかに直す: `Z = (S − 平均) / ばらつき + 補正`（`TYPE_NORM`）。
3. Z に 0〜0.2 のでたらめを足し、`VOICE_TYPES` の中でいちばん高い型になる。差が 0.2 以上あれば必ずその型。

| 型 | 点 S の式 | 平均 | ばらつき | 補正 | 声で生まれるか |
|---|---|---|---|---|---|
| ヘビ snake | breath×1.4 | 0.195 | 0.299 | +0.546 | ○ |
| ウサギ hop | sharp×1.7 − max(0, tempo−0.6)×1.5 | 0.12 | 0.154 | −0.102 | ○ |
| トリ bird | pitch×0.25 + melody×1.0 | 0.751 | 0.319 | −0.455 | ○ |
| クマ donkey | (1−pitch)×0.2 + rough×1.0 | 0.418 | 0.221 | +0.271 | ○ |
| イタチ bound | tempo×1.3 + rough×0.2 | 1.098 | 0.305 | −0.137 | ○ |
| タヌキ walk | (1−tempo)×0.8 + (1−melody)×0.8 − rough×1.0 − breath×0.5 − pitch×0.3 | −0.096 | 0.456 | −0.122 | ○（のんびりして、すなおな声） |
| アザラシ seal | (1−pitch)×0.8 + (1−tempo)×0.7 | | | | ×（ユーザーの指示で外した） |
| トビネズミ biped | pitch×0.7 + sharp×0.6 | | | | ×（`?debug` だけ） |

平均・ばらつき・補正は `node tools/voice-balance.mjs fit` で作る。合成の話し声（男・女・子ども）300人を、たまごと同じく1人3回の平均にして求めた。**本物の人の声では測っていない。**

別に作った 300 人（`node tools/voice-balance.mjs check`）での分かれ方:

|---|---|---|---|---|---|---|
| 全体 | 21% | 14% | 14% | 17% | 14% | 19% |
| 男の声 | 35% | 11% | 4% | 29% | 8% | 13% |
| 女の声 | 19% | 15% | 11% | 12% | 18% | 25% |
| 子どもの声 | 9% | 17% | 26% | 11% | 17% | 20% |

|---|---|---|---|---|---|---|---|---|
| のんびり | calm | 0.29 | 0.02 | 0.00 | 0.00 | 0.04 | 0.00 | タヌキ |
| たかい声 | high | 0.95 | 0.30 | 0.00 | 0.00 | 0.14 | 1.00 | トリ |
| はずむ声 | bounce | 0.39 | 0.56 | 0.00 | 0.02 | 0.40 | 0.26 | ウサギ |

## 4. 数 → 体（`founder`。j は標準偏差 0.08 のゆらぎ）

| 遺伝子 | 式 |
|---|---|
| seg（胴の節） | tempo×0.7 + 0.15 + j |
| tail（尾） | rough×0.6 + 0.2 + j |
| legs（足の対） | 0.35 + (1−breath)×0.4 + j |
| legLen（脚の長さ） | pitch×0.6 + 0.2 + j |
| girth（太さ） | breath×0.6 + 0.3 + j |
| fluff（毛の長さ） | breath×0.7 + j |
| vtl | 0.5 と (筒の長さ−9)/10 を 0.4 で混ぜる + j |
| f0 | 0.5 と log(F0/80)/log(450/80) を 0.4 で混ぜる + j |
| neck・stop・bold | でたらめ |

そのあと `blendBody` で、型ごとの手本の体へ寄せる: `g = 手本 + (g − 手本) × BODY_NEAR`。

| 型 | 手本の番号 | BODY_NEAR |
|---|---|---|
| ヘビ | 9 | 0.45 |
| ウサギ | 6 | 0.3 |
| トリ | 3 | 0.15 |
| クマ | 1 | 0.25 |
| イタチ | 2 | 0.15 |
| タヌキ | 8 | 0.15 |

## 5. 数 → 見た目（`lookGenes`。j は ±0.04 のゆらぎ）

| 見た目 | 式 |
|---|---|
| 色あい hue | bright + j（暗い声＝藍・すみれ → 明るい声＝珊瑚・杏・菜の花） |
| 明るさ light | pitch + j |
| もよう spots | rough×1.2 + j |
| 耳の長さ ear | melody + j |
| 耳の先 sharp | sharp + j |
| 墨の毛 | pitch < 0.22 かつ bright < 0.25 |
| 白い毛 | pitch > 0.8 かつ rough < 0.3 |

毛の主役はいちばん長くかけた声の色で、はっきりちがう声の色を 2 つまで差し色にする（`voiceTints`）。
育てるで声をかけると、見た目の数が その声の向きへ 35% 寄る（hue・light・spots・ear・sharp。`hear`）。体の型と骨は変わらない。
