# こえのこ 企画と UX のブラッシュアップ（2026-11-08 夜）

ユーザー「ゲームとしてなりたたせるための企画と UX デザインのブラッシュアップをすすめて。基本方針は今の感じでいい」。
制作チーム（ディレクター・ゲームデザイン・遊び手UX）がそれぞれ HANDOFF・GAME・RELEASE・WATCH と画面を見て出した案を、ここにまとめた。

## 1. 柱（ディレクターの言い直し）
**自分の声から生まれた、よその体の子が、その子なりに動き方を覚えていく。その足で、野を少しずつ広げていく。**
- 声は命令ではなく体の材料。学ぶことがそのまま育つこと（GAME.md 9.5）。2文目が、いま足りない「目標」の席。
- PLAN.md 1章はまだ「里山の本物の箱庭」が柱のまま → こえのこの柱に書き直す（決まったら）。

## 2. 足りない芯: 「でかけた所が、家に返ってくる」
ディレクターとゲームデザインが別々に出した案が、同じ方向を向いていた。2つを合わせる。

| | ディレクター案A「野の地図」 | ゲームデザイン案A「けもの道とひっつき虫」 |
|---|---|---|
| でかける（走る） | 藪・水場・倒木・丘に着くと、その子の毛の色の足あと | 藪でひっつき虫（種）が毛につく（いまの泥と同じしくみ） |
| 家に帰る（育てる） | 着いた所の地面が、次の練習の場所に入る | 種がぽろぽろ落ちて芽が出る。来るたびに一段育ち、花の並びが「足あとの地図」になる |
| 先へ | 育つと奥へ行ける（決まりで閉じず、物理でまだ渡れないだけ） | 同じ |
| 出さないもの | 秒・順位・失敗（9.7） | 同じ。芽は枯れない・日がたっても罰なし |

**すすめる形**: 走ると種がつき、帰ると庭に咲き、走った地面が練習に入る。新しい決まりは「ふれた物は体につき、落ちた所に残る」に種を足すだけ（泥の点＝`dirt.js`・`felt.js` の `mud` と同じ道すじ）。
- 日をまたぐ理由: 芽が「次に来たとき」一段育つ（あした ひらく）。
- 代をつなぐ（年をとる・最期・たまごの受けつぎ＝WATCH.md）は、そのあとの段。

**最初の小さな段（1〜2日）**: 走るの藪を2種にして、ふれると種が点でつく → 育てるで落ちる（水浴びでも）→ 落ちた所に芽 → 次に来たら花。種の点は泥と同じく骨から見た場所で持ち運ぶ。確かめ: はじめての人が 30 秒以内に藪に1つ着くか、自分から育てる⇄走るを2往復するか。

## 3. UX（遊び手の目で、重い順）
すぐ直したもの（2026-11-08）:
- 育てるで子と操作がかさなった → 見る点を下げて子を画面の上寄りに。声のみほんは「声のみほん」1つにたたむ。約束の注記は生むだけ。
- 水浴びが声のまとまりに割りこんでいた → 右のふちに水の印の丸いボタン（横向きは左下）。
- 知らせが画面の上で見落とす → 下のまとまりのすぐ上に。
- 左上の名前が書きかえられると見えない → いつも えんぴつ と点線。
- 歩き方を聞くカードで、押すと何が起きるか → 「覚えなおすと、いまの歩き方は消えて、よちよちから」。カードのあいだは声のみほんをしまう。
- タブが 38px・押せないタブが見分けにくい → 44px、子が来るまでは 生む だけ。
- めもりの「練習 720 回」は意味がわからない → 段の名前と太い棒だけ。3匹の切りかえの字を少し大きく。

決めてから作るもの:
1. **子を失う操作の知らせが弱い**（いちばん重い）: 3匹いっぱいで生むと いま見ている子が野にかえる・「べつのたまごをつくる」は確かめなしで生まれた子が消える。→ 決める前に、かえる子の名前のカードを出す。どの子をかえすか自分で選べるように。
2. 下のメニューの組みかえ（声で育てる1つの大きなボタン、道具はふちへ、たて・横・PC で区割りを決めなおす）。声の大きさでマイクのふちがふくらむ。
3. 走るを同じページの場面にして、読みこみをなくす。走るのカメラ・揺れ・雨は「見え方」1つにたたむ。左上の「着くまで◯秒」は外す（くらべっこをさそう＝RELEASE で外すと決めたもの）。

## 4. ユーザーに決めてもらうこと
1. 目標を「でかけた所が家の庭になる（種と足あと・走った地面が練習に入る）」でよいか。
2. タブ: 3つ（生む・育てる・走る）のまま／2つ（育てる｜でかける、生むは入口と小さなボタン＝ディレクターのすすめ）。
3. 小屋: 「でかけたあと帰る場所」（泥つきで帰る → 小屋で水浴び → 練習）として置くか。
4. いっぱいのとき、野にかえす子を遊ぶ人が選ぶ形でよいか。

## 5. ほかのセクションに残っている問い
- 生き物監修: 里山で毛につく種（イノコヅチ・ヌスビトハギ・チヂミザサ）。ノウサギの行き来の距離から野の大きさ。
- アート・音: フェルトのひっつき虫・芽・花・足あと・地図（つるつるにしない）。
- 検証: 種と泥で点の上限 200 が重くならないか。地面を練習に入れると歩き方が崩れないか。
- レベル: 段ごとに届く距離・坂・ぬかるみ・小川の並べ方。
