## 確かめのしかた
1. `node tools/solve.mjs levels/r1.json levels/r2.json levels/r3a.json levels/r3.json levels/r4.json`（r4 は `MAXSTATES=8000000 node --max-old-space-size=7000 ...`、数分）。どの部屋も合格の目安（PLAN 2章）。
2. `node pathstones/tools/playtest.mjs`（ゲームのフォルダで。検証が書いた。autoplay・意図した解をキーで流す・火が消える・もどす／やり直し・幅ごとの1マスの大きさ）。
3. ブラウザで `pathstones/?autoplay=1` → 画面の上とコンソールに「r1: ok / … / r4: ok」（意図した解を rules.js で流す。道具とゲームの決まりが同じことの確かめ）。
4. ブラウザで意図した解をキーで流す（コンソールで `window.__ps` を見ながら。v001 で r1〜r4 すべて着いた）。
5. `node ../tools/playwright/shots.mjs pathstones` で幅ごとの画面とエラー。
6. 音はない（段階A）。

## 操作（PLAN 3章）
- タップ: となりのマス＝動く／「切る」→ 光るマス／「置く」（またはミニ図）→ となりのマスで影 → 同じマスで反対の端 → 「決める」。となり以外をタップすると置くのをやめる。
- キー: WASD・矢印＝動く（いつも上が北）、X＋方向＝切る、E＋方向＝置く影、Tab＝端、Enter＝決める、Space＝待つ、Z＝もどす、R＝やり直し（もどすで戻せる）、Esc＝やめる。
- もどすの長押しで続けてもどる、待つの長押しで続けて待つ（印のマスにいるときは止まる）。
