## ユーザーの案（2026-10-19）
- バードビュー。世界は 3D で描くが、操作は 2D（W はいつも画面の上）。
- 暗い野に灯りが点々。敵も見えづらく、灯りに照らされた所だけ、通った跡がうっすら見える。
- 敵はリアルタイムに動く（ターン制ではない）。
- 自分はわなを置いて敵をちょん切り、ブロックを拾う。
- ムカデの頭はちょっと赤系。頭には操縦席があって、敵の小人が乗っている。自分も小人。ブロックをつなぐとムカデを操縦できる（今回は、拾ったブロックが自分のうしろにつながるところまで）。

## ファイル
- `index.html?p=A〜D` — 遊べる試作（1〜4 キーか下のボタンで切りかえ。`&shot=1` で撮影用の配置）。
- `look.js` — 共通のしくみ（配置・動きは乱数の種で固定。どのパターンも同じ世界）。
- `patterns.js` — 見た目の数字だけ。新しいパターンはここに足す。
- `compare.html` — 並べて見くらべるページ（`shots/` の絵は大きいので Git に入れていない。ローカルで撮り直す）。`shots/` の絵は `node tools/playwright/shots.mjs pathstones/look --sizes=1280x720 --query="p=A&shot=1" --wait=6000` で撮った。

## 作ってみて気づいたこと
- 灯りどうしを近づけ（9 マス）、カメラを引かないと「点々」に見えない。1つの灯りが画面いっぱいだと、ただの暗い部屋になる。
- 頭と操縦席の小人は、頭を 1.2 倍・小人を 1.3 倍にして、操縦席に小さな明かりを足してやっと読める。小人の顔までは見えない（寄れば見える）。
- 灯りが部品の内側にあると、まわりの部品が地面に大きな黒い影を落とす → 柱だけ影を落とす。
- C は「見えづらい」をやりすぎ。体が地面に溶ける。D は逆に一番はっきりしている。

## 3回目（2026-10-19）: D を土台に振る
ユーザー「D を土台に、ふちどり・積み木の色・頭や操縦席の作りこみを振った案をいくつか並べて」。`D1`〜`D7`（`patterns.js` の終わり。`index.html?p=D5` のように開く。数字キー 1〜8 で D〜D7）。
- D1／D2 ふちどり太め・細め（`outlineK`）。D3 白と朱のしま。D4 頭から尾へ色が移る（`block.gradient`）。D5 操縦席を作りこむ（`head.cockpit: 'deluxe'`: ガラスの丸屋根・真鍮のふち・前照灯の SpotLight・旗）。D6 くみあわせ（＋隈取り `head.face`）。
- D7 ヘビ型（ユーザー「蛇型とかあってもおもしろそう（まなびラボ流用）」）: まなびラボ `snake-move` の実物の形（Hu ほか 2009: 波長 0.4 L・ふれはば 0.1 L）で頭の向きを h ± 57° にふり、体は頭の道をなぞる（石のあいだの進み方、Gray 1946。横すべりなし）。足なし、跡は1本のすじ。
- 気づき: 本物の曲がりは半径が体の太さくらいまで小さい。太い積み木だと内側で重なる → ヘビは細く（体長の約 5%）短い体節を 22 個。
- 気づき: 操縦席の明かり・自分の明かりが小人に近いと、白く飛んで小人が見えない → 明かりを高く・前へ（すべてのパターンに効く）。
- 撮影: `&shot=1` でムカデを止め、`&zoom=0.5` で頭の寄り、`&focus=snake` でヘビを選ぶ。

- 決まり（2026-10-19 ユーザー）: **D5。ヘビ型はオミット**。D7 のパターンとボタンは外した（`look.js` の kind 'snake' のしくみと `shots/D7*.png` は記録として残す）。
