## 0. ひとことで（v1 と同じ芯）

> **何も生まれず、何も消えない。ただ、めぐるだけ。**

v2 では、そのめぐりを**目で追える**ようにする（体は土に、命は光になって深淵・霧・雲・雨・つぼへ）。太陽と月は「止めるとすぐ返事がある」空の手に、進化は「見て分かる」体の変化と「選ぶ」遊びに。十の年のあとにヒトが来て、プレイヤーと同じ手で世界を変え、最後に空から「大地は丸いのでは」と気づく。

## 1. 太陽と月（EXPANSION 3章。PLAYTEST #17）

| しくみ | 中身 |
|---|---|
| たまる日ざし | 区画ごとに日ざしがたまる（25 秒でならす）。回っていれば平均と同じ、止めると真下は暑く乾き（草が焼ける・ひび）、反対がわは夜のまま凍る |
| 止めた印 | 止めた・つかんだ太陽: 地面への光の柱と、真下に広がる光の輪。月: 真下へちぢむ青い輪（大潮は二重） |
| 大潮と小潮 | 潮の強さは月と太陽の向きで変わる（新月・満月で大潮、直角で小潮）。天の輪に月の満ち欠けと大潮の波の印 |
| 生き物の暦 | シカは昼に食べ夜は休む。オオカミは夜に狩る（飢えれば昼も）。サギは大潮でよくとる。サカナは満月のころに多く卵を産む（光の輪）。日食では陸の生き物が立ちどまる |
| 止めたときのことば | はじめの2回だけ、何が起きるかを1文で |

## 2. 進化（EXPANSION 2章。PLAYTEST #14）

- 遺伝子で形が変わる: あしの速いシカ・オオカミは足が1段長く、くちばしの長いサギはくちばしが長く、体の大きさは描く大きさに。
- 生き物の札に「はじめの姿」（遺伝子がみな 0.5）の影と「この子」を並べる。
- **第九の年は、きびしさを選ぶ**: 逃げ足（オオカミ＝命のつぼ）／寒さに強い体（太陽）／大きなサカナ（月の大潮でサギの狩り）。選んだ遺伝子の平均を 0.06 上げる。ヒントのはしごの手助けは、選んだきびしさを強める（オオカミ・寒い冬・大きな潮とサギ）。
- 選ぶ力を強めた: オオカミは近くの足の遅いシカをねらう（本当の捕食者と同じ）、一頭で満ちる量を減らして狩りをふやす。寒さは小さな体ほどこたえる。
- 命のつぼから来る命は、いま大地にいる群れの平均に近い遺伝子（進化した群れが「はじめの姿」にもどらないように）。
- 見つけたこと: 長い足・大きな体・大きなサカナ・長いくちばし。

## 3. めぐり（EXPANSION 1章）

- **体は土にかえる**（本当）: 死んだ生き物・ふん・枯れた草が土を肥やす（W.fert）。肥えた土では草と水草がよく育ち、育つ草は肥えを使う。肥えた所には花。水は肥えを下流へ運び、滝から深淵へ。泉がくみ上げる。
- **命の光**（作りごと。図鑑で正直に書く）: 去った命 3 つで光の粒 1 つ。空へのぼり、ふちへただよって深淵へ。深淵の命は滝の霧にのって雲になり、雨といっしょにおりて命のつぼへ。泉からも帰る。滝をぜんぶ止めると帰りにくい。深淵にたまった命は大地の下の暗がりに光る。
- いなくなった種類は 1日に1つは帰る（取り返しがつかないことは起きない。v1 と同じ）。

## 4. ヒト（EXPANSION 4章）

- 十の年のあと（エンディング後・自由な箱庭）に命のつぼへ来る。
- 村をつくり、昼は食べものを集め、夜は村の火のそばで休む。家（ヒト 3 人に 1 軒）と夜の火。
- 知恵（まねで村じゅうに広がる）: 火 → 狩り → 漁 → 畑 → 水路 → 堤 → 暦 → 丸い大地。畑は草地をうばい（シカの草がへる）、水路と堤は水をうばう（下流が干上がる）。掘った土はとなりに盛る（土は消えない）。暦を知ると春の畑・大潮の漁がはかどる。
- 最後の知恵「丸い大地」で「ヒトの観察帳」の札（本当は: アリストテレスの月食の影と星、エラトステネスの影）。
- オオカミはヒトをおそわない。死はほかの生き物と同じ小さなけむり。

## 5. 決めたこと（EXPANSION 6章でユーザーに聞いていたこと。いまは Claude の仮の決め。ユーザーに見てもらって変える）

1. ヒトは「その後の世界」（十の年のあと・自由な箱庭）に入れた（本編には入れない）。
2. めぐりは科学の側で正直に（土の肥え）、命の光は小さな光の粒として出し、図鑑で作りごとと書く。
3. 命のつぼから出る生き物の遺伝子は、いまの群れの平均に近く（群れがいなければ 0.5 のまわり）。
