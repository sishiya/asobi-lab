# ぺらぺら世界の歴史係 見た目の決めごと（ART.md・下書き）

3D の主人公・形・道具を作るときに、作る前に読む。作ったものは、ここに書いた目で採点してから見せる（`../RULES.md` 10章の手順。2026-10-17 ユーザー「ツールが変わっても、手を動かす人とその考え方が変わらないから」）。
色の決まり・かどの決まり（UI）は `DEVNOTES.md` の「色のきまり」「かどのきまり」。ここは 3D の形のこと。

## 1. 主人公はゲームの中でどう見えるか（測った値。2026-10-17）
`node tools/playwright/hero-lineup.mjs` で、ゲームの中（図版 I・ふつうのカメラ）に入れて測った。

- **大きさ**: 主人公の外わく（足もとの輪まで）は PC 1280×720 で **約165px**、スマホのたて 375×740 で **約122px**。胴の宝石は PC で約60px。
- **1 単位 ≒ 70px**（PC。主人公は `scale 1.25` で、輪から頭まで約 2.3 単位）。**3〜4px（0.05 単位）より細いものは見えない**。細部は 0.06 単位以上か、面の明暗の差で見せる。
- **うしろ**: クリームの紙に、こげ茶のハッチングの線がこまかく入っている（にぎやか）。主人公は、紙より**暗く・あざやかな、ふちのはっきりした形**でないとまぎれる。
- **光**: 半球の光（空 `#fff2d8`／地 `#7a5a3a`、1.25）と太陽（`#ffe2b5`、1.5、左上の奥から）だけ。**映りこみの光（環境マップ）もトーンマッピングもない**。金属（metalness 1）・すける素材（transmission）は暗くにごる（試作で確かめた）。金は「金属でない、あたたかい黄土色＋少しの発光」で見せるか、主人公の材質にだけ `envMap` をつける。
- **断面**: 2D 世界には**メッシュごとの凸包**が出る（`stage3d.js` の `sliceObject`）。部品はそれぞれ凸に。glb で1つの部品に材質が2つあると、three.js では2つのメッシュに分かれ、両方の凸包が重なって出る。すける材質（`transparent`）は断面に出ない（`userData.slice` で出せる）。
- **カメラはたいてい主人公のうしろ**（ふつうの向きは +X で、カメラは +X を奥に見る）。前につけた目は、ほとんど見えない。**目立たせる1点は、うしろやななめうしろからも見える所に**（大まかな形の1回目で気づいた）。進む向きは、前のかざりより、うしろへ流れるものと前のめりで見せる。
- **足もとの輪は脇役**: 太く明るいと、主人公と目立ち合う。太さ 0.028・発光 0.15 くらい。
- **重さ**: 断面は動くたびに 2〜3 ページぶん計算する。主人公ぜんぶで**三角形 3000 まで**を目安に。

## 2. いまの「多面体の旅人」の採点（ゲームの大きさで）
- シルエット: 丸い塊（胴）の上にひし形（頭）がのった「雪だるま」。**どちらを向いているかがわからない**（旅人なのに進む向きが読めない）。手の四面体は小さすぎて、胴にまぎれる。
- 明暗: 胴（青緑）と頭（金）が、白黒にするとほぼ同じ灰色。**いちばん目立たせたいもの（顔・芯）が決まっていない**。
- 細部: 金のふちの線は 1〜2px で、ほとんど見えない。目（0.06）も見えない。
- よいところ: 青緑と金の色の組み合わせ・浮かぶ輪・面ごとの明暗（flatShading）は、紙の上で読める。これは残す。

## 3. 目ざす見た目（形の言葉）
- **「標本室にしまわれていた、金細工の幾何学の器具が、旅に出た」**。銅版画の図鑑（2D）の、ひとつ上の次元の住人。
- 形の言葉: **かどのある結晶・多面体**（丸はほんとうに丸いものだけ。UI の「かどのきまり」と同じ考え）。下はとがって浮かぶ、上は冠のように開く。
- **大・中・小 ≒ 6:3:1**: 胴（大）・頭や輪（中）・手や細工（小）。小さいものも 0.06 単位以上。
- **進む向きが読める**: 前（+X）に向かう形（へさき・のぞく目）と、うしろに流れるもの（あとを追う動きの部品）をつける。
- **明暗は3段**: 胴＝中くらいの暗さの青緑、頭や留め金＝明るい金、芯や目＝いちばん明るい1点（目立たせるのは1つ）。
- **ふち**: にぎやかな紙の上で形を立たせるため、銅版画のような**こげ茶のインクのふち**（裏返した殻。材質は transparent にして断面に出さない）を試す。

## 4. 参考（写すのではなく、形と作りの手本）
- **ヴェンツェル・ヤムニッツァー『Perspectiva Corporum Regularium』（1568）** — 金細工師が描いた多面体の銅版画。同じ多面体の家族の中での「変化のつけ方」（星形・切頂・くり抜き・輪との組み合わせ）と、面ごとの明暗の3段の塗り分け。[メトロポリタン美術館](https://www.metmuseum.org/art/collection/search/339008)・[クーパー・ヒューイット（パブリックドメイン）](https://collection.cooperhewitt.org/objects/18418175)・[Wikipedia](https://en.wikipedia.org/wiki/Perspectiva_corporum_regularium)
- **レオナルド・ダ・ヴィンチ画『神聖比例論』の多面体（1509）** — 辺を太い角材にした「骨組みの多面体」。辺に厚みがあるので、骨組みでも形が読める（前の試作の金のふちは細く丸くて、ただの鳥かごに見えた）。[George Hart の木の模型の再現](https://w.georgehart.com/sculpture/leonardo-project.html)
- **ケプラー『宇宙の神秘』の入れ子の多面体（1596）** — 多面体の中に球、その中に多面体。大きいものの中に小さいもの、という段階。断面にすると、入れ子の多角形になる（このゲームの2D世界で映える）。[World History Encyclopedia（パブリックドメインの図）](https://www.worldhistory.org/image/17841/keplers-platonic-solid-universe-model)
- **天球儀（アーミラリー天球儀）** — 真鍮の環を斜めに組んだ器具。環の目盛り。輪が傾くと、シルエットに動きが出る。[サイエンス・ミュージアム（16世紀ドイツ）](https://collection.sciencemuseumgroup.org.uk/objects/co56290/ptolemaic-armillary-sphere-armillary-sphere)
- **鉱物の結晶**（緑柱石の六角柱・水晶の先のとがり・ざくろ石の十二面体） — 自然の多面体。とがった先が向きをつくる。

## 5. 採点のしかた（見せる前に、3回は直す）
1. **シルエット**: 黒くぬって、ゲームの大きさで、何かわかるか・向きがわかるか。
2. **明暗**: 白黒にして、3段に分かれているか・目立つのは1つか。
3. **原寸**: PC 165px・スマホ 122px のゲームの中で（`hero-lineup.mjs`）。ビューアーの大写しで決めない。
4. **参考とくらべる**: 4章のどれに、どこが近いか。
5. **断面**: 2D 世界の小窓で、断面の形が読めるか（つぶれた細い多角形にならないか）。

## 6. 新しい主人公「天球儀の旅人」（B 天球儀。2026-10-17〜18。v092 で主人公の選択肢に入れた。既定は「多面体の旅人」のまま）
- 大まかな形の3案（A 宝石・改／B 天球儀／C 結晶。`_dev/blender/review/blockout-lineup.png`（ローカルだけ））から、ユーザーが **B** を選んだ。
- 作り: `tools/blender/traveler_b.py` → `flat-history/models/armillary.glb`（ゲームの中の場所）（部品 108・三角形 約1650）。並べた絵は `_dev/blender/review/traveler-b-lineup.png`（ローカルだけ）。
  - 胴: レオナルドの骨組みの二十面体（六角の角材 0.07・頂点の金の留め玉 0.055・頂点を上下に）。中に光る十二面体（0.17、発光 1.4。いちばん明るい1点）。下の頂点に光のしずく。前へ 14° かたむく
  - 黄道の環（主役の環。半径 0.80・太さ 0.06、X 32°・Y 24° に開く）と、そのはしの暗い星ふたつ（手のかわり、±90°）
  - 頭: 明るい金の二十面体 0.17 と光輪の環。足もとの輪は脇役。全体を 0.85 倍（原寸で PC 158px・スマホ 117px）
  - 断面だけに出る二十面体の殻（不透明度 0.06・`slice`）で、2D に「二十面体の中に十二面体」の入れ子の多角形が出る
  - インクのふち（0.016・こげ茶 `#3a2614`。環・目盛り・殻にはつけない＝`noInk`）は**つける**方向
- アートディレクター役（別のエージェント。ART.md と絵だけを見る）との3回: 5/10 → 6/10 → 7/10。「形の段階はここで終えて、動きへ」。

### のこり（採用するときにすること）
1. **動き**（④。2026-10-18。v092 でゲームに入れた）: `flat-history/js/look/armillary.js`（ゲームの主人公と同じ `userData.animate(dt, s)`）。くらべるページ `_dev/blender/motion.html`（`?poses` で決め絵）、動画 `_dev/blender/review/traveler-motion.mp4`（ローカルだけ）（`node tools/playwright/record.mjs _dev/blender/motion.html --query=dist=8`）。
   - **決め絵を先に**: 待機・動きだし・歩く・走る・止まる（つんのめる）・宙・着地・持ち上げる を `POSES`・`KEYS` に数で書き、絵にして確かめてから動きにした（`_dev/blender/review/traveler-poses.png`（ローカルだけ））。
   - **ばねでつなぐ**: 部品ごとに速さのちがうばね（胴 3.2Hz → 頭 2.4Hz → 黄道の環 1.5Hz・よくゆれる）。体の速さの急な変化（位置から測る）を、ばねにけりとして足す。止まると前へつんのめって戻る、動きだすと一瞬うしろへ残る、曲がると環が外へ傾く。
   - **進む向き**: 胴の前傾・頭が前へ・光のつぶ（世界に置くので、うしろへ流れて見える）。
   - 決め絵で気づいたこと: 骨組みはほぼ丸いので、傾けても前のめりに見えにくい → 頭の前後で見せる。黄道の環は胴の子なので、胴といっしょに立って車輪に見えた → ジャイロ（ジンバル）のように胴の傾きの 85% を打ち消す。
   - アートディレクター役は動画を見られないので、動きの採点はこま割り（`--sheet`）で。今回はまだ受けていない。
2. **ゲームの変更**（v092 でした）: `sliceObject` に `noSlice`（環・留め玉・目盛りは断面に出さない）。インクのふちと noSlice の印は `armillary.js` でつける。glb はあとから読むので、`heroes.js` の `makeArmillary` はまず空の入れ物をかえし、読み終わったら中身を入れる。
3. ユーザー（2026-10-18）「このまま入れてもOK、デフォルトはいまの多角形の旅人」→ 主人公の選択肢の2番目に足した。
4. のこり: ゲームは主人公に「持っている」を伝えていない（`carry: false`）ので、持ち上げるポーズはゲームでは出ない。動きのアートディレクター役の採点はまだ。

## 7. 作り方でわかったこと（次の形にも使う）
- **ビューアーの大写しで決めない**。ゲームの光（映りこみなし）・カメラ（うしろ）・大きさ（原寸）で見ないと、まちがった方向に直す（最初の試作は、ビューアーではよく見えても、ゲームの中ではにごった塊だった）。
- **大まかな形の段階で案を並べる**と、選ぶのが早い（3案を作って並べるまでが短い）。
- **作る人と見る人を分ける**と、自分で見落とすもの（芯の前の星・カメラから見た環の向き・尾の縮み）を拾える。アートディレクター役には、ART.md・並べた絵・数値の入ったスクリプトを渡し、「何が悪いか（どの絵のどこ）」「どう直すか（数値）」で答えさせる。同じ役を続けて使うと、前の指摘が直ったかも見てくれる。
- 採点の道具の不具合（シルエットに透明の殻がうつる・ページが主人公を隠す）も、絵を見て気づく。道具の絵も疑う。
