# （仮）ぺらぺら世界の歴史係 企画書

## ユーザーの案（2026-10-16 のまま）
- 四次元が3次元＋時間なら、2次元＋時間の世界も作れるのではないか。
- 主人公は3Dモデル。ゲームは2Dの横スクロール。ジャンプはあるが上下の操作はいらない。
- 上下の操作＝奥行きの移動で、時間が前後する。2D世界が奥行き方向に無数に並んでいるのを見せる。奥のとなりは1秒前、その奥は2秒前…。手前のとなりは1秒後、その手前は2秒後…。
- 主人公は2D世界の住人ではない。2D世界は2D世界のルールで動いている。
- パラレルワールドとも少し違う。
- 遊び: 2D世界の人がスタートからゴールへ行くのが目的。でも、はじめの世界では崖・山・猛獣などで行けない。3Dの主人公が時間を前後して未来に何があるかを見て、過去に戻って2D世界を変え、ゴールできる**正史**を作る。
- ゲームの最後に、だめだった2D世界とよくなった2D世界を、動画プレイヤーのように再生して見せたい。

## ひとことで
1秒ずつの2D世界がトランプのように奥（昔）と手前（未来）に並んでいる。主人公はその束の上を歩き、3Dの形を束の中へ下ろす。2D世界には形の**断面**が現れ、そこから手前の未来が波のように描きかわる。

## 0. 決めたこと（2026-10-16 ユーザーと）
- **物理に忠実にする。** 主人公は2D世界の物にじかにさわらない。主人公が置くのは**3D空間の3Dの物**で、2D人にさわれるのは、それと1秒のページが重なった**断面（切り口）**だけ。投影（影）ではない（投影だとほかの秒の部分まで写りこむ）。
- **3Dでの形が、2D世界では動きになる。** 下の表。
- **主人公は2D世界のブロック（x・y・時間の箱）の外**、空の上のガラスの棚を歩く。中に立つと体の断面が2D世界に出てしまうので。手や道具だけを中へ下ろす（体の断面＝最初の相談の C は、ここで自然に入る）。
- **影は遊びの道具にしない。** 2D世界の中の光が断面にさえぎられてできる影は、物理として入れてよい。3Dの光源は、ページと平行（真上から）の光だけ筋が通る。斜めはほかの秒へ流れこむのでなし。2D人を引き返させるのは「縦の板」（一定の時間だけ出る壁）でする。
- **インターステラーに似せない。** アイデア（時間の外から過去を見て、物理の手段で働きかける）は物理の時空図や『フラットランド』（1884年）にもある。避けるのは見せ方と筋: 本棚・部屋の裏から見る、同じ部屋が何度も並ぶ格子、重力や時計の針でメッセージ、親子の物語・愛が時をこえる、ブラックホール、暗い宇宙の光の筋。こちらは明るい昼の光、紙やガラスのページの束、主人公はしゃべらず形を置くだけ、遊びの芯は「形＝動き」の幾何のパズル。
- **最後に、はじめの歴史と正史をくらべて再生できる**（再生・一時停止・シーク・速さ）。2D人から見ると、橋がちょうどよい時に何もない所から現れて消える、奇跡のように見える。
- 題名・フォルダ名・公開の仕方（`time-strata` のように push を待つか）は、まだ決めていない。

## 1. しくみの芯

### 1-1. ページの束＝ひとつの歴史（ブロック宇宙）
- 2D世界は**決まったルールで動く**（重力・歩く・段をのぼる・壁で引き返す・高い所から落ちるとだめ）。はじめの状態と置いた3Dの物が決まれば、0秒から最後まで全部が1通りに決まる。
- その歴史を1秒ごとに切ったものがページ（段階Aは 0〜60 秒の 61 枚）。**全部のページは同時にある**。主人公が奥へ歩けば昔、手前へ歩けば未来が見える。
- **パラレルワールドとのちがい**: 歴史は1本だけ。物を置くと、その1本が書きかわる。前の歴史はしばらく薄い残像として残るだけ。

### 1-2. 形＝動き（断面のルール）
| 3Dで置く物 | 2D世界では |
|---|---|
| 奥行き方向に長い角材（崖をまたぐ向き） | ある秒に橋が現れ、しばらくして消える。奥行きの長さ＝橋のある時間 |
| 手前（未来）へ向かって上がる板 | だんだん上がる足場＝エレベーター。傾き＝速さ |
| 縦の板 | 一定の時間だけ壁が出る。2D人はそこで引き返す（着く時刻をずらせる） |
| 球（段階B〜） | 小さな円が現れ、大きくなって、縮んで消える（『フラットランド』と同じ） |

- 3Dの物は2Dの重力では落ちない（2D世界での動きは形でもう決まっている）。2D世界の側から押して動かすこともできない。
- 3Dの物は、ブロックの中の**動かない地形**（どの秒にもある地面＝奥行き方向にのびた土の塊）の上に下ろすと止まる。底のない崖の上だけには置けない。3Dの物どうしは重ならない。
- 断面が2D人の足もとに現れたり、下から上がってきたりすると、2D人は上に押し上げられる。

### 1-3. 手を入れると未来が波のように描きかわる
- 10 秒目から始まる物を置くと、10 秒目から手前のページが計算しなおされ、**描きかえの波が手前へ走る**。
- 置いた物は持ち上げて取りのぞける（その物の始まりの秒から描きかわる）。

### 1-4. 2D人の世界線
- 2D人の通り道は、束をななめに見ると**光るリボン（世界線）**になる。落ちた所でリボンが切れて赤い印。ゴールまで届いたら金色になって**正史**。
- 物理の時空図（ミンコフスキー図）と同じ見え方。

### 1-5. 主人公の動き
- 左右＝2D世界の横方向、上下キー＝奥行き＝時間（上＝奥＝昔、下＝手前＝未来）。ジャンプあり。ガラスの棚の上を歩く。
- 持っている形を選ぶと、足もとの下に形の下書き（ゴースト）が見え、いまのページから奥行きの方向にのびる。置ける所なら下ろす。

## 2. 面の案
ポイントは2種類: **「いつ着くか」を変える面**（時刻あわせ）と、**「その時にそこにある」形を作る面**（橋・エレベーター）。どちらも「未来を見て、過去を変える」。

1. **崖と段（段階A）**: 崖を角材の橋でわたり、高い段を斜めの板（エレベーター）でのぼる。橋が短いと、段で引き返したときに崖へ落ちる。
2. **潮**: 引き潮のあいだだけ浜がわたれる。縦の板で着く時刻をずらす。
3. **猛獣**: 獣も2D世界のルールで歩く。縦の板で獣を足止めする（2D人には別の時刻に通ってもらう）。
4. **落石**: 決まった時刻に石が転がってくる。斜めの屋根を出しておく。
5. **球の面**: 大きくなって縮む円を、一時の足場・押し上げに使う。
6. **二人**: 2D人が二人。一人のための橋が、もう一人には壁になる。
7. **短い物しかない**: 角材を斜めに置いて「動く足場」にし、2D人を運ぶ。
