## 1. 何がうまくいっていないか（原因の見立て）

| 症状（ユーザー） | 原因 | 手がかり |
|---|---|---|
| 介入している感じがない | 主人公の体と、世界の変化がつながっていない。空の棚から糸で下ろすので、手と結果のあいだが遠い。結果は少しおくれて、遠くで起きる | **行為主体感（sense of agency）**は、自分の動きと結果が「すぐ・近くで・予想どおりに」つながると生まれる（Haggard らの比較器モデル、意図的結合）。**直接操作**（Shneiderman）: 対象を見ながら、手でじかに動かす |
| ただ矢印を卵に向ける作業になる | 答えに要る情報が全部見えている（未来のページ・結末の秒の文字・小窓の再生・最初から見える世界線）。変えられるのは秒だけ | **情報の空白が好奇心を生む**（Loewenstein の情報ギャップ説）。全部見えると「確かめ」になる。**行きづまり→見方の組みかえ→ひらめき**（洞察の研究、Kounios & Beeman）は、見えない部分があるときに起きる |
| 移動キーと主人公の向きが合わない | 矢印キーが「世界の軸」に固定で、カメラを回すと頭の中で向きを回す必要がある | **心的回転**は角度に比例して時間と負担がかかる（Shepard & Metzler）。**カメラ基準の移動**（スーパーマリオ64 以降の三人称アクションの標準）で消せる |
| 置く場所が遠く、主人公と両方を見ようとすると端しか見えない | 主人公（空の上）と、置く場所（地面）の高さがはなれている | **注意の分割**は負担が大きい（作業記憶の上限は 4 つほど、Cowan）。手もとと目もとを同じ場所に |
| W・S で奥行きを動くのがつらい | 「奥＝昔、手前＝未来」が体の感覚と逆。前に進むと過去へ行く | **「未来は前にある」**という体の比喩（Lakoff & Johnson、Boroditsky）。前へ歩けば未来、が自然 |
| 画面と画面がつながっていない、余計なボタン | 戻る道がボタンごとにばらばら。同時に見えるボタンが多い | **ヒックの法則**（選択肢が多いほど迷う）、**段階的な開示**、**一貫した逃げ道**（どこでも Esc） |

**ひとことで言うと**: いまは「見えているものを合わせる作業」になっている。これを**「歩いて観察し、予想して、体で手を入れ、見届ける」**遊びに変える。

## 3. 作り直す遊びの芯

### 3-1. 主人公は「ページのあいだ」を歩く
- 61枚のページを重ねると、ページの上のふち（地面）が並んで、3Dの大地（時空の地形）になる。**主人公はこの大地を歩く**。本を閉じたときの、ページのふち（小口）の上を歩くような絵になる。
- **前（カメラの奥）へ歩くと未来、うしろへ歩くと昔。左右は2D世界の横方向**。崖は時間の方向にのびた溝、段は壁。ジャンプ・よじ登りで越える。溝は橋のある時間だけ渡れるので、**時間の方向に回りこむ**道さがしが生まれる。
- **物理の筋**: 主人公の体の厚みはページの間隔（1秒）より薄いので、**ページとページのあいだに立つかぎり、2D世界とは交わらない**（だから主人公は2D人にさわれない、という最初の決まりと矛盾しない）。歴史を変えられるのは、**何枚ものページをつらぬく3Dの形**だけ。
- **足あと**: ページのふちを踏むと、紙に小さな**押し跡**が残って、ゆっくり消える（インターステラーの「揺らぎ」でなく、紙の世界の表し方）。2D世界から見ると、空がほんの少しくぼむ。歴史は変えない（パズルをこわさない）。

### 3-2. 形は、手で持って運んで、押して、回す（ひとつの動詞「つかむ」）
- 形は、図版のはしの**標本箱**に入っている。近づいて **E でつかむ**。持ったまま歩き、**E で目の前に下ろす**。置いた形の前で **E でつかむと、持ち上げずに押し引きできる**（前へ押す＝未来へずれる、引く＝昔へ）。**Q で回す**（横向きの板を、奥行きにのびる向きにする、など）。
- 置く場所は主人公の目の前なので、**主人公と置く場所がいつも同じ画面に入る**。
- 置いた瞬間、**主人公のまわりのページだけがすぐ描きかわる**（近く・すぐの手ごたえ）。そこから先の未来へは、描きかえの波が手前へ走っていく。
- **形の動きは説明しない**。のってみて、見て、わかる（Braid・The Witness）。「回すと意味が変わる」「ななめにすると動く足場になる」を、遊ぶ人が自分で見つける。

### 3-3. 見えるのはランプのまわりだけ（何を隠すか）
- 主人公のランプが照らす**前後数秒のページだけ**、2D世界とキーウィがはっきり見える。遠い未来は地形の影だけ。何が起きるかは、**歩いて行って見ないとわからない**（情報の空白）。
- **見た出来事は「観察帳」に自動で残る**（アウターワイルズの日誌・オブラディンの手帳）。例: 「8秒 キーウィ、崖から落ちる」の小さな図。覚えておく負担を外に出す。見ていないことは書かれない。
- **歴史を書きかえると、観察帳の先の出来事はぼやける**（「この先はまだ見ていない」）。もう一度見に行く。
- **出さないもの**: 結末の秒の文字、小窓のくり返し再生、最初から見える世界線、形の説明。世界線のリボンは**見に行ったところだけ**描く。
- **キーウィについて歩く**（F）: キーウィのとなりを、時間の流れの速さで自動で前へ歩く。見届ける・確かめるのが楽しくなる（ためしたあとの「確認」も遊びになる）。

### 3-4. 遊びの流れ（観察 → 予想 → 介入 → 見届け）
1. **観察**: 歩いて未来へ行き、キーウィがどこでつまずくかを見つける（観察帳に残る）。
2. **予想**: 「ここに、この向きで、このくらいの時間」と考える。（答えの矢印がないので、自分で考えるしかない）
3. **介入**: 形を運んで置く・押す・回す。近くのページがすぐ変わる。
4. **見届け**: キーウィについて歩くか、未来へ走って結果を見る。だめなら直す。
5. **正史**: 巣に着いたら、すぐ**くらべて再生**（はじめの歴史と正史を、住人の目線で）。どこでも Esc か E で抜けられ、「次の図版へ／もう一度」。

### 3-5. 図版の作り方（1面1つの考え → 組み合わせ → ひねり）
| 図版 | 気づいてほしいこと（言葉では言わない） |
|---|---|
| I | 前へ歩くと未来が見える。キーウィは崖に落ちる。標本箱は落ちる場所のすぐそばに置いてある |
| II | 板の奥行き＝橋のある時間。短い板は、置く時間を探さないといけない |
| III | 板を回すと意味が変わる（崖をまたぐ向き／時間にのびる向き） |
| IV | ななめの板は、上がっていく足場 |
| V | 柱でひきかえすと、着く時刻がずれる |
| VI〜 | 組み合わせ。解き方が何通りもある。少ない形・短い時間で解くと印 |
| のちに | ななめにずらした板＝横に動く足場、2羽のキーウィ、2D世界の転がる石など、ひねり |

## 4. 操作（キーボード＋マウス。押すキーを少なく）

| 入力 | すること |
|---|---|
| **W A S D** | **カメラの向き基準**で歩く（W＝画面の奥。最初の向きでは、奥＝未来） |
| **Space** | ジャンプ（着地前でも少し早く押せば受け付ける。崖からはみ出しても一瞬は跳べる） |
| 壁に向かって歩く | 低い段（主人公の背の半分ほど）なら自動でよじ登る |
| **E** | つかむ／下ろす／押し引き（そのとき使える内容を小さく表示: 「E つかむ」） |
| **Q** | 持っている形を回す |
| **F** | キーウィについて歩く |
| **マウス右ドラッグ** | カメラを回す（動いているあいだは、ゆるく主人公の後ろへ戻る）。**ホイール**で寄る・引く |
| **Tab** | 観察帳と時間の帯（遠くの秒へとぶ） |
| **Esc** | メニュー（つづける／やりなおす／図版の一覧／あそびかた／音楽／タイトルへ）。再生の中なら抜ける |

- 画面に出すのは、**図版の名前**・**ひとことの導き**・**そのとき使えるキー**だけ。ボタンの列はなくす。
- 時間の帯（物差し）は、画面のはしの**しおり**として細く。いまいる秒だけ大きく。

## 5. ひとことの導きと手助け
- 図版 I〜V は、言葉より**置き方**で教える（標本箱の場所、見えるもの）。言葉は動き方だけ（「W で前へ」）。
- 困ったとき用の**しおり（手助け）**をメニューに。3段階で、選んだときだけ: ① どこを見るとよいか ② 何をためすとよいか ③ 答え。自分で解いた感じ（有能感・自律性: 自己決定理論）をこわさないように、**自分から開くときだけ**。

## 6. 作る順番（段階）
1. **歩く土台**: 時空の地形を歩く・カメラ基準の移動・ジャンプとよじ登り・ゆるく追うカメラ・前＝未来・Esc メニュー・正史ですぐ再生。図版 I。
2. **つかむ**: 標本箱・つかむ／下ろす／押し引き／回す・近くのページがすぐ変わる。図版 II〜V。
3. **隠す**: ランプの範囲・見たところだけの世界線・観察帳・書きかえるとぼやける・キーウィについて歩く・足あと（押し跡）。
4. **深める**: 解き方が何通りもある図版・印・手助けのしおり・ひねりの形。

## 7. 決めてほしいこと

- 観察帳・手助けのしおりを入れるか。
