# 果ての滝の箱庭 開発メモ

最終更新: 2026-10-13

深淵に浮かぶ平らな円盤の大地。水は地形にそって流れ、ふちから果ての滝になって落ちる。泉・雲・雨で水がめぐり、草・シカ・オオカミ・サカナ・サギの生態系をつくる箱庭ゲーム。生き物は遺伝子を持って進化し、春夏秋冬がめぐる。`../heaven-spheres/`（天をまわす箱庭）の別バージョン。企画は `PLAN.md`。外のライブラリ・データは使わない（Canvas 2D と WebAudio だけ）。

### はまりどころ
- **Browser ペインが裏に回ると rAF が止まる**。進めるのは `__ef.step(秒)`。スクリーンショットが固まったら少し待ってもう一度。
- **自動のドラッグは Shift をのせない**。Shift＋ドラッグや2本指は `PointerEvent` を `dispatchEvent` で試す（`setPointerCapture` が失敗しても動くようにしてある）。
- **試しのブラウザにも自動セーブが残る**。はじめの札が「つづきから」になり、`#panel .main` を押すと前の世界を読む。試す前に `localStorage` の `asobi-lab/edge-falls/save/*` を消す。8781 のオリジンは音をオフに保存してある。音を鳴らしたら、終わるときにタブをほかのページへ移す。
- **生態系の調整は Node で**（下）。ブラウザで見るより速い。進化は「選ぶ力が本当にはたらいているか」を、死んだ個体の遺伝子と群れの平均を比べて確かめる（v005 で、オオカミが相手を替えて速さが効いていなかった）。
- **公開前チェック**は毎回「要確認 8 件」と出るが、すべて `../_dev/promo/out/`（Git に入らない、恐竜かけっこの宣伝動画と字幕）。このゲームのファイルに問題が出たら公開しない。コミットには自分の変更だけ（`archive.html`・`CLAUDE.md` は自分の行だけ）。
- 長い書きかえは、bash のヒアドキュメントに日本語とクォートをまぜると壊れやすい。Python の小さなスクリプトをスクラッチに書いて流すと安全。
- `life.js` の `nearest` は粗い格子（8 区画）。生き物の上限（シカ 220・オオカミ 40・サカナ 360・サギ 30）がセーブの最大の大きさ（約 52KB）と重さを決めている。

- **読む順**: `../CLAUDE.md` → `../RULES.md` → このファイル → 下の「ファイル構成」で関係するファイルだけ。

- **区切りごとに**（`../RULES.md` 3章）: 確認 → 下の「状態」に1行 → `launcher.html` の表に1行 → 公開前チェック → コミット → push。節目なら `versions/v0NN-名前/` に index.html・css・js を丸ごとコピー（アクセス解析の1行を消し、← と姉妹作へのリンクを `../../../` に）してカードも。節目でない版は push のあとで表に Git のリンク。JS・CSS を変えたら `index.html` の `?v=` を版の番号に（いまは `?v=12`）。見た目が変わったら `tools/make-thumbs.ps1 -Games edge-falls`（8780 が使えないときは `-Port 8781`）。保管庫のカードの更新日も。

## しくみのメモ

## 気温と季節（v008）
- ユーザー「気温と季節を足して」。1年＝16 日（春夏秋冬 4 日ずつ）。はじめは春のなかごろ（年の進み 0.1）。

- 草: 育つ速さ×`tempGrow`（1 度で 0、13 度で 1、33 度より上で落ちる）。−2 度より下で枯れる。水草は水の中なので +4 度。木も気温で育つ。
