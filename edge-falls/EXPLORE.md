# 果ての滝の箱庭 探検モード 仕様（案）

2026-10-14。`PLAYTEST.md` の #20（ユーザーの思いつき「箱庭を探検するモードがほしい」）を、仕様の案にした。**まだ作っていない**。決めてほしいことは最後の章。

`DESIGN.md` の約束（要素を増やさず組み合わせる・システマチックな UI にしない・没入を守る・心に残す）をそのまま守る。

---

## 0. ひとことで

> **自分でつくった世界に、降りてみる。**

上から見ていたときは小さな水たまりだった湖が、降りると向こう岸がかすむほど広い。指でひと筋けずった川が、足もとで音を立てて流れる。ふちまで歩くと、自分の世界が果てから深淵へ落ちていくのが見える。

心に残したい体験（遊び終わったあとに残る一文）:
> 「上から見ていた世界は、中から見ると、ずっと大きかった。」

神の手（上から変える）と、旅人の目（中で感じる）の**2つの大きさを行き来する**ことが、このモードの芯。

## 1. 位置づけ

| | 箱庭（いま） | 探検 |
|---|---|---|
| 目 | 神の目（上から斜めに） | 旅人の目（地面の高さ） |
| できること | 土・水・命で世界を変える | 歩く・見る・ついて行く |
| できないこと | 中から感じる | 世界を変える（**手に持つものは使えない**） |
| 時 | 流れる（天の輪で速さ） | 流れる（いつも ×1。止めることはできる） |

- 世界のしくみ（水・生態系・季節）は**何も変えない**。同じ世界を別の目で見るだけ。新しい資源・新しい敵・新しい数字は足さない。
- 降りているあいだは土も水も命も使えない。これが探検の「損」（DESIGN.md 2章の表裏一体）。罰ではなく、神の手を休めて世界に身をまかせる時間。
- 時はいつも ×1。×16 で走る世界の中を歩くと酔うし、ながめる楽しさとぶつかる。

## 2. 入り方・出方

### 2.1 入る
- **手に何も持っていないとき**（＝「見る」）、地面を**ダブルタップ**（PC はダブルクリック）→ そこへ降りる。
- 見る用のボタン（`view.js`）の列に「降りる」を1つ足す（画素の絵は小さな足あと）。押すと画面のまんなかの地面へ。
- 生き物を押して出る札（`#card`）に「ついて行く」（4章）。

### 2.2 降りる演出（とぎれさせない）
ユーザーは「ズームがシームレスに」を大事にしている（PLAYTEST #19）ので、暗転や切りかえの札は使わない。
1. 斜めの見え方のまま、降りる所へ寄っていく（いまの寄るの続き。0.8 秒）。
2. 寄りきる直前に、**雲が1つ手前を横切る**（白いもやが画面をなでる。0.4 秒）。そのあいだに描き方を探検の絵に切りかえる。
3. もやが晴れると、地面の高さに立っている。少し上から落ちてきて、着いた所に土ぼこり（v062 の生き物が着くときと同じ粒）。

出るときは逆: 空を見上げる → もや → 上から見た世界にもどり、降りていた所がしばらくうすく光る（「ここにいた」）。

### 2.3 出る
- 左上に小さく「のぼる」（画素の絵は上向きの矢と雲）。Esc・右クリックでも。
- 出たときのカメラは、降りる前の向き・寄り具合にもどす。

## 3. 歩く（旅人の目）

### 3.1 目
- **一人称**（旅人の姿は描かない）。図形を組み合わせた人の姿はチープになりやすい（v030 のユーザーの言葉）し、だれでもない目のほうが「自分が世界の中にいる」と感じやすい。
- 目の高さは、シカの頭くらい（地面から 0.6 区画ほど）。草や苗が目の前でゆれ、シカがすぐ横を通ると大きく見える。
- 自分がいる印は、足もとの影と、歩くと立つ小さな土ぼこり・水を歩くと波紋だけ。

### 3.2 操作（指1本でできる）
| | 指（スマホ） | PC |
|---|---|---|
| 見回す | ドラッグ | マウスのドラッグ（または右ドラッグ） |
| 歩く | 行きたい所を**押す** → そこまで歩く。押しつづけると、向いている方へ歩きつづける | WASD・矢印。押した所へ歩く（クリック）も同じ |
| 走る | 2回つづけて押す | Shift |
| 立ち止まる | もう一度押す | 手を離す |

- バーチャルの棒（画面の左下の丸）は使わない。画面に UI が増え、世界の上に「ゲームのボタン」がのるので。
- 押した所には、ヒントの光（ほたる）と同じ光の点を一瞬。

### 3.3 世界の手ざわり（いまのしくみがそのまま効く）
| 所 | 起きること | 気づくこと |
|---|---|---|
| 段差 | 1 段（高さ 1.2）まではのぼれる。それより高い崖はのぼれない（回りこむ） | 自分が盛った山・けずった谷の大きさ |
| 浅い水（深さ 0.35 まで） | 歩ける。足もとに波紋、水音 | |
| 深い水 | 泳ぐ（ゆっくり）。**流れに流される**（`flowAt`） | 川の速さ。サカナが流される気持ち |
| 水の中 | 目が水面より下になると、青くゆらぐ水の中の景色（水草・サカナ）。音がこもる | |
| 山の上 | 雲の高さに届くと、雲の中を歩く（白くかすむ）。冬は雪をふむ音 | 雲が山にぶつかって雨になる所 |
| 雨 | 自分のまわりに雨のすじ。地面にはね | |
| 夜 | 暗い。ホタルが近くに。太陽が遠くを回っているのが見える | 昼と夜はどこでも同じではない（太陽の近くは昼） |
| ふち | 地面が切れて、その先は深淵。滝が足もとから落ちていく。岩の根が下へのび、下に星 | この世界の果て |

### 3.4 果てから落ちる（このモードのいちばんの山場）
- ふちを越えて歩くと、**落ちる**。止めない（警告も出さない）。
- 滝の水といっしょに深淵へ落ちていく（上に、遠ざかる円盤の裏と岩の根。3 秒ほど）。暗くなり、深淵の光の中を通って——
- **泉からわき出る**。泉がなければ、いちばん近い水辺から。水といっしょに「めぐった」ことを、体で知る。
- これは DESIGN.md 0章のきまり「何も生まれず、何も消えない。ただ、めぐるだけ」を、プレイヤー自身が通る体験。初めて落ちたときだけ、一行「水は深淵をめぐって、泉へもどる」。
- ゲームオーバーではない。むしろ見つけたこと（6章）の1つ。

### 3.5 生き物とのかかわり
- 旅人は生き物に**ふれない・食べられない**。オオカミは旅人を追わない（こわい思いをさせない。`DESIGN.md` 5章）。
- シカとサギは、近づきすぎると少しはなれる（いまの「逃げる」を、旅人に弱く当てるだけ）。そっと近づくと逃げない（走ると逃げる）。
- 生き物を押すと、その横に小さく1匹の札（いまの `#card` と同じ。名前・年・遺伝子の見た目）。

## 4. ついて行く（生き物の目のそばで）

1匹を選んで、その少しうしろからついて行く。**あやつらない**（生態系のしくみをこわさない。あやつる遊びは `../parasite-pilot/` がある）。

| 生き物 | 見えるもの |
|---|---|
| シカ | 草を食べる・水辺へ行く・オオカミから逃げる。足の長さ（遺伝子）が近くで分かる |
| オオカミ | シカを追う。追いつけない、追いつく（追いついたら、いつもの小さなけむり。カメラは少し上へ引いて見せすぎない） |
| サカナ | 水の中。流れに負けそうになる・滝のふちで踏んばる・落ちる（落ちたらいっしょに深淵へ、3.4 と同じ） |
| サギ | 空をとぶ（**空から自分の世界を見下ろす**、神の目とはちがう低い空）。浅瀬に降りてサカナをねらう |

- その1匹が死んだら、カメラは少し上へ引き、一行「シカは命のつぼへもどった」。そのまま旅人の目にもどる。
- 進化の年（第九の年）とつながる: 「逃げ足くらべ」のあいだにシカについて行けば、足の速いシカが逃げのびるのを**目の前で**見られる（PLAYTEST #14「進化がよく分からず放っておいた」の手助けにもなる）。

## 5. 描き方（いまの斜めのボクセルでは足りない）

### 5.1 しらべたこと
- いまの描き方は**直交投影**（遠くも近くも同じ大きさ）で、傾きは 0.32〜0.92（`main.js`）。地平線がないので、どれだけ寄せても「地面の高さに立つ」絵にはならない。
- いっぽう、ボクセルの描き方（`style-voxel.js`）は「列ごとに手前から奥へ格子をたどり、前より上に出た所だけ塗る」形。これは**遠近のある高さ地図の描き方（ボクセルスペース。昔のフライトゲームの地形の描き方）とほぼ同じ形**なので、考え方と色（`cellColors` の `TR..`・`SR..`・`LUM`・`Zq`）はそのまま使える。

### 5.2 新しく作るもの（`js/explore.js`。800 行まで）
- **遠近の地形**: 画面の列ごとに、目から光線を出して格子を手前から奥へたどる（DDA）。区画の柱を、遠いほど小さく描く。前より上に出た所だけ塗る（`ybuf`）。区画は角ばったまま（ボクセルのルックを守る）。上の面の粒の模様・段の角の明るさ・画素の輪郭も、いまと同じ決め方で。
- **低い解像度の板**に描いて、ぼかさずに広げる（いまと同じ。スマホは横 240〜320、PC は 400 前後）。列ごとに奥行き（`zbuf`）を残す。
- **水**: 水面を半とうめいで。目が水面より下なら、水の中の色に（青くゆらぐ・遠くほど暗い）。
- **木・生き物・雲**: いまの画素の絵（`PEN`・`drawCreature`）を、遠さで小数の倍率にして立てる（板と見る向きの方を向く札）。`zbuf` とくらべて、地形にかくれる所は描かない。雲は箱のまま、本当の高さに。
- **空**: 背景のドーム（`drawDome`・`domePoint`）をそのまま。太陽と月は**頭の上を本当に回る**（天動説の空を下から見上げる）。
- **ふちと滝**: 大地の外は深淵。ふちに近いときだけ、滝（落ちる水の柱）と岩の根を描く。下を向くと星。
- **遠くはかすむ**（遠さで空の色にまぜる）。描く遠さを区切れるので軽くなる。
- **画風**: まずボクセルだけ。ほかのルックのときは、探検の中はボクセルで描く（または入れない）。

### 5.3 重さの目安
- 列 320 × たどる区画 最大 130（直径 92 区画）。1 コマ PC 5ms 前後・スマホ 12ms までをねらう（いまのボクセルが PC 6〜11ms）。
- 時の計算は ×1 だけなので軽い（×16 の 1/16）。描くのは 30 回/秒でよい（見回しているあいだは毎回）。
- 熱くならないように、PLAYTEST の段階1（解像度は 2 倍まで・間引き）と同じ決まりで。

### 5.4 しくみへのつなぎ
- `EXP`（null でないあいだは `drawWorld` が探検の絵を描く。`collapse.js` の `COL` と同じ形）。時の計算・お題・見つけたことは、いつもどおり進む。
- セーブ: 探検の中にいるかは残さない（つづきからは、いつも上から見た世界）。

## 6. 探検で見つけること（★の代わりの「見つけたこと」をふやす）

いまの見つけたこと（15。`book.js` の `FINDS`）に、**探検でしか見られないもの**を足す。命令ではなく、気づいたらうれしいもの。

| 見つけたこと | 起きるとき |
|---|---|
| 果てに立つ | ふちまで歩く |
| めぐる | 果てから落ちて、泉からわき出る |
| 雲の中 | 山の上で雲の中に入る |
| 滝の裏 | 滝のすぐ内がわで、外を向く |
| いっしょに泳ぐ | サカナのすぐそばを泳ぐ |
| 逃げのびた | ついて行ったシカが、オオカミから逃げきる |

- 見つけたときの小さな絵（`takeSketch`）は、**旅人の目から見た景色**を銅版画ふうに（`DEVNOTES.md`「銅版画も雰囲気が良かった」の使い道）。観察帳の頁に「旅の頁」として並ぶ。
- **旅の版画**: 探検の中から、いま見ている景色を世界の版画にできる。PLAYTEST の段階6の決まり（画面を写さず、大きな板に描き直す・遊ぶための印は出さない）をそのまま使う。

## 7. 没入を守る（してはいけないこと）

- 体力・空腹・時間の制限を足さない。探検はいつでも、何度でも、ただ歩くだけでいい。
- ミニマップ・方位磁針・距離の数字を出さない。迷ったら「のぼる」で上から見ればいい（2つの目を行き来するのが芯）。
- 世界の上に四角い札を出さない。文字は一行まで。
- 生き物の死を近くで見せない（いまと同じ、小さなけむり。カメラは少し引く）。
- 酔わせない: カメラはなめらかに（急に回さない・ゆれは小さく）、歩く速さは一定、見回す速さを設定で選べる。

## 8. 作る順（段階に分ける）

1. **段階 E-1 試作（見た目を確かめる）**: `explore.js` で遠近の地形・水・空・ふちだけ。歩く・見回す・のぼる。降りる演出はかんたんに（もやだけ）。**ユーザーに「チープに見えないか」を見てもらう**。ここで見た目がよくなければ、描き方から考え直す。
2. **段階 E-2 世界を満たす**: 木・生き物・雲・雨・雪・夜・ホタル、音（滝は近いほど大きく・水の中はこもる・足音）。降りる演出をとぎれなく。
3. **段階 E-3 果てから落ちる**: 3.4（落ちる → 深淵 → 泉から）。泳ぐ・流される。
4. **段階 E-4 ついて行く**: シカ・オオカミ・サカナ・サギ。
5. **段階 E-5 心に残す**: 探検の見つけたこと・旅の頁・旅の版画。英語（`TX`）。スマホの重さ。ダイジェストに探検の場面を足す。

どの段階も、Browser ペインで PC とスマホの幅を見て、1 コマの重さをはかってから。

## 9. 決めてほしいこと

1. **いつから降りられるか**: (a) はじめから（第一の年から） (b) ある年から（例: 第三の年の草が来たあと。世界に見るものがふえてから） (c) エンディングのあとのごほうび（「自由な箱庭」といっしょに）。**案は (b)**。来るときは世界の出来事として（「大地に降りる道が見えた」）。
2. **旅人の姿**: 一人称（姿なし）でよいか。小さな姿をうしろから見る三人称にするか。**案は一人称**。
3. **生き物**: 「ついて行く」だけ（あやつらない）でよいか。
4. **時**: 探検の中はいつも ×1 でよいか（止めることはできる）。
5. **進め方**: まず段階 E-1 の試作で見た目を確かめてからでよいか。
6. 円盤が球に丸まる案（`sphere.js`、試作中）のあとで、**丸い世界を歩く**（どこまで歩いても果てがない＝答え合わせ）も入れるか。入れるなら、地平線が丸く下がっていく絵を E-1 のうちに考えておく。
