「ユーザの行動には常にメリット・デメリットが表裏一体で、世界をコントロールするにはバランス感覚が要されること。ただし苦痛にならないようにレベル設定を行うこと。世界に没入できる、まさに箱庭の世界を守ること。いきなりおおくのことをさせるのではなく、すこしずつゲームシステムに慣れさせるよう設計し、スムーズな成長曲線を描けるようにすること。ボタン配置やデザインにもゲーム画面との調和を意識すること。システマチックなUIに気を削がれないように配慮をすること。複雑になりそうならまずはシンプルにできるかを再考すること。要素を増やすのではなく、シンプルな要素の組み合わせができないか考えること。常にUXデザインや認知科学を意識した画面設計にすること。これをプレイしたユーザーに、得た体験を心に残したい。」

## 0. ひとことで

> **何も生まれず、何も消えない。ただ、めぐるだけ。**
> 果てから落ちていくものを、止めることも、手放すこともできる。その手かげんを覚える箱庭。

プレイヤーが覚えるきまりは、この**1つだけ**にする。土・水・命のどれも「どこかから持ってくれば、どこかが減る」。だから行動にはいつも得と損がついてくる（表裏一体）。説明でルールを教えるのではなく、このきまりが世界の手ざわりとして伝わるようにする。

心に残したい体験（遊び終わったあとに残る一文）:
> 「全部を止めようとすると、世界はよどんだ。少し落としてやると、世界はまわりだした。」

## 1. 要素をへらして、組み合わせにする

### 1.1 いまの道具 9 つ → 手に持つもの 3 つ ＋ 空

| いま | 案 | 理由 |
|---|---|---|
| 見る・盛る・削る・泉・草・シカ・オオカミ・サカナ・サギ（ボタン9つ） | **土ぶくろ**・**水がめ**・**命のつぼ**（3つ）。太陽と月は空にあるものをじかにつかむ（いまのまま） | 一度に見分けるものは 4 つ前後まで（作業記憶の限り）。「何でできているか」で3つにまとめると、ボタンの名前を覚えなくても形で分かる |
| 盛る／削る | **土ぶくろ1つ**。なぞると削る（ふくろがふくらむ）。ふくろを押すと「口を開く」＝盛る向きに裏返る | 削った土がそのまま盛る土になる。表と裏が1つの物なので、得と損が同じ物に見える |
| 泉（6 つまで） | **水がめ**。泉を置く・押して止める。数の上限をやめて、**深淵の水が減る**ことを上限にする | 「6」という数はゲームの都合。深淵の水が減ると滝が細くなる＝見て分かる上限になる |
| 草・シカ・オオカミ・サカナ・サギ | **命のつぼ1つ**。押すと中に入っている命（たね・シカ…）が並ぶ。章が進むと中身が増える | 新しい生き物は「ボタンが増える」のではなく「つぼに新しい命が来る」。つぼの中は増えても、手に持つものは3つのまま |
| 見る | 道具を持たない状態が「見る」。もう一度押すと手を空にする | 「見る」はモードではなく、何も持っていないこと |

### 1.2 数字の上限をやめて、めぐる量にする

いまは土ぶくろ・泉 6・命のつぼ「1日に1つ」と、きまりがばらばら。これを**3つとも同じ形**にそろえる。

| もの | どこから来る | どこへ行く | 上限は |
|---|---|---|---|
| 土 | 削った所 | 盛った所 | ふくろの中の量（いまのまま） |
| 水 | 深淵（泉から） | 滝から深淵へ・霧から雲へ | 深淵の残り（滝の太さで見える） |
| 命 | つぼ | 死んだ・落ちた命は深淵へ → **少しずつつぼへ戻る** | つぼの中の数 |

- 命も水と同じめぐり方にする（新しいきまりを足すのではなく、水のきまりをそのまま命にも当てる）。滝から落ちたシカも、食べられたシカも、いつかつぼに戻ってくる。
- 生き物が全部いなくなっても、つぼに命が戻ってくるので**取り返しがつかないことは起きない**（苦しくならない）。
- 戻る速さは Node で決める（目安: 去った命の 1/4 が 2 日かけて戻る。ほかに春に1つ）。子が生まれる分だけ世界の命は増えるので、めぐる量はぴったり保たれなくてよい。

## 2. どの行動にも得と損（表裏一体の表）

新しいしくみはほとんど足さずに、**いまある物理と生態系から自然に出てくる損**を、プレイヤーに見えるようにする。

| 行動 | 得 | 損（同時に起きる） | 見えるようにする所 |
|---|---|---|---|
| 削る | 川筋・水路ができる。土がたまる | 水が早く流れて、滝から多く失われる。低い所は水びたしで草が枯れる | 削った川の先の滝が太くなる |
| 盛る（ふちに） | 水がせき止められて湖。サカナが住める | 下流が干上がる。湖の底の草は枯れる | せきの下で草が茶色に |
| 盛る（山に） | 雲がぶつかって雨がふる | 山の上は寒く、冬は雪と氷。土を使う | 山の頂に雪 |
| 泉をわかせる | 水と草が増える | 深淵が減って、ほかの泉も滝も細くなる。流れが速くなりサカナが落ちる | 滝の太さ・深淵の光 |
| 太陽を止める | その下は草がよく育つ | 下は乾いて暑く、反対がわは夜のまま凍る | 地面の色（乾き・霜） |
| 月を寄せる | 潮で浅瀬ができて、サギが魚をとれる | 月の下のふちから水があふれて失われる | あふれる滝 |
| シカを放す | 草を食べて増える | 増えすぎると草を食べつくし、冬に飢える | 草の色が薄くなる |
| オオカミを放す | シカを抑える。シカが速くなる（進化） | 多すぎるとシカが絶え、自分も飢える | シカの群れのまばらさ |
| サカナ・サギ | 同じ形（食べる・食べられる） | 同じ形 | |
| 時を速める | 早く進む | 見のがす（**罰はない**） | — |

- 「得しかない行動」をなくす。例: いまの泉は置けば置くほど得なので、深淵が減る損を見えるようにする。
- 「損しかない行動」もなくす。滝から落ちるのも、命のつぼと霧と雲につながる（落とすことにも意味がある）。
- **損は罰ではなく、世界の返事**。いきなり大きく出さず、数日かけてゆっくり見える（だから「気づいて直す」ができる）。

## 3. 成長の曲線（すこしずつ慣れる）

### 3.1 章＝世界の年

1つの章を「この世界の1年」（16 日。×4 なら約 4 分）くらいにして、章ごとに**1つだけ**新しいものが来る。説明の札は出さず、**世界の出来事として**来る。

| 章 | 来るもの | プレイヤーがすること（お題） | 覚えること | 損に気づく |
|---|---|---|---|---|
| 1 水 | 水がめ（泉1つ）。はじめは岩と土だけの大地 | 泉をわかせ、水が果てから落ちるのを見る。**湖をひとつ** | 水は低い方へ、ふちから落ちる | 落ちるとなくなる？ → 深淵から戻る |
| 2 土 | 土ぶくろ | ふちを盛って湖を大きく、別の所に川を | 削れば盛れる | せきの下が干上がる |
| 3 草 | つぼにたね | **草の原** | 水と光で育つ | 水びたしで枯れる |
| 4 シカ | つぼにシカ | **シカのむれ** | 食べる・増える | 食べつくし |
| 5 冬 | 季節がはっきりする（それまでは冬がおだやか） | **冬をこす**（シカが春まで残る） | 季節と寒さ | 秋に増えすぎると冬に飢える |
| 6 オオカミ | つぼにオオカミ | **食べる・食べられる** | 数のつり合い | 多すぎると共だおれ |
| 7 水の命 | つぼにサカナ、次の年にサギ | **湖のサカナ**、サギと**いっしょに** | 水の中にもつり合い | 流れで落ちる・浅瀬はとられる |
| 8 進化 | 観察帳に「遺伝子の頁」 | **逃げ足くらべ**など3つから1つ選ぶ | きびしさが体を変える | きびしすぎると絶える |
| 9 めぐる世界 | なにも来ない（全部そろった） | **めぐる世界**（全部が1年つづく） | 手かげん | — |
| 終わり | エンディング | — | — | — |

- 太陽と月の手ざわりは、章1から使える（もとからある空のもの）。ただし章1〜4は月の潮をおだやかにしておく。
- **むずかしさは世界のつまみで上げる**（UI を増やさない）: 冬の寒さ、潮の強さ、深淵の量、つぼに戻る速さ。章が進むほど少しずつきびしく。
- お題は**いつでも1つだけ**見える（いまの「第一の日のお題」と同じ）。9章でも、出ている目標は1つ。

### 3.2 苦しくしない

- **時間の制限・ゲームオーバーなし**。お題が進まないあいだは、何日かたつごとに世界がそっと助ける（ヒントのはしご）:
  1. 3日: 関係のある所がかすかに光る（例: 草が育ちそうな水辺）
  2. 6日: 一行のひとこと（いまのヒントの文）
  3. 10日: つぼに命を1つ足す／冬を少しやわらげる
- ★の点数はやめる（または、観察帳の中だけに置く）。★は「もっと早く」と急がせ、ながめる楽しさとぶつかる。代わりに**観察の記録**（3.3）。
- 絶えたら責めない。「シカがいなくなった。つぼに、いつか戻ってくる」。
- 「止める」はいつでも。止めたまま地形を直せる（いまのまま）。

### 3.3 観察の記録（★の代わり）

お題とは別に、**見つけると観察帳の頁が埋まる**小さな出来事。命令ではなく、気づいたらうれしいもの。
例: 「シカが川を泳いでわたった」「サギが氷の上で立ちつくした」「滝のしぶきが雲になった」「山に初めて雪」「オオカミがシカを追いきれなかった」「サカナが滝から落ちた」。
- 新しい要素ではなく、いまのしくみがすでに起こしていることに名前をつけるだけ。
- 埋まった頁は、銅版画ふうの小さな絵と一行（`DEVNOTES.md`「銅版画も雰囲気が良かった」の使い道）。

## 4. 画面（ゲームの世界に UI をとけこませる）

### 4.1 方針
- **画面のほとんどは世界**。いまの右がわの箱（お題・グラフ・遺伝子・水のめぐり・神の手・時の速さ・音）は、ふだん隠す。
- 数字の代わりに**世界そのもので見せる**: 深淵の水＝滝の太さと円盤の下の光、土ぶくろ＝ふくろのふくらみ、季節＝太陽の道と草の色、生き物の数＝群れの見た目。
- 文字は1行まで。説明は、さわってみて分かる順に。

### 4.2 置き場所（スマホの縦を先に考える）

```
┌────────────────────┐
│ ←          ◐天の輪   │  ← 左上: 戻る（小さく）。右上: 天の輪（季節と日・時の速さ）
│                      │
│   いまのお題（1行）   │  ← 上のまんなか。うすく、数秒で小さくなる
│                      │
│                      │
│      浮かぶ大地      │  ← 世界。太陽と月はじかにつかむ
│                      │
│                      │
│                      │
│  [土]  [水]  [命]   📖│  ← 下: 手に持つもの3つ（親指が届く所）。右下: 観察帳
└────────────────────┘
```

- **手に持つもの3つ**は四角いボタンではなく、画風に合わせた**物の絵**（ボクセルなら画素の土ぶくろ・水がめ・つぼ）。深淵の上に浮かんでいる小物のように置く。中身の量が絵で分かる（ふくろのふくらみ・かめの水の高さ・つぼの光の数）。
- 持っているものは、手もと（指・カーソルの先）に小さく絵がつく。「いま何を持っているか」を覚えておかなくてよい。
- **天の輪**: 小さな丸い文字盤。外の輪が1年（季節の色）、針が今日。**押すと止まる／動く、長押しで速くなる**（×4・×16 のボタンをなくす）。時の速さと季節の表示を1つにまとめる。
- **観察帳**（📖）: グラフ・遺伝子・水のめぐり・観察の記録・セーブ・音・「このゲームについて」をここに全部入れる。羊皮紙と銅版画の見た目で、開くと世界の上に本が開く。**見たい人が見る**もので、遊ぶのに開かなくてよい。
- 1匹の札（いまの `#card`）は、生き物を押したときだけ、その生き物のそばに小さく。

### 4.3 認知科学・UX のよりどころ（設計のチェック表）

| 考え | この設計では |
|---|---|
| 作業記憶は一度に 4 つ前後 | 手に持つもの3つ＋空。お題は1つ |
| 段階的に見せる（progressive disclosure） | 章ごとに1つ。遺伝子の頁は章8から |
| 思い出すより見て分かる（recognition over recall） | 物の絵・手もとの絵。ボタンの名前を覚えなくてよい |
| じかにさわる（direct manipulation）と 0.1 秒の手ごたえ | なぞると土が動く音と粒。太陽をつかむ |
| 原因と結果を近くに | 損は「さわった所の近く」で見える（せきの下・削った川の先の滝） |
| ちょうどよいむずかしさ（フロー） | 世界のつまみで少しずつ。ヒントのはしごで落ちこまない |
| 目標が近いと進みたくなる（goal gradient） | お題の進みは、上の1行の下に細い線で |
| 親指の届く所・大きさ（Fitts） | 手に持つものは下。44px 以上 |
| 終わりと山場が記憶に残る（ピーク・エンドの法則） | 山場: 初めての滝・初めての冬・初めての進化。終わり: 6章 |
| 終わっていないことは心に残る（ツァイガルニク） | 章の終わりに、次に来るものの影だけ見せる（つぼの中に何かいる） |

## 5. 没入を守る（してはいけないこと）

- 世界の上にふつうの四角いポップアップを出さない。知らせは世界の中（空に文字がにじむ・つぼが光る）か、画面の下に一行。
- 赤い警告色・「失敗」「ゲームオーバー」の言葉を使わない。
- 音で急かさない（BGM はおだやか。いまのまま）。知らせの音も、世界の音（風・鳥・水）でつくる。
- 章の切りかわりで画面を暗転させない。季節がめぐるように、そのまま続く。
- 数字は観察帳の中に。世界の上には、なるべく数字を出さない（お題の1行だけ）。

## 6. 心に残す（エンディングとおみやげ）

- **エンディング**（PLAN.md の段階C「大地が丸くなる答え合わせ」）: めぐる世界のお題をこえた年の冬至の夜、円盤のふちがゆっくり下へ丸まって、球になる。果ての滝が消えて、川は海へ、海から雲へ、雲から雨へ、深淵なしで水がめぐる。
  - 文: 「本当の世界には、果てがない。落ちていくものは、どこかで、めぐっている。」
  - そのあと、プレイヤーの世界の年表（初めての滝・初めての冬・いちばん速いシカ…）を銅版画の頁で数枚。
- **世界の版画**（おみやげ）: いまの自分の大地を、銅版画の画風で1枚の絵にして保存できる（PNG）。題・年・観察の数を下に刻む。銅版画のコードはもうある（`?style=etch`）ので、新しく作るのは絵の書き出しだけ。
- エンディングのあとは**自由な箱庭**として続けられる（つぼの中身は全部・つまみはプレイヤーが選ぶ）。

## 9. 実装で変えたこと・まだのこと（v011）

- **章は十の年**: 3.1 の「7 水の命」を、サカナの年とサギの年に分けた（1年に新しいものは1つ、を守るため）。冬の年は 5 番目のまま。
- **土の年の目標**: 水の年で湖を広げすぎると、土の年がすぐ終わってしまったので、「章に入ったときより 4 ポイント広く（8% 以上）」にした。
- **進化の年の目標**: 「0.6 にする」は 40 日でも届かなかった。「どれか1つの遺伝子の平均を、章に入ったときより 0.08 動かす（上でも下でも）」にした。使わない力が下がるのも進化、と言えるように。
- **エンディング**: 「冬至の夜に」は待たせるのでやめ、めぐる世界ができたら少しあとに始まる。演出は v010 の「殻がはがれる」を使い、最後に年表と「世界の版画をのこす」「自由な箱庭へ」。
