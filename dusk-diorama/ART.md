# 闇の箱庭（仮）— 見た目の目標（ART.md）

2026-10-22〜。ユーザー「箱庭アプリのような雰囲気で、ダークファンタジーの世界を作って」「まずはコンセプトアートから」「ゲーム性はこれから。見た目にマッチする企画をあとで考える」。

## 1. ねらい
- **箱庭アプリの手ざわり**: 宙に浮かぶ土のかたまり（下は地層と垂れた根）の上に、小さな村と廃墟。手にとれる模型に見えること（ミニチュアのぼけ＝上下をぼかす、斜め見下ろし、ドラッグで回す）。手本の方向: Tiny Glade・Townscaper のような「さわって眺める小さな世界」。写さない。
- **ダークファンタジー**: 夜・廃墟・枯れ木・墓地・霧・鬼火・たき火。こわさは「さびしさ・不気味さ」まで。血・死体・性的なものは入れない（CLAUDE.md の基本ルール）。
- **目立たせるのは灯**: 暗い世界で、あたたかい灯（窓・ランタン・たき火）が目の行き先になる。

## 2. いまの見くらべ（`look/`、手元だけ・Git に入れない）
同じ箱庭を3つのルックで。光・空・粒・色の仕上げだけが違う。
- A 月夜の模型: 青い月あかり＋窓とたき火のあたたかい灯。いちばん「箱庭アプリ」に近い
- B 灯りの闇: 光の届くところだけ色。外は月の青い影（勇者は今日も腹をこわすの「C 灯りの闇」をユーザーが選びかけた流れ）
- C 灰と残り火: 赤い日食・灰が降る・家の灯は消え、たき火だけ

## 2.5 決まったこと（2026-10-23）
- **ルックは C 灰と残り火**（ユーザー）。
- ユーザー「ポリゴンポリゴンしすぎている」「滑らかなほど綺麗ともかぎらない。適切な汚しや崩れがぐっとくるルックになることもある」「ジオラマ的な被写界深度の表現は好み」。
  → 細かさは**なめらかさではなく、汚し・崩れ・ほつれ**で出す。上下のぼけ（ミニチュアの被写界深度）は残す。
- 試しの版は `look/?detail=1`（`look/detail.js`）: 白黒の絵を色と凹凸に使う質感（石積み・はがれた漆喰・雨だれ・板・樹皮・岩）、屋根の板石と欠け・大きく抜けた屋根、木組み・窓わく・外れかけたよろい戸、控え壁・鐘の窓・傾いた十字、形のちがう墓石と鉄柵、塔のまわりのれんがの山・梁・枯れたつた、倒れた柵・踏み石・たる・荷車、ふちから垂れる草、根 130 本、下の岩の段と岩くれ、たき火のけむり。C は明るさ 1.0→1.3。

## 3. 大きさと光（測った値）
- 島の半径 約6（ふちは 5.35〜6.65）、下の岩の深さ 約8.2。小屋の壁の高さ 0.75、旅人 0.55、礼拝堂の塔 約3.8。
- カメラ: 画角 30°、距離 30〜（たて画面は 24/縦横比）、見下ろし 0.5 rad。
- 光: 月（向きの光・影 2048）、半球の光、手前下からの弱い光（下の岩を読ませる）、点の光 9（窓5・ランタン3・たき火・旅人）。
- 仕上げ: 光のにじみ → ACES → 上下のぼけ → 彩度（暗いところほど色を抜く）・周辺の暗さ・粒子。
