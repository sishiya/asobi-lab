# 闇の箱庭（仮）— 見た目の目標（ART.md）

2026-10-22〜。ユーザー「箱庭アプリのような雰囲気で、ダークファンタジーの世界を作って」「まずはコンセプトアートから」「ゲーム性はこれから。見た目にマッチする企画をあとで考える」。

## 1. ねらい
- **箱庭アプリの手ざわり**: 宙に浮かぶ土のかたまり（下は地層と垂れた根）の上に、小さな村と廃墟。手にとれる模型に見えること（ミニチュアのぼけ＝上下をぼかす、斜め見下ろし、ドラッグで回す）。手本の方向: Tiny Glade・Townscaper のような「さわって眺める小さな世界」。写さない。
- **ダークファンタジー**: 夜・廃墟・枯れ木・墓地・霧・鬼火・たき火。こわさは「さびしさ・不気味さ」まで。血・死体・性的なものは入れない（CLAUDE.md の基本ルール）。
- **目立たせるのは灯**: 暗い世界で、あたたかい灯（窓・ランタン・たき火）が目の行き先になる。

## 2. いまの見くらべ（`look/`、手元だけ・Git に入れない）
同じ箱庭を3つのルックで。光・空・粒・色の仕上げだけが違う。
- A 月夜の模型: 青い月あかり＋窓とたき火のあたたかい灯。いちばん「箱庭アプリ」に近い
- B 灯りの闇: 光の届くところだけ色。外は月の青い影（勇者は今日も腹をこわすの「C 灯りの闇」をユーザーが選びかけた流れ）
- C 灰と残り火: 赤い日食・灰が降る・家の灯は消え、たき火だけ

## 2.5 決まったこと（2026-10-23）
- **ルックは C 灰と残り火**（ユーザー）。
- ユーザー「ポリゴンポリゴンしすぎている」「滑らかなほど綺麗ともかぎらない。適切な汚しや崩れがぐっとくるルックになることもある」「ジオラマ的な被写界深度の表現は好み」。
  → 細かさは**なめらかさではなく、汚し・崩れ・ほつれ**で出す。上下のぼけ（ミニチュアの被写界深度）は残す。
- 試しの版は `look/?detail=1`（`look/detail.js`）: 白黒の絵を色と凹凸に使う質感（石積み・はがれた漆喰・雨だれ・板・樹皮・岩）、屋根の板石と欠け・大きく抜けた屋根、木組み・窓わく・外れかけたよろい戸、控え壁・鐘の窓・傾いた十字、形のちがう墓石と鉄柵、塔のまわりのれんがの山・梁・枯れたつた、倒れた柵・踏み石・たる・荷車、ふちから垂れる草、根 130 本、下の岩の段と岩くれ、たき火のけむり。C は明るさ 1.0→1.3。

## 3. 大きさと光（測った値）
- 島の半径 約6（ふちは 5.35〜6.65）、下の岩の深さ 約8.2。小屋の壁の高さ 0.75、旅人 0.55、礼拝堂の塔 約3.8。
- カメラ: 画角 30°、距離 30〜（たて画面は 24/縦横比）、見下ろし 0.5 rad。
- 光: 月（向きの光・影 2048）、半球の光、手前下からの弱い光（下の岩を読ませる）、点の光 9（窓5・ランタン3・たき火・旅人）。
- 仕上げ: 光のにじみ → ACES → 上下のぼけ → 彩度（暗いところほど色を抜く）・周辺の暗さ・粒子。

## 4. 採点のしかた

## 5. 火トカゲ（2026-10-24、アートディレクターと。v016）
遊びの主役（つまんで闇へ連れていく・丸くなって照らす）になったのに、原寸で 10px ほど・黒い体が黒い草にとけ・たき火の真ん前で炎のにじみに隠れて、ほぼ見えなかった（採点 2/10）。直して 5/10（試作として可）。
- **大きさと場所**: K 1.6→1.85（体長 約0.85）。ふだんの場所は、はじめのカメラから見て火の右よこ（輪の角 0〜0.6）。炎のにじみに重ねない。火のまわりの輪（0.85〜1.1）は草を低く・灰の地面 `#4a443e` に（`village.js` の `trod`、`island.js` の `ASH`）。
- **見分けは「黒い体＋間の黒が残る斑点＋足もとの影」**: 斑点は節ごとに1〜2個・大きさ 0.4〜0.9 倍・ところどころ前後にのびる、色 `#c8901a`、ふだんの emissive 0.3±0.08 を3つの組でずらして熾火のように明滅。足もとの影は不透明度 0.78・体長×1.25・幅は体の 1.8 倍、ふちを模様でくずす。**体ぜんぶを光らせない**（a1・a2 の失敗: 明るい黄色の斑点が火の光でつながり、ふちの光と灰も明るすぎて「燃えるかたまり」に見えた）。
- **皮**: たき火側だけのふちの光（fresnel^3 × たき火の向き、強さ 0.6、火から 3.2 まで、模様でむら）。背にまだらの灰、肌の荒さは横腹 0.55・背 0.9（0.3 では球ごとに照りの点が出て数珠に見えた）。目に小さなたき火の映り（顔の向きが読める）。
- **丸まり**: 尾を頭へ 約300° 巻く（節ごとの角 `CURL`。きれいな輪にせず、尾の先ははみ出す）。足をたたみ、頭を少し上げる。
- **表情と歩き**: 火がはぜると首を上へ 25°、マウスを乗せる・運ぶと手へ振り向いて 35°・のどをふくらませ・手のほうの前足を上げる（`ctl.peek`）。歩きは 3〜4 歩ごとに 0.4〜0.85 秒止まる（長さはばらつかせる）。足はつけ根が太く先が細い2本の棒と、平たい手。
- **闇で休むとき**: 斑点だけ上がる（+0.45k）。点の光は 6・届く距離 1.4・体の向こう側（カメラの反対）0.2・高さ 0.15 で、体は逆光の影絵、まわりの灰が丸く照らされる。
- **残り**: rest は、ともした隣のかがり台の炎（行き先が台から 0.3）に飲まれて形が読めない（3/10）→ 休む場所を台から 0.6 以上はなすには、台にふれる距離（0.7）との両立をゲームデザイン・UX と決める。ふだんの寄り 0.8 で見つけにくいのは、島全体のもやで黒が持ち上がっているのがいちばんの原因（ルックの課題）。
- **採点のしかた**: `node dusk-diorama/tools/sal-look.mjs <名前>` で home・flare・hover・curl・rest を、ふだんの寄り 0.8 といちばん寄せた 0.45 の原寸で、PC とスマホで切り出す。`sal-sheet.mjs` で前とあとを並べる。見るのは ①1秒で見つかるか ②にじみの中で輪郭が残るか ③丸まりが形で読めるか ④顔の向き ⑤チープさ（つるつるの球の列・ネオンの光・機械の動き）。
